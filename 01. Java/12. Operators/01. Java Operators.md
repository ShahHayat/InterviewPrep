## Introduction to Operators

**Definition**: Operators are special symbols that perform specific operations on one, two, or three operands and return a result.

**Classification by Operands**:
- **Unary Operators**: Operate on single operand (e.g., `++`, `--`, `!`, `~`)
- **Binary Operators**: Operate on two operands (e.g., `+`, `-`, `*`, `/`, `==`, `&&`)
- **Ternary Operator**: Operates on three operands (`? :`)

**Classification by Function**:
- Arithmetic, Relational, Logical, Bitwise, Assignment, etc.

## Arithmetic Operators

### Basic Arithmetic Operators

| Operator | Name | Description | Example |
|----------|------|-------------|---------|
| `+` | Addition | Adds two operands | `a + b` |
| `-` | Subtraction | Subtracts second operand from first | `a - b` |
| `*` | Multiplication | Multiplies two operands | `a * b` |
| `/` | Division | Divides first operand by second | `a / b` |
| `%` | Modulus | Returns remainder after division | `a % b` |

### Important Notes on Arithmetic Operations

#### Integer Division
```java
int a = 10;
int b = 3;
int result = a / b;  // result = 3 (not 3.333...)
```

#### Floating-Point Precision
```java
double a = 0.1;
double b = 0.2;
double result = a + b;  // result ≈ 0.30000000000000004
```

#### Modulus with Negative Numbers
```java
int a = -10;
int b = 3;
int result = a % b;  // result = -1
```

#### Overflow and Underflow
```java
int max = Integer.MAX_VALUE;
int overflow = max + 1;  // Wraps around to Integer.MIN_VALUE

int min = Integer.MIN_VALUE;
int underflow = min - 1;  // Wraps around to Integer.MAX_VALUE
```

## Relational Operators

### Comparison Operators

| Operator | Name | Description | Example |
|----------|------|-------------|---------|
| `==` | Equal to | Checks if operands are equal | `a == b` |
| `!=` | Not equal to | Checks if operands are not equal | `a != b` |
| `>` | Greater than | Checks if left operand is greater | `a > b` |
| `<` | Less than | Checks if left operand is less | `a < b` |
| `>=` | Greater than or equal to | Checks if left operand is greater or equal | `a >= b` |
| `<=` | Less than or equal to | Checks if left operand is less or equal | `a <= b` |

### Important Notes on Relational Operators

#### Reference Equality vs Value Equality
```java
String s1 = "Hello";
String s2 = new String("Hello");
String s3 = "Hello";

System.out.println(s1 == s2);  // false (different objects)
System.out.println(s1 == s3);  // true (same object due to string pool)
System.out.println(s1.equals(s2));  // true (same content)
```

#### Floating-Point Comparisons
```java
double a = 0.1 + 0.2;
double b = 0.3;

// Don't use == for floating-point comparisons
System.out.println(a == b);  // false

// Use epsilon comparison instead
double epsilon = 0.0001;
System.out.println(Math.abs(a - b) < epsilon);  // true
```

## Logical Operators

### Boolean Logical Operators

| Operator | Name | Description | Example |
|----------|------|-------------|---------|
| `&&` | Logical AND | Returns true if both operands are true | `a && b` |
| `\|\|` | Logical OR | Returns true if either operand is true | `a \|\| b` |
| `!` | Logical NOT | Returns opposite of operand | `!a` |

### Short-Circuit Evaluation

**Important**: `&&` and `||` use short-circuit evaluation.

```java
// Short-circuit AND
boolean result = false && someExpensiveMethod();  // someExpensiveMethod() is NOT called

// Short-circuit OR
boolean result = true || someExpensiveMethod();   // someExpensiveMethod() is NOT called
```

### Non-Short-Circuit Operators

| Operator | Name | Description |
|----------|------|-------------|
| `&` | Bitwise AND | Always evaluates both operands |
| `\|` | Bitwise OR | Always evaluates both operands |

```java
// Non-short-circuit AND
boolean result = false & someExpensiveMethod();  // someExpensiveMethod() IS called

// Non-short-circuit OR
boolean result = true | someExpensiveMethod();   // someExpensiveMethod() IS called
```

### Truth Tables

#### AND Truth Table
| A | B | A && B |
|---|---|--------|
| T | T | T |
| T | F | F |
| F | T | F |
| F | F | F |

#### OR Truth Table
| A | B | A \|\| B |
|---|---|---------|
| T | T | T |
| T | F | T |
| F | T | T |
| F | F | F |

#### NOT Truth Table
| A | !A |
|---|----|
| T | F |
| F | T |

## Bitwise Operators

### Bitwise Logical Operators

| Operator | Name | Description | Example |
|----------|------|-------------|---------|
| `&` | Bitwise AND | Performs AND on each bit | `a & b` |
| `\|` | Bitwise OR | Performs OR on each bit | `a \| b` |
| `^` | Bitwise XOR | Performs XOR on each bit | `a ^ b` |
| `~` | Bitwise NOT | Inverts all bits | `~a` |

### Bitwise Shift Operators

| Operator | Name | Description | Example |
|----------|------|-------------|---------|
| `<<` | Left shift | Shifts bits left by specified amount | `a << n` |
| `>>` | Right shift (signed) | Shifts bits right, preserves sign | `a >> n` |
| `>>>` | Right shift (unsigned) | Shifts bits right, fills with zeros | `a >>> n` |

### Bitwise Operations Examples

```java
int a = 5;  // 0101 in binary
int b = 3;  // 0011 in binary

int and = a & b;   // 0001 = 1
int or = a | b;    // 0111 = 7
int xor = a ^ b;   // 0110 = 6
int not = ~a;      // 11111111111111111111111111111010 = -6

int leftShift = a << 1;   // 1010 = 10
int rightShift = a >> 1;  // 0010 = 2
int unsignedRightShift = a >>> 1;  // 0010 = 2
```

### Common Bitwise Patterns

#### Check if number is power of 2
```java
boolean isPowerOfTwo = (n & (n - 1)) == 0;
```

#### Get the rightmost set bit
```java
int rightmostSetBit = n & (-n);
```

#### Clear the rightmost set bit
```java
int cleared = n & (n - 1);
```

#### Count set bits
```java
int count = 0;
while (n != 0) {
    count += n & 1;
    n = n >>> 1;
}
```

## Assignment Operators

### Simple Assignment
```java
int a = 10;  // Simple assignment
```

### Compound Assignment Operators

| Operator | Description | Equivalent to |
|----------|-------------|---------------|
| `+=` | Add and assign | `a = a + b` |
| `-=` | Subtract and assign | `a = a - b` |
| `*=` | Multiply and assign | `a = a * b` |
| `/=` | Divide and assign | `a = a / b` |
| `%=` | Modulus and assign | `a = a % b` |
| `&=` | Bitwise AND and assign | `a = a & b` |
| `\|=` | Bitwise OR and assign | `a = a \| b` |
| `^=` | Bitwise XOR and assign | `a = a ^ b` |
| `<<=` | Left shift and assign | `a = a << b` |
| `>>=` | Right shift and assign | `a = a >> b` |
| `>>>=` | Unsigned right shift and assign | `a = a >>> b` |

### Important Notes on Assignment

#### Type Conversion in Assignment
```java
int a = 10;
double b = a;  // Implicit widening conversion

double c = 10.5;
int d = (int) c;  // Explicit narrowing conversion required
```

#### Compound Assignment and Type Conversion
```java
byte b = 10;
b = b + 1;      // Compilation error: int cannot be assigned to byte
b += 1;         // OK: implicit cast to byte
b = (byte)(b + 1);  // OK: explicit cast
```

## Increment/Decrement Operators

### Pre-increment/Pre-decrement
```java
int a = 5;
int b = ++a;  // a becomes 6, b becomes 6
int c = --a;  // a becomes 5, c becomes 5
```

### Post-increment/Post-decrement
```java
int a = 5;
int b = a++;  // b becomes 5, a becomes 6
int c = a--;  // c becomes 6, a becomes 5
```

### Important Notes on Increment/Decrement

#### Order of Operations
```java
int a = 5;
int result = a++ + ++a;  // 5 + 7 = 12 (a becomes 7)
```

#### Multiple Increments in Same Expression
```java
int a = 5;
int b = a++ + a++ + a++;  // 5 + 6 + 7 = 18 (a becomes 8)
```

#### Side Effects and Readability
```java
// Avoid complex expressions with increment/decrement
int a = 5;
int b = 3;
int result = a++ + ++b;  // Hard to read and understand

// Better approach
int a = 5;
int b = 3;
a++;
b++;
int result = a + b;
```

## Conditional (Ternary) Operator

### Syntax
```java
result = condition ? expression1 : expression2;
```

### Examples
```java
int a = 10;
int b = 20;
int max = (a > b) ? a : b;  // max = 20

String result = (a > 0) ? "Positive" : "Non-positive";

// Nested ternary (avoid for readability)
int c = 15;
int max = (a > b) ? (a > c ? a : c) : (b > c ? b : c);
```

### Important Notes

#### Type Compatibility
```java
// Both expressions must be compatible types
int a = 10;
double b = 20.5;
double result = (a > 5) ? a : b;  // OK: int can be converted to double

// Error: incompatible types
// int result = (a > 5) ? "string" : 10;
```

#### Null Safety
```java
String str = null;
String result = (str != null) ? str.toUpperCase() : "DEFAULT";
```

## Instanceof Operator

### Syntax
```java
object instanceof Type
```

### Examples
```java
String str = "Hello";
Integer num = 10;
Object obj = new ArrayList<>();

System.out.println(str instanceof String);     // true
System.out.println(str instanceof Object);     // true
System.out.println(num instanceof Number);     // true
System.out.println(obj instanceof List);       // true
System.out.println(str instanceof Integer);    // false
```

### Pattern Matching (Java 14+)
```java
Object obj = "Hello";

// Traditional instanceof
if (obj instanceof String) {
    String str = (String) obj;
    System.out.println(str.length());
}

// Pattern matching (Java 14+)
if (obj instanceof String str) {
    System.out.println(str.length());
}
```

### Important Notes

#### Null Handling
```java
String str = null;
System.out.println(str instanceof String);  // false (null is not an instance of any type)
```

#### Interface Checking
```java
List<String> list = new ArrayList<>();
System.out.println(list instanceof List);        // true
System.out.println(list instanceof Collection);  // true
System.out.println(list instanceof Iterable);    // true
```

## Operator Precedence

### Precedence Table (Highest to Lowest)

| Precedence | Operators | Associativity |
|------------|-----------|---------------|
| 1 | `()`, `[]`, `.` | Left to Right |
| 2 | `++`, `--`, `!`, `~`, `+` (unary), `-` (unary), `(type)` | Right to Left |
| 3 | `*`, `/`, `%` | Left to Right |
| 4 | `+`, `-` | Left to Right |
| 5 | `<<`, `>>`, `>>>` | Left to Right |
| 6 | `<`, `<=`, `>`, `>=`, `instanceof` | Left to Right |
| 7 | `==`, `!=` | Left to Right |
| 8 | `&` | Left to Right |
| 9 | `^` | Left to Right |
| 10 | `\|` | Left to Right |
| 11 | `&&` | Left to Right |
| 12 | `\|\|` | Left to Right |
| 13 | `? :` | Right to Left |
| 14 | `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `&=`, `^=`, `\|=`, `<<=`, `>>=`, `>>>=` | Right to Left |

### Examples of Precedence

```java
int result = 2 + 3 * 4;        // 14 (not 20)
int result2 = (2 + 3) * 4;     // 20

boolean result3 = 5 > 3 && 2 < 4;  // true
boolean result4 = 5 > 3 || 2 > 4;  // true

int a = 5, b = 3, c = 2;
int result5 = a + b * c;       // 11 (not 16)
int result6 = (a + b) * c;     // 16
```

## Operator Associativity

### Left-to-Right Associativity
```java
int result = 10 - 5 - 3;  // (10 - 5) - 3 = 2
int result2 = 10 / 2 / 2; // (10 / 2) / 2 = 2
```

### Right-to-Left Associativity
```java
int a = 5;
int b = 3;
int c = 2;
int result = a = b = c;  // a = (b = c) = 2

int d = 10;
int result2 = ++d + ++d;  // (++d) + (++d) = 12 + 13 = 25
```

## Type Conversion in Operations

### Widening Conversions (Automatic)
```java
byte b = 10;
short s = b;      // byte → short
int i = s;        // short → int
long l = i;       // int → long
float f = l;      // long → float
double d = f;     // float → double
```

### Narrowing Conversions (Explicit Cast Required)
```java
double d = 10.5;
float f = (float) d;  // double → float
long l = (long) f;    // float → long
int i = (int) l;      // long → int
short s = (short) i;  // int → short
byte b = (byte) s;    // short → byte
```

### Type Promotion in Expressions
```java
byte b = 10;
int i = 20;
long l = 30L;
float f = 40.0f;
double d = 50.0;

// Result type is determined by the widest operand
int result1 = b + i;      // int
long result2 = i + l;     // long
float result3 = l + f;    // float
double result4 = f + d;   // double
```

### Integer Division vs Floating-Point Division
```java
int a = 10;
int b = 3;
double result1 = a / b;       // 3.0 (integer division first, then conversion)
double result2 = (double) a / b;  // 3.333... (floating-point division)
```

## Common Pitfalls and Best Practices

### 1. Floating-Point Precision
```java
// Avoid direct equality comparison
double a = 0.1 + 0.2;
double b = 0.3;
System.out.println(a == b);  // false

// Use epsilon comparison
double epsilon = 0.0001;
System.out.println(Math.abs(a - b) < epsilon);  // true
```

### 2. Integer Overflow
```java
// Be careful with large numbers
int a = Integer.MAX_VALUE;
int b = a + 1;  // Overflow: becomes Integer.MIN_VALUE

// Use long for large calculations
long result = (long) a + 1;  // Correct
```

### 3. Short-Circuit Evaluation
```java
// Use short-circuit operators for efficiency
if (list != null && list.size() > 0) {
    // Safe and efficient
}

// Avoid non-short-circuit when not needed
if (list != null & list.size() > 0) {
    // Less efficient, may cause NullPointerException
}
```

### 4. Operator Precedence Confusion
```java
// Use parentheses for clarity
int result = (a + b) * c;  // Clear intent

// Avoid relying solely on precedence
int result2 = a + b * c;   // May be confusing
```

### 5. Increment/Decrement in Expressions
```java
// Avoid complex expressions with side effects
int a = 5;
int result = a++ + ++a;  // Hard to read and understand

// Prefer separate statements
int a = 5;
a++;
int temp = a;
a++;
int result = temp + a;
```

### 6. Type Conversion Issues
```java
// Be explicit about narrowing conversions
double d = 10.5;
int i = (int) d;  // Explicit cast

// Be careful with compound assignment
byte b = 10;
b += 1;  // OK: implicit cast
b = b + 1;  // Error: explicit cast needed
```

### 7. Null Pointer Safety
```java
// Always check for null before operations
String str = getString();
if (str != null && str.length() > 0) {
    // Safe operation
}
```

### 8. Bitwise Operations
```java
// Use bitwise operations for flags
int READ = 1;    // 001
int WRITE = 2;   // 010
int EXECUTE = 4; // 100

int permissions = READ | WRITE;  // 011 = 3
boolean canRead = (permissions & READ) != 0;  // true
```

## Practice Problems

### 1. Basic Arithmetic
```java
int a = 10, b = 3;
System.out.println(a / b);      // 3
System.out.println(a % b);      // 1
System.out.println((double) a / b);  // 3.333...
```

### 2. Bitwise Operations
```java
int num = 42;  // 101010 in binary
System.out.println(num << 1);   // 84 (1010100)
System.out.println(num >> 1);   // 21 (10101)
System.out.println(num & 1);    // 0 (check if even)
```

### 3. Logical Operations
```java
boolean x = true, y = false;
System.out.println(x && y);     // false
System.out.println(x || y);     // true
System.out.println(!x);         // false
System.out.println(x ^ y);      // true (XOR)
```

### 4. Conditional Operator
```java
int age = 18;
String status = (age >= 18) ? "Adult" : "Minor";
System.out.println(status);  // "Adult"
```

### 5. Operator Precedence
```java
int result = 2 + 3 * 4 - 1;  // 2 + 12 - 1 = 13
System.out.println(result);
```

## Summary

Java operators are fundamental building blocks for creating expressions and performing operations. Understanding their precedence, associativity, and behavior is crucial for writing correct and efficient code. Always use parentheses when in doubt about operator precedence, and be mindful of type conversions and potential pitfalls like floating-point precision issues and integer overflow.

Key takeaways:
1. **Precedence matters**: Use parentheses for clarity
2. **Short-circuit evaluation**: Use `&&` and `||` for efficiency
3. **Type safety**: Be explicit about narrowing conversions
4. **Null safety**: Always check for null before operations
5. **Readability**: Avoid complex expressions with side effects
6. **Bitwise operations**: Useful for flags and low-level operations
7. **Floating-point**: Use epsilon comparison for equality
8. **Overflow**: Be careful with large numbers and use appropriate types
