## Introduction

ThreadLocal provides thread-confined variables, while Virtual Threads (introduced in Java 19 as preview, stable in Java 21) revolutionize concurrent programming by enabling lightweight, high-throughput applications with millions of threads.

### 🎯 **What You'll Learn**
- **ThreadLocal**: Variables that are unique to each thread
- **Virtual Threads**: Revolutionary lightweight threads (Project Loom)
- **Platform vs Virtual**: Understanding the fundamental differences
- **Migration Strategy**: When and how to adopt virtual threads

### 💡 **Simple Analogy**
- **ThreadLocal** = Each worker has their own personal toolbox (not shared)
- **Platform Threads** = Traditional workers (expensive to hire, limited number)
- **Virtual Threads** = Magical workers that can multiply and work efficiently (millions possible)
- **Memory Usage** = Platform threads like full offices, Virtual threads like hot-desking

## ThreadLocal Fundamentals

### Basic ThreadLocal Usage

```java
public class ThreadLocalBasics {
    
    // Simple ThreadLocal
    private static final ThreadLocal<Integer> threadLocalValue = new ThreadLocal<Integer>() {
        @Override
        protected Integer initialValue() {
            return 0;
        }
    };
    
    // ThreadLocal with Supplier (Java 8+)
    private static final ThreadLocal<String> threadLocalString = 
        ThreadLocal.withInitial(() -> "Thread-" + Thread.currentThread().getId());
    
    public static void basicExample() {
        System.out.println("=== Basic ThreadLocal Example ===");
        
        Runnable task = () -> {
            String threadName = Thread.currentThread().getName();
            
            // Each thread has its own copy
            System.out.println(threadName + " initial value: " + threadLocalValue.get());
            System.out.println(threadName + " initial string: " + threadLocalString.get());
            
            // Modify thread-local values
            threadLocalValue.set(threadLocalValue.get() + 10);
            threadLocalString.set(threadLocalString.get() + "-modified");
            
            System.out.println(threadName + " modified value: " + threadLocalValue.get());
            System.out.println(threadName + " modified string: " + threadLocalString.get());
        };
        
        Thread thread1 = new Thread(task, "Thread-1");
        Thread thread2 = new Thread(task, "Thread-2");
        Thread thread3 = new Thread(task, "Thread-3");
        
        thread1.start();
        thread2.start();
        thread3.start();
        
        try {
            thread1.join();
            thread2.join();
            thread3.join();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
    
    public static void main(String[] args) {
        basicExample();
    }
}
```

### ThreadLocal Memory Leaks and Cleanup

```java
import java.lang.ref.WeakReference;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.TimeUnit;

public class ThreadLocalMemoryManagement {
    
    // Problematic ThreadLocal - can cause memory leaks
    private static final ThreadLocal<ExpensiveObject> problematicThreadLocal = new ThreadLocal<>();
    
    // Better ThreadLocal with cleanup
    private static final ThreadLocal<ExpensiveObject> managedThreadLocal = new ThreadLocal<ExpensiveObject>() {
        @Override
        protected ExpensiveObject initialValue() {
            return new ExpensiveObject("Managed-" + Thread.currentThread().getId());
        }
    };
    
    static class ExpensiveObject {
        private final String name;
        private final byte[] data = new byte[1024 * 1024]; // 1MB
        
        public ExpensiveObject(String name) {
            this.name = name;
            System.out.println("Created expensive object: " + name);
        }
        
        @Override
        protected void finalize() throws Throwable {
            System.out.println("Finalized expensive object: " + name);
            super.finalize();
        }
        
        public String getName() { return name; }
    }
    
    public static void demonstrateMemoryLeak() {
        System.out.println("=== Memory Leak Demonstration ===");
        
        ExecutorService executor = Executors.newFixedThreadPool(5);
        
        // Submit tasks that create ThreadLocal objects
        for (int i = 0; i < 10; i++) {
            final int taskId = i;
            executor.submit(() -> {
                // Create expensive object in ThreadLocal
                problematicThreadLocal.set(new ExpensiveObject("Problematic-" + taskId));
                
                // Use the object
                ExpensiveObject obj = problematicThreadLocal.get();
                System.out.println("Using object: " + obj.getName());
                
                // Simulate work
                try {
                    Thread.sleep(1000);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
                
                // NOTE: Not calling remove() - this can cause memory leaks!
                // problematicThreadLocal.remove(); // Uncomment to fix leak
            });
        }
        
        executor.shutdown();
        try {
            executor.awaitTermination(30, TimeUnit.SECONDS);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
        
        // Force garbage collection
        System.gc();
        
        try {
            Thread.sleep(2000);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
    
    public static void demonstrateProperCleanup() {
        System.out.println("\n=== Proper Cleanup Demonstration ===");
        
        ExecutorService executor = Executors.newFixedThreadPool(5);
        
        for (int i = 0; i < 10; i++) {
            final int taskId = i;
            executor.submit(() -> {
                try {
                    // Use ThreadLocal with proper cleanup
                    ExpensiveObject obj = managedThreadLocal.get();
                    System.out.println("Using managed object: " + obj.getName());
                    
                    // Simulate work
                    Thread.sleep(1000);
                    
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                } finally {
                    // Always clean up ThreadLocal
                    managedThreadLocal.remove();
                    System.out.println("Cleaned up ThreadLocal for task " + taskId);
                }
            });
        }
        
        executor.shutdown();
        try {
            executor.awaitTermination(30, TimeUnit.SECONDS);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
        
        System.gc();
        
        try {
            Thread.sleep(2000);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
    
    public static void main(String[] args) {
        demonstrateMemoryLeak();
        demonstrateProperCleanup();
    }
}
```

## ThreadLocal Patterns

### Request Context Pattern

```java
import java.util.UUID;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;

public class RequestContextPattern {
    
    // Request context stored in ThreadLocal
    static class RequestContext {
        private final String requestId;
        private final String userId;
        private final long startTime;
        
        public RequestContext(String requestId, String userId) {
            this.requestId = requestId;
            this.userId = userId;
            this.startTime = System.currentTimeMillis();
        }
        
        // Getters
        public String getRequestId() { return requestId; }
        public String getUserId() { return userId; }
        public long getStartTime() { return startTime; }
        public long getElapsedTime() { return System.currentTimeMillis() - startTime; }
        
        @Override
        public String toString() {
            return String.format("RequestContext{requestId='%s', userId='%s', elapsed=%dms}", 
                               requestId, userId, getElapsedTime());
        }
    }
    
    // ThreadLocal to store request context
    private static final ThreadLocal<RequestContext> REQUEST_CONTEXT = new ThreadLocal<>();
    
    // Utility methods for context management
    public static void setRequestContext(String requestId, String userId) {
        REQUEST_CONTEXT.set(new RequestContext(requestId, userId));
    }
    
    public static RequestContext getRequestContext() {
        return REQUEST_CONTEXT.get();
    }
    
    public static void clearRequestContext() {
        REQUEST_CONTEXT.remove();
    }
    
    // Service layers that use the context
    static class AuthenticationService {
        public boolean authenticate(String token) {
            RequestContext context = getRequestContext();
            System.out.println("Authenticating request: " + context.getRequestId());
            
            // Simulate authentication
            try {
                Thread.sleep(100);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
            
            return token.startsWith("valid_");
        }
    }
    
    static class BusinessService {
        public String processRequest(String data) {
            RequestContext context = getRequestContext();
            System.out.println("Processing business logic for user: " + context.getUserId() + 
                             " (request: " + context.getRequestId() + ")");
            
            // Simulate business processing
            try {
                Thread.sleep(500);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
            
            return "Processed: " + data;
        }
    }
    
    static class AuditService {
        public void logRequest() {
            RequestContext context = getRequestContext();
            System.out.println("AUDIT: " + context + " - Request completed");
        }
    }
    
    // Request processor that ties it all together
    static class RequestProcessor {
        private final AuthenticationService authService = new AuthenticationService();
        private final BusinessService businessService = new BusinessService();
        private final AuditService auditService = new AuditService();
        
        public void processRequest(String requestId, String userId, String token, String data) {
            try {
                // Set up request context
                setRequestContext(requestId, userId);
                
                // Process request through various services
                if (authService.authenticate(token)) {
                    String result = businessService.processRequest(data);
                    System.out.println("Request result: " + result);
                } else {
                    System.out.println("Authentication failed for request: " + requestId);
                }
                
                // Log the request
                auditService.logRequest();
                
            } finally {
                // Always clean up context
                clearRequestContext();
            }
        }
    }
    
    public static void main(String[] args) {
        RequestProcessor processor = new RequestProcessor();
        ExecutorService executor = Executors.newFixedThreadPool(3);
        
        // Simulate multiple concurrent requests
        for (int i = 1; i <= 5; i++) {
            final int requestNum = i;
            executor.submit(() -> {
                String requestId = "REQ-" + UUID.randomUUID().toString().substring(0, 8);
                String userId = "USER-" + requestNum;
                String token = (requestNum % 2 == 0) ? "valid_token_" + requestNum : "invalid_token_" + requestNum;
                String data = "data_" + requestNum;
                
                processor.processRequest(requestId, userId, token, data);
            });
        }
        
        executor.shutdown();
        try {
            executor.awaitTermination(10, TimeUnit.SECONDS);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
}
```

## Virtual Threads (Project Loom)

### Basic Virtual Thread Usage

```java
import java.util.concurrent.Executors;
import java.time.Duration;

public class VirtualThreadBasics {
    
    public static void basicVirtualThreads() {
        System.out.println("=== Basic Virtual Threads ===");
        
        // Create virtual thread directly
        Thread virtualThread = Thread.ofVirtual()
            .name("virtual-thread-1")
            .start(() -> {
                System.out.println("Virtual thread: " + Thread.currentThread());
                try {
                    Thread.sleep(1000);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
                System.out.println("Virtual thread completed");
            });
        
        // Create virtual thread with builder
        Thread.Builder virtualBuilder = Thread.ofVirtual().name("virtual-", 0);
        Thread virtualThread2 = virtualBuilder.start(() -> {
            System.out.println("Built virtual thread: " + Thread.currentThread());
        });
        
        try {
            virtualThread.join();
            virtualThread2.join();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
    
    public static void virtualThreadExecutor() {
        System.out.println("\n=== Virtual Thread Executor ===");
        
        // Create virtual thread executor
        try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
            
            // Submit many tasks
            for (int i = 0; i < 10; i++) {
                final int taskId = i;
                executor.submit(() -> {
                    System.out.println("Task " + taskId + " on " + Thread.currentThread());
                    try {
                        Thread.sleep(Duration.ofSeconds(1));
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                    }
                    System.out.println("Task " + taskId + " completed");
                });
            }
            
        } // Executor is automatically closed
        
        System.out.println("All virtual thread tasks completed");
    }
    
    public static void massiveVirtualThreads() {
        System.out.println("\n=== Massive Virtual Threads ===");
        
        long startTime = System.currentTimeMillis();
        
        try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
            
            // Create many virtual threads
            for (int i = 0; i < 10000; i++) {
                final int taskId = i;
                executor.submit(() -> {
                    try {
                        Thread.sleep(Duration.ofMillis(100));
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                    }
                    
                    if (taskId % 1000 == 0) {
                        System.out.println("Completed task " + taskId);
                    }
                });
            }
            
        }
        
        long endTime = System.currentTimeMillis();
        System.out.println("10,000 virtual threads completed in: " + (endTime - startTime) + "ms");
    }
    
    public static void main(String[] args) {
        basicVirtualThreads();
        virtualThreadExecutor();
        massiveVirtualThreads();
    }
}
```

### Performance Comparison

```java
import java.util.concurrent.*;
import java.time.Duration;
import java.util.concurrent.atomic.AtomicInteger;

public class ThreadPerformanceComparison {
    
    private static final int TASK_COUNT = 10000;
    private static final int SLEEP_DURATION_MS = 100;
    
    public static void comparePlatformThreads() {
        System.out.println("=== Platform Threads Performance ===");
        
        long startTime = System.currentTimeMillis();
        AtomicInteger completedTasks = new AtomicInteger(0);
        
        // Use cached thread pool for platform threads
        ExecutorService executor = Executors.newCachedThreadPool();
        
        try {
            for (int i = 0; i < TASK_COUNT; i++) {
                final int taskId = i;
                executor.submit(() -> {
                    try {
                        Thread.sleep(SLEEP_DURATION_MS);
                        int completed = completedTasks.incrementAndGet();
                        
                        if (completed % 1000 == 0) {
                            System.out.println("Platform threads - Completed: " + completed);
                        }
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                    }
                });
            }
            
            executor.shutdown();
            executor.awaitTermination(60, TimeUnit.SECONDS);
            
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
        
        long endTime = System.currentTimeMillis();
        System.out.println("Platform threads - Total time: " + (endTime - startTime) + "ms");
        System.out.println("Platform threads - Completed tasks: " + completedTasks.get());
    }
    
    public static void compareVirtualThreads() {
        System.out.println("\n=== Virtual Threads Performance ===");
        
        long startTime = System.currentTimeMillis();
        AtomicInteger completedTasks = new AtomicInteger(0);
        
        try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
            
            for (int i = 0; i < TASK_COUNT; i++) {
                final int taskId = i;
                executor.submit(() -> {
                    try {
                        Thread.sleep(Duration.ofMillis(SLEEP_DURATION_MS));
                        int completed = completedTasks.incrementAndGet();
                        
                        if (completed % 1000 == 0) {
                            System.out.println("Virtual threads - Completed: " + completed);
                        }
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                    }
                });
            }
            
        }
        
        long endTime = System.currentTimeMillis();
        System.out.println("Virtual threads - Total time: " + (endTime - startTime) + "ms");
        System.out.println("Virtual threads - Completed tasks: " + completedTasks.get());
    }
    
    public static void memoryUsageComparison() {
        System.out.println("\n=== Memory Usage Comparison ===");
        
        Runtime runtime = Runtime.getRuntime();
        
        // Measure baseline memory
        System.gc();
        long baselineMemory = runtime.totalMemory() - runtime.freeMemory();
        
        // Test platform threads
        System.out.println("Testing platform threads memory usage...");
        ExecutorService platformExecutor = Executors.newFixedThreadPool(1000);
        
        for (int i = 0; i < 1000; i++) {
            platformExecutor.submit(() -> {
                try {
                    Thread.sleep(10000); // Keep threads alive
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            });
        }
        
        System.gc();
        long platformMemory = runtime.totalMemory() - runtime.freeMemory();
        
        platformExecutor.shutdownNow();
        
        // Wait for cleanup
        try {
            Thread.sleep(2000);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
        
        // Test virtual threads
        System.out.println("Testing virtual threads memory usage...");
        
        Thread[] virtualThreads = new Thread[1000];
        for (int i = 0; i < 1000; i++) {
            virtualThreads[i] = Thread.ofVirtual().start(() -> {
                try {
                    Thread.sleep(10000); // Keep threads alive
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            });
        }
        
        System.gc();
        long virtualMemory = runtime.totalMemory() - runtime.freeMemory();
        
        // Cleanup virtual threads
        for (Thread vt : virtualThreads) {
            vt.interrupt();
        }
        
        System.out.println("Baseline memory: " + (baselineMemory / 1024 / 1024) + " MB");
        System.out.println("Platform threads memory: " + (platformMemory / 1024 / 1024) + " MB");
        System.out.println("Virtual threads memory: " + (virtualMemory / 1024 / 1024) + " MB");
        
        System.out.println("Platform threads overhead: " + 
                          ((platformMemory - baselineMemory) / 1024 / 1024) + " MB");
        System.out.println("Virtual threads overhead: " + 
                          ((virtualMemory - baselineMemory) / 1024 / 1024) + " MB");
    }
    
    public static void main(String[] args) {
        comparePlatformThreads();
        compareVirtualThreads();
        memoryUsageComparison();
    }
}
```

## Real-Life Examples

### 1. Web Server with Virtual Threads

```java
import java.io.*;
import java.net.*;
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicLong;

public class VirtualThreadWebServer {
    
    private final int port;
    private final AtomicLong requestCounter = new AtomicLong(0);
    private volatile boolean running = true;
    
    public VirtualThreadWebServer(int port) {
        this.port = port;
    }
    
    public void start() {
        try (ServerSocket serverSocket = new ServerSocket(port)) {
            System.out.println("Virtual Thread Web Server started on port " + port);
            
            // Use virtual thread executor for handling requests
            try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
                
                while (running) {
                    try {
                        Socket clientSocket = serverSocket.accept();
                        
                        // Handle each request in a virtual thread
                        executor.submit(() -> handleRequest(clientSocket));
                        
                    } catch (IOException e) {
                        if (running) {
                            System.err.println("Error accepting connection: " + e.getMessage());
                        }
                    }
                }
            }
            
        } catch (IOException e) {
            System.err.println("Server error: " + e.getMessage());
        }
    }
    
    private void handleRequest(Socket clientSocket) {
        long requestId = requestCounter.incrementAndGet();
        
        try (BufferedReader in = new BufferedReader(new InputStreamReader(clientSocket.getInputStream()));
             PrintWriter out = new PrintWriter(clientSocket.getOutputStream(), true)) {
            
            System.out.println("Request " + requestId + " handled by: " + Thread.currentThread());
            
            // Read HTTP request
            String requestLine = in.readLine();
            if (requestLine == null) return;
            
            String[] parts = requestLine.split(" ");
            String method = parts[0];
            String path = parts[1];
            
            // Skip headers
            String line;
            while ((line = in.readLine()) != null && !line.isEmpty()) {
                // Skip headers
            }
            
            // Simulate processing time (I/O bound operation)
            try {
                Thread.sleep(100 + (int)(Math.random() * 200)); // 100-300ms
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                return;
            }
            
            // Generate response
            String response = generateResponse(method, path, requestId);
            
            // Send HTTP response
            out.println("HTTP/1.1 200 OK");
            out.println("Content-Type: text/html");
            out.println("Content-Length: " + response.length());
            out.println();
            out.println(response);
            
            System.out.println("Request " + requestId + " completed");
            
        } catch (IOException e) {
            System.err.println("Error handling request " + requestId + ": " + e.getMessage());
        } finally {
            try {
                clientSocket.close();
            } catch (IOException e) {
                System.err.println("Error closing socket: " + e.getMessage());
            }
        }
    }
    
    private String generateResponse(String method, String path, long requestId) {
        return String.format("""
            <html>
            <head><title>Virtual Thread Server</title></head>
            <body>
                <h1>Hello from Virtual Thread Server!</h1>
                <p>Request ID: %d</p>
                <p>Method: %s</p>
                <p>Path: %s</p>
                <p>Thread: %s</p>
                <p>Time: %s</p>
            </body>
            </html>
            """, requestId, method, path, Thread.currentThread(), java.time.LocalDateTime.now());
    }
    
    public void stop() {
        running = false;
    }
    
    // Load testing client
    static class LoadTestClient {
        public static void testServer(String host, int port, int requestCount, int concurrency) {
            System.out.println("Starting load test: " + requestCount + " requests with " + 
                             concurrency + " concurrent connections");
            
            long startTime = System.currentTimeMillis();
            AtomicLong completedRequests = new AtomicLong(0);
            
            try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
                
                for (int i = 0; i < requestCount; i++) {
                    executor.submit(() -> {
                        try (Socket socket = new Socket(host, port);
                             PrintWriter out = new PrintWriter(socket.getOutputStream(), true);
                             BufferedReader in = new BufferedReader(new InputStreamReader(socket.getInputStream()))) {
                            
                            // Send HTTP GET request
                            out.println("GET / HTTP/1.1");
                            out.println("Host: " + host);
                            out.println();
                            
                            // Read response
                            String line;
                            while ((line = in.readLine()) != null) {
                                if (line.isEmpty()) break; // End of headers
                            }
                            
                            // Skip response body
                            while ((line = in.readLine()) != null) {
                                // Read body
                            }
                            
                            long completed = completedRequests.incrementAndGet();
                            if (completed % 100 == 0) {
                                System.out.println("Completed requests: " + completed);
                            }
                            
                        } catch (IOException e) {
                            System.err.println("Client error: " + e.getMessage());
                        }
                    });
                }
                
            }
            
            long endTime = System.currentTimeMillis();
            long duration = endTime - startTime;
            
            System.out.println("Load test completed:");
            System.out.println("  Total requests: " + completedRequests.get());
            System.out.println("  Duration: " + duration + "ms");
            System.out.println("  Requests/sec: " + (completedRequests.get() * 1000 / duration));
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        VirtualThreadWebServer server = new VirtualThreadWebServer(8080);
        
        // Start server in a separate thread
        Thread serverThread = Thread.ofPlatform().start(server::start);
        
        // Wait for server to start
        Thread.sleep(2000);
        
        // Run load test
        LoadTestClient.testServer("localhost", 8080, 1000, 100);
        
        // Stop server
        server.stop();
        serverThread.interrupt();
    }
}
```

### Problem: ThreadLocal with Virtual Thread Pool

```java
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicInteger;

public class ThreadLocalVirtualThreadProblem {
    
    // ThreadLocal that might not work as expected with virtual threads
    private static final ThreadLocal<UserSession> sessionThreadLocal = new ThreadLocal<>();
    
    // Alternative: Use scoped values (Java 20+ preview feature)
    // This is conceptual - actual implementation may vary
    static class ScopedValueExample {
        // Scoped values are designed to work better with virtual threads
        // private static final ScopedValue<UserSession> SESSION_SCOPE = ScopedValue.newInstance();
    }
    
    static class UserSession {
        private final String userId;
        private final String sessionId;
        private final AtomicInteger requestCount = new AtomicInteger(0);
        
        public UserSession(String userId, String sessionId) {
            this.userId = userId;
            this.sessionId = sessionId;
        }
        
        public void incrementRequests() {
            requestCount.incrementAndGet();
        }
        
        public String getUserId() { return userId; }
        public String getSessionId() { return sessionId; }
        public int getRequestCount() { return requestCount.get(); }
        
        @Override
        public String toString() {
            return String.format("UserSession{userId='%s', sessionId='%s', requests=%d}", 
                               userId, sessionId, requestCount.get());
        }
    }
    
    static class RequestProcessor {
        
        public void processWithPlatformThreads() {
            System.out.println("=== Processing with Platform Threads ===");
            
            ExecutorService executor = Executors.newFixedThreadPool(5);
            
            for (int i = 0; i < 10; i++) {
                final int userId = i % 3; // Simulate 3 users
                
                executor.submit(() -> {
                    // Set up session in ThreadLocal
                    UserSession session = new UserSession("user" + userId, "session-" + userId);
                    sessionThreadLocal.set(session);
                    
                    try {
                        // Process multiple requests in same thread
                        for (int j = 0; j < 3; j++) {
                            processRequest("request-" + j);
                            Thread.sleep(100);
                        }
                        
                        // Print final session state
                        System.out.println("Platform thread final session: " + sessionThreadLocal.get());
                        
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                    } finally {
                        sessionThreadLocal.remove();
                    }
                });
            }
            
            executor.shutdown();
            try {
                executor.awaitTermination(10, TimeUnit.SECONDS);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
        
        public void processWithVirtualThreads() {
            System.out.println("\n=== Processing with Virtual Threads ===");
            
            try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
                
                for (int i = 0; i < 10; i++) {
                    final int userId = i % 3; // Simulate 3 users
                    
                    executor.submit(() -> {
                        // Set up session in ThreadLocal
                        UserSession session = new UserSession("user" + userId, "vsession-" + userId);
                        sessionThreadLocal.set(session);
                        
                        try {
                            // Process multiple requests in same virtual thread
                            for (int j = 0; j < 3; j++) {
                                processRequest("vrequest-" + j);
                                Thread.sleep(100); // This may cause thread to be unmounted/remounted
                            }
                            
                            // Check if session is still there
                            UserSession finalSession = sessionThreadLocal.get();
                            if (finalSession != null) {
                                System.out.println("Virtual thread final session: " + finalSession);
                            } else {
                                System.out.println("Virtual thread session lost!");
                            }
                            
                        } catch (InterruptedException e) {
                            Thread.currentThread().interrupt();
                        } finally {
                            sessionThreadLocal.remove();
                        }
                    });
                }
                
            }
        }
        
        private void processRequest(String requestId) {
            UserSession session = sessionThreadLocal.get();
            if (session != null) {
                session.incrementRequests();
                System.out.println("Processing " + requestId + " for " + session.getUserId() + 
                                 " on " + Thread.currentThread());
            } else {
                System.out.println("No session found for " + requestId + 
                                 " on " + Thread.currentThread());
            }
        }
    }
    
    // Alternative approach: Explicit context passing
    static class ExplicitContextProcessor {
        
        public void processWithExplicitContext() {
            System.out.println("\n=== Processing with Explicit Context ===");
            
            try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
                
                for (int i = 0; i < 10; i++) {
                    final int userId = i % 3;
                    final UserSession session = new UserSession("user" + userId, "explicit-" + userId);
                    
                    executor.submit(() -> {
                        try {
                            for (int j = 0; j < 3; j++) {
                                processRequestWithContext(session, "explicit-request-" + j);
                                Thread.sleep(100);
                            }
                            
                            System.out.println("Explicit context final session: " + session);
                            
                        } catch (InterruptedException e) {
                            Thread.currentThread().interrupt();
                        }
                    });
                }
                
            }
        }
        
        private void processRequestWithContext(UserSession session, String requestId) {
            session.incrementRequests();
            System.out.println("Processing " + requestId + " for " + session.getUserId() + 
                             " on " + Thread.currentThread());
        }
    }
    
    public static void main(String[] args) {
        RequestProcessor processor = new RequestProcessor();
        ExplicitContextProcessor explicitProcessor = new ExplicitContextProcessor();
        
        processor.processWithPlatformThreads();
        processor.processWithVirtualThreads();
        explicitProcessor.processWithExplicitContext();
    }
```

## Key Takeaways

1. **ThreadLocal Usage**: Ideal for request context, database connections, and thread-specific state, but requires careful cleanup to prevent memory leaks.

2. **Virtual Thread Benefits**: Enable massive concurrency (millions of threads), lower memory footprint, and simplified concurrent programming model.

3. **Virtual Thread Limitations**: Not suitable for CPU-intensive tasks, ThreadLocal behavior may differ, and requires Java 19+ (preview) or Java 21+ (stable).

4. **ThreadLocal vs Scoped Values**: Scoped values (Java 20+) are designed to work better with virtual threads and structured concurrency.

5. **Migration Strategy**: Gradually adopt virtual threads for I/O-bound workloads while keeping platform threads for CPU-intensive tasks.

6. **Performance Considerations**: Virtual threads excel in I/O-heavy applications but may not improve CPU-bound performance.

This comprehensive guide covers ThreadLocal usage patterns and the revolutionary Virtual Threads feature, providing both theoretical understanding and practical implementation examples for modern concurrent Java applications.
