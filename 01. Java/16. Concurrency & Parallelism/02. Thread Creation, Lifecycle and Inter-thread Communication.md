## Introduction

Thread management is fundamental to concurrent programming in Java. This document explores the various ways to create threads, their lifecycle states, and mechanisms for inter-thread communication.

### 🎯 **What You'll Learn**
- **Thread Creation**: Different ways to create and start threads in Java
- **Thread Lifecycle**: How threads transition between different states (NEW, RUNNABLE, BLOCKED, etc.)
- **Inter-thread Communication**: How threads can coordinate and communicate with each other
- **Best Practices**: When to use which approach and common pitfalls to avoid

### 💡 **Simple Analogy**
Think of threads like **workers in a restaurant**:
- **Creating threads** = Hiring workers (different ways to hire: full-time, part-time, contractors)
- **Thread lifecycle** = Worker states (available, working, on break, finished shift)
- **Communication** = Workers coordinating (chef tells waiter when food is ready)

## Thread Creation Methods

**🛠️ Overview**: Java provides several ways to create threads, each with its own use cases and benefits.

### 1. Extending Thread Class

**🎯 When to Use**: When you need full control over thread behavior and don't need to extend another class.
**⚠️ Limitation**: Java single inheritance - you can't extend another class if you extend Thread.

```java
public class MyThread extends Thread {
    private String threadName;
    
    public MyThread(String name) {
        this.threadName = name;
    }
    
    @Override
    public void run() {
        System.out.println("Thread " + threadName + " is running");
        for (int i = 0; i < 5; i++) {
            System.out.println(threadName + ": " + i);
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                System.out.println(threadName + " interrupted");
                Thread.currentThread().interrupt();
                return;
            }
        }
        System.out.println(threadName + " finished");
    }
}

// Usage
public class ThreadExample {
    public static void main(String[] args) {
        MyThread thread1 = new MyThread("Thread-1");
        MyThread thread2 = new MyThread("Thread-2");
        
        thread1.start();
        thread2.start();
    }
}
```

### 2. Implementing Runnable Interface

**🎯 When to Use**: Preferred approach - allows your class to extend another class and promotes better design.
**✅ Benefits**: Better separation of concerns, more flexible design.

### 4. Using Callable and Future

```java
import java.util.concurrent.*;

public class CallableExample {
    static class NumberCalculator implements Callable<Integer> {
        private int number;
        
        public NumberCalculator(int number) {
            this.number = number;
        }
        
        @Override
        public Integer call() throws Exception {
            System.out.println("Calculating factorial of " + number + 
                             " in thread: " + Thread.currentThread().getName());
            
            int result = 1;
            for (int i = 1; i <= number; i++) {
                result *= i;
                Thread.sleep(100); // Simulate work
            }
            
            return result;
        }
    }
    
    public static void main(String[] args) {
        ExecutorService executor = Executors.newFixedThreadPool(2);
        
        try {
            // Submit callable tasks
            Future<Integer> future1 = executor.submit(new NumberCalculator(5));
            Future<Integer> future2 = executor.submit(new NumberCalculator(7));
            
            // Get results
            System.out.println("Factorial of 5: " + future1.get());
            System.out.println("Factorial of 7: " + future2.get());
            
        } catch (InterruptedException | ExecutionException e) {
            e.printStackTrace();
        } finally {
            executor.shutdown();
        }
    }
}
```

### 5. Using Thread Factory

```java
public class CustomThreadFactory implements ThreadFactory {
    private int threadCount = 0;
    private String namePrefix;
    
    public CustomThreadFactory(String namePrefix) {
        this.namePrefix = namePrefix;
    }
    
    @Override
    public Thread newThread(Runnable r) {
        Thread thread = new Thread(r, namePrefix + "-" + (++threadCount));
        thread.setDaemon(false);
        thread.setPriority(Thread.NORM_PRIORITY);
        
        // Add uncaught exception handler
        thread.setUncaughtExceptionHandler((t, e) -> {
            System.err.println("Thread " + t.getName() + " threw exception: " + e.getMessage());
            e.printStackTrace();
        });
        
        return thread;
    }
}
```

## Thread Lifecycle

**🔄 Understanding Thread States**: Threads go through different states during their lifetime, like employees during a workday.

**📊 Thread State Diagram**:
```
NEW → RUNNABLE ⇄ BLOCKED
  ↓       ↓        ↓
TERMINATED ← WAITING/TIMED_WAITING
```

**🏢 Office Worker Analogy**:
- **NEW**: Employee hired but hasn't started work yet
- **RUNNABLE**: Employee is working or ready to work  
- **BLOCKED**: Employee waiting for meeting room (resource)
- **WAITING**: Employee waiting for colleague indefinitely
- **TIMED_WAITING**: Employee on scheduled lunch break
- **TERMINATED**: Employee finished work and left

### Thread States

```java
public class ThreadLifecycleDemo {
    public static void main(String[] args) throws InterruptedException {
        Object lock = new Object();
        
        Thread thread = new Thread(() -> {
            synchronized (lock) {
                System.out.println("Thread acquired lock, state: RUNNABLE");
                try {
                    lock.wait(); // Thread goes to WAITING state
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            }
        });
        
        // NEW state
        System.out.println("1. Thread state: " + thread.getState()); // NEW
        
        thread.start();
        Thread.sleep(100);
        
        // RUNNABLE state (or could be WAITING if already reached wait())
        System.out.println("2. Thread state: " + thread.getState());
        
        Thread.sleep(500);
        // WAITING state
        System.out.println("3. Thread state: " + thread.getState()); // WAITING
        
        // Wake up the waiting thread
        synchronized (lock) {
            lock.notify();
        }
        
        thread.join(); // Wait for thread to complete
        
        // TERMINATED state
        System.out.println("4. Thread state: " + thread.getState()); // TERMINATED
    }
}
```

### Detailed State Transitions

```java
public class ThreadStateTransitions {
    private static final Object lock1 = new Object();
    private static final Object lock2 = new Object();
    
    public static void main(String[] args) throws InterruptedException {
        // Demonstrate BLOCKED state
        Thread blockedThread = new Thread(() -> {
            synchronized (lock1) {
                System.out.println("BlockedThread acquired lock1");
                synchronized (lock2) {
                    System.out.println("BlockedThread acquired lock2");
                }
            }
        }, "BlockedThread");
        
        Thread blockingThread = new Thread(() -> {
            synchronized (lock2) {
                System.out.println("BlockingThread acquired lock2");
                try {
                    Thread.sleep(3000); // Hold lock for 3 seconds
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
                synchronized (lock1) {
                    System.out.println("BlockingThread acquired lock1");
                }
            }
        }, "BlockingThread");
        
        // Demonstrate TIMED_WAITING state
        Thread timedWaitingThread = new Thread(() -> {
            try {
                Thread.sleep(2000); // TIMED_WAITING state
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }, "TimedWaitingThread");
        
        // Start threads
        blockingThread.start();
        Thread.sleep(100);
        blockedThread.start();
        timedWaitingThread.start();
        
        // Monitor thread states
        for (int i = 0; i < 40; i++) {
            System.out.println("Iteration " + i + ":");
            System.out.println("  BlockedThread: " + blockedThread.getState());
            System.out.println("  BlockingThread: " + blockingThread.getState());
            System.out.println("  TimedWaitingThread: " + timedWaitingThread.getState());
            System.out.println();
            
            Thread.sleep(100);
        }
        
        // Wait for all threads to complete
        blockedThread.join();
        blockingThread.join();
        timedWaitingThread.join();
    }
}
```

## Inter-thread Communication

### 1. Wait-Notify Mechanism

```java
public class WaitNotifyExample {
    private static final Object lock = new Object();
    private static boolean dataReady = false;
    private static String sharedData;
    
    static class Producer implements Runnable {
        @Override
        public void run() {
            synchronized (lock) {
                System.out.println("Producer: Preparing data...");
                try {
                    Thread.sleep(2000); // Simulate data preparation
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    return;
                }
                
                sharedData = "Important Data from Producer";
                dataReady = true;
                
                System.out.println("Producer: Data ready, notifying consumers");
                lock.notifyAll(); // Notify all waiting threads
            }
        }
    }
    
    static class Consumer implements Runnable {
        private String name;
        
        public Consumer(String name) {
            this.name = name;
        }
        
        @Override
        public void run() {
            synchronized (lock) {
                System.out.println(name + ": Waiting for data...");
                
                while (!dataReady) {
                    try {
                        lock.wait(); // Release lock and wait
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        return;
                    }
                }
                
                System.out.println(name + ": Received data: " + sharedData);
            }
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        Thread producer = new Thread(new Producer(), "Producer");
        Thread consumer1 = new Thread(new Consumer("Consumer-1"));
        Thread consumer2 = new Thread(new Consumer("Consumer-2"));
        
        // Start consumers first
        consumer1.start();
        consumer2.start();
        
        Thread.sleep(1000);
        
        // Start producer
        producer.start();
        
        // Wait for all threads to complete
        producer.join();
        consumer1.join();
        consumer2.join();
    }
}
```

### 2. BlockingQueue Communication

```java
import java.util.concurrent.*;

public class BlockingQueueCommunication {
    private static final BlockingQueue<String> queue = new ArrayBlockingQueue<>(10);
    
    static class Producer implements Runnable {
        @Override
        public void run() {
            try {
                for (int i = 1; i <= 5; i++) {
                    String message = "Message-" + i;
                    queue.put(message); // Blocks if queue is full
                    System.out.println("Producer sent: " + message);
                    Thread.sleep(1000);
                }
                
                queue.put("STOP"); // Signal to stop consumers
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
    }
    
    static class Consumer implements Runnable {
        private String name;
        
        public Consumer(String name) {
            this.name = name;
        }
        
        @Override
        public void run() {
            try {
                while (true) {
                    String message = queue.take(); // Blocks if queue is empty
                    
                    if ("STOP".equals(message)) {
                        queue.put(message); // Put it back for other consumers
                        break;
                    }
                    
                    System.out.println(name + " received: " + message);
                    Thread.sleep(1500);
                }
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        Thread producer = new Thread(new Producer());
        Thread consumer1 = new Thread(new Consumer("Consumer-1"));
        Thread consumer2 = new Thread(new Consumer("Consumer-2"));
        
        producer.start();
        consumer1.start();
        consumer2.start();
        
        producer.join();
        consumer1.join();
        consumer2.join();
    }
}
```

### 3. CountDownLatch Communication

```java
import java.util.concurrent.CountDownLatch;

public class CountDownLatchExample {
    private static final int WORKER_COUNT = 3;
    private static final CountDownLatch startSignal = new CountDownLatch(1);
    private static final CountDownLatch doneSignal = new CountDownLatch(WORKER_COUNT);
    
    static class Worker implements Runnable {
        private int workerId;
        
        public Worker(int workerId) {
            this.workerId = workerId;
        }
        
        @Override
        public void run() {
            try {
                System.out.println("Worker " + workerId + " waiting for start signal");
                startSignal.await(); // Wait for start signal
                
                System.out.println("Worker " + workerId + " started working");
                
                // Simulate work
                Thread.sleep((long) (Math.random() * 3000 + 1000));
                
                System.out.println("Worker " + workerId + " finished work");
                doneSignal.countDown(); // Signal completion
                
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        // Start all workers
        for (int i = 1; i <= WORKER_COUNT; i++) {
            new Thread(new Worker(i)).start();
        }
        
        System.out.println("Main thread preparing...");
        Thread.sleep(2000);
        
        System.out.println("Main thread giving start signal");
        startSignal.countDown(); // Release all workers
        
        System.out.println("Main thread waiting for all workers to complete");
        doneSignal.await(); // Wait for all workers to complete
        
        System.out.println("All workers completed, main thread continuing");
    }
}
```

### 4. CyclicBarrier Communication

```java
import java.util.concurrent.CyclicBarrier;
import java.util.concurrent.BrokenBarrierException;

public class CyclicBarrierExample {
    private static final int THREAD_COUNT = 4;
    private static final CyclicBarrier barrier = new CyclicBarrier(THREAD_COUNT, () -> {
        System.out.println("*** All threads reached barrier, barrier action executed ***");
    });
    
    static class Task implements Runnable {
        private int taskId;
        
        public Task(int taskId) {
            this.taskId = taskId;
        }
        
        @Override
        public void run() {
            try {
                for (int phase = 1; phase <= 3; phase++) {
                    System.out.println("Task " + taskId + " working on phase " + phase);
                    
                    // Simulate work
                    Thread.sleep((long) (Math.random() * 2000 + 1000));
                    
                    System.out.println("Task " + taskId + " completed phase " + phase + 
                                     ", waiting at barrier");
                    
                    barrier.await(); // Wait for all threads to reach this point
                    
                    System.out.println("Task " + taskId + " proceeding after barrier");
                }
            } catch (InterruptedException | BrokenBarrierException e) {
                Thread.currentThread().interrupt();
                System.err.println("Task " + taskId + " interrupted: " + e.getMessage());
            }
        }
    }
    
    public static void main(String[] args) {
        System.out.println("Starting " + THREAD_COUNT + " tasks");
        
        for (int i = 1; i <= THREAD_COUNT; i++) {
            new Thread(new Task(i)).start();
        }
    }
}
```

### 5. Semaphore Communication

```java
import java.util.concurrent.Semaphore;

public class SemaphoreExample {
    private static final Semaphore semaphore = new Semaphore(2); // Allow 2 concurrent accesses
    
    static class Resource {
        private static int resourceId = 0;
        
        public static void access(String threadName) {
            try {
                System.out.println(threadName + " requesting access to resource");
                semaphore.acquire(); // Acquire permit
                
                int currentResourceId = ++resourceId;
                System.out.println(threadName + " acquired resource " + currentResourceId);
                
                // Simulate resource usage
                Thread.sleep(3000);
                
                System.out.println(threadName + " releasing resource " + currentResourceId);
                
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            } finally {
                semaphore.release(); // Release permit
            }
        }
    }
    
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            final String threadName = "Thread-" + i;
            new Thread(() -> Resource.access(threadName)).start();
        }
    }
}
```

## Advantages and Disadvantages

### Thread Creation Methods Comparison

| Method | Advantages | Disadvantages |
|--------|------------|---------------|
| **Extending Thread** | Simple, direct access to thread methods | Single inheritance limitation, tight coupling |
| **Implementing Runnable** | Better design, supports multiple inheritance | Requires Thread wrapper, no direct thread control |
| **Lambda Expressions** | Concise, functional programming style | Limited to simple tasks, less readable for complex logic |
| **Callable/Future** | Returns results, exception handling | More complex, requires ExecutorService |
| **Thread Factory** | Customizable thread creation, centralized configuration | Additional complexity, overhead |

### Inter-thread Communication Methods

| Method | Advantages | Disadvantages |
|--------|------------|---------------|
| **Wait/Notify** | Low-level control, efficient | Complex, error-prone, requires synchronization |
| **BlockingQueue** | Thread-safe, easy to use | May cause blocking, memory overhead |
| **CountDownLatch** | One-time coordination, simple | Single-use only, cannot be reset |
| **CyclicBarrier** | Reusable, supports barrier action | All threads must reach barrier |
| **Semaphore** | Controls concurrent access | Can lead to starvation, complex permit management |

### 1. Web Crawler with Thread Pool

```java
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicInteger;
import java.net.URL;
import java.io.BufferedReader;
import java.io.InputStreamReader;

public class WebCrawler {
    private final ExecutorService executor;
    private final BlockingQueue<String> urlQueue;
    private final ConcurrentHashMap<String, Boolean> visitedUrls;
    private final AtomicInteger activeWorkers;
    private final int maxWorkers;
    
    public WebCrawler(int maxWorkers) {
        this.maxWorkers = maxWorkers;
        this.executor = Executors.newFixedThreadPool(maxWorkers);
        this.urlQueue = new LinkedBlockingQueue<>();
        this.visitedUrls = new ConcurrentHashMap<>();
        this.activeWorkers = new AtomicInteger(0);
    }
    
    class CrawlerWorker implements Runnable {
        @Override
        public void run() {
            while (true) {
                try {
                    String url = urlQueue.poll(5, TimeUnit.SECONDS);
                    if (url == null) {
                        if (activeWorkers.get() == 0) {
                            break; // No more work and no active workers
                        }
                        continue;
                    }
                    
                    if (visitedUrls.putIfAbsent(url, true) != null) {
                        continue; // Already visited
                    }
                    
                    activeWorkers.incrementAndGet();
                    crawlPage(url);
                    activeWorkers.decrementAndGet();
                    
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    break;
                }
            }
        }
        
        private void crawlPage(String urlString) {
            try {
                System.out.println("Crawling: " + urlString + " by " + 
                                 Thread.currentThread().getName());
                
                URL url = new URL(urlString);
                BufferedReader reader = new BufferedReader(
                    new InputStreamReader(url.openStream()));
                
                String line;
                while ((line = reader.readLine()) != null) {
                    // Extract URLs (simplified)
                    if (line.contains("href=\"http")) {
                        // Add found URLs to queue (simplified extraction)
                        // urlQueue.offer(extractedUrl);
                    }
                }
                reader.close();
                
                // Simulate processing time
                Thread.sleep(1000);
                
            } catch (Exception e) {
                System.err.println("Error crawling " + urlString + ": " + e.getMessage());
            }
        }
    }
    
    public void startCrawling(String startUrl) {
        urlQueue.offer(startUrl);
        
        for (int i = 0; i < maxWorkers; i++) {
            executor.submit(new CrawlerWorker());
        }
        
        executor.shutdown();
        try {
            executor.awaitTermination(1, TimeUnit.HOURS);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
        
        System.out.println("Crawling completed. Total URLs processed: " + visitedUrls.size());
    }
    
    public static void main(String[] args) {
        WebCrawler crawler = new WebCrawler(5);
        crawler.startCrawling("http://example.com");
    }
}
```

### 2. Bank Transaction System

```java
import java.util.concurrent.locks.ReentrantLock;
import java.util.concurrent.atomic.AtomicLong;

public class BankTransactionSystem {
    static class BankAccount {
        private final String accountId;
        private volatile double balance;
        private final ReentrantLock lock = new ReentrantLock();
        private static final AtomicLong transactionCounter = new AtomicLong(0);
        
        public BankAccount(String accountId, double initialBalance) {
            this.accountId = accountId;
            this.balance = initialBalance;
        }
        
        public boolean withdraw(double amount) {
            lock.lock();
            try {
                if (balance >= amount) {
                    System.out.println("Withdrawing " + amount + " from " + accountId + 
                                     " by " + Thread.currentThread().getName());
                    
                    // Simulate processing time
                    Thread.sleep(100);
                    
                    balance -= amount;
                    System.out.println("Withdrawal successful. New balance: " + balance);
                    return true;
                } else {
                    System.out.println("Insufficient funds in " + accountId + 
                                     " for withdrawal of " + amount);
                    return false;
                }
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                return false;
            } finally {
                lock.unlock();
            }
        }
        
        public void deposit(double amount) {
            lock.lock();
            try {
                System.out.println("Depositing " + amount + " to " + accountId + 
                                 " by " + Thread.currentThread().getName());
                
                // Simulate processing time
                Thread.sleep(100);
                
                balance += amount;
                System.out.println("Deposit successful. New balance: " + balance);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            } finally {
                lock.unlock();
            }
        }
        
        public double getBalance() {
            lock.lock();
            try {
                return balance;
            } finally {
                lock.unlock();
            }
        }
        
        public static boolean transfer(BankAccount from, BankAccount to, double amount) {
            long transactionId = transactionCounter.incrementAndGet();
            System.out.println("Starting transfer #" + transactionId + ": " + amount + 
                             " from " + from.accountId + " to " + to.accountId);
            
            // Always acquire locks in the same order to prevent deadlock
            BankAccount firstLock = from.accountId.compareTo(to.accountId) < 0 ? from : to;
            BankAccount secondLock = from.accountId.compareTo(to.accountId) < 0 ? to : from;
            
            firstLock.lock.lock();
            try {
                secondLock.lock.lock();
                try {
                    if (from.balance >= amount) {
                        from.balance -= amount;
                        to.balance += amount;
                        
                        System.out.println("Transfer #" + transactionId + " completed successfully");
                        System.out.println(from.accountId + " balance: " + from.balance);
                        System.out.println(to.accountId + " balance: " + to.balance);
                        return true;
                    } else {
                        System.out.println("Transfer #" + transactionId + " failed: insufficient funds");
                        return false;
                    }
                } finally {
                    secondLock.lock.unlock();
                }
            } finally {
                firstLock.lock.unlock();
            }
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
```

### Problem 1: Dining Philosophers with Timeout

```java
import java.util.concurrent.TimeUnit;
import java.util.concurrent.locks.ReentrantLock;

public class DiningPhilosophersWithTimeout {
    private static final int NUM_PHILOSOPHERS = 5;
    private static final ReentrantLock[] forks = new ReentrantLock[NUM_PHILOSOPHERS];
    
    static {
        for (int i = 0; i < NUM_PHILOSOPHERS; i++) {
            forks[i] = new ReentrantLock();
        }
    }
    
    static class Philosopher implements Runnable {
        private final int id;
        private int mealsEaten = 0;
        private final int maxMeals = 3;
        
        public Philosopher(int id) {
            this.id = id;
        }
        
        @Override
        public void run() {
            try {
                while (mealsEaten < maxMeals) {
                    think();
                    if (eat()) {
                        mealsEaten++;
                        System.out.println("Philosopher " + id + " has eaten " + mealsEaten + " meals");
                    } else {
                        System.out.println("Philosopher " + id + " couldn't get forks, continuing to think");
                    }
                }
                System.out.println("Philosopher " + id + " finished eating and left");
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                System.out.println("Philosopher " + id + " was interrupted");
            }
        }
        
        private void think() throws InterruptedException {
            System.out.println("Philosopher " + id + " is thinking");
            Thread.sleep((long) (Math.random() * 1000 + 500));
        }
        
        private boolean eat() throws InterruptedException {
            int leftFork = id;
            int rightFork = (id + 1) % NUM_PHILOSOPHERS;
            
            // Try to acquire both forks with timeout
            boolean gotLeftFork = forks[leftFork].tryLock(2, TimeUnit.SECONDS);
            if (!gotLeftFork) {
                return false;
            }
            
            try {
                boolean gotRightFork = forks[rightFork].tryLock(2, TimeUnit.SECONDS);
                if (!gotRightFork) {
                    return false;
                }
                
                try {
                    System.out.println("Philosopher " + id + " is eating");
                    Thread.sleep((long) (Math.random() * 1000 + 500));
                    return true;
                } finally {
                    forks[rightFork].unlock();
                }
            } finally {
                forks[leftFork].unlock();
            }
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        Thread[] philosophers = new Thread[NUM_PHILOSOPHERS];
        
        for (int i = 0; i < NUM_PHILOSOPHERS; i++) {
            philosophers[i] = new Thread(new Philosopher(i), "Philosopher-" + i);
            philosophers[i].start();
        }
        
        for (Thread philosopher : philosophers) {
            philosopher.join();
        }
        
        System.out.println("All philosophers finished");
    }
}
```

### Problem 2: Producer-Consumer with Priority

```java
import java.util.concurrent.PriorityBlockingQueue;
import java.util.concurrent.atomic.AtomicInteger;

public class PriorityProducerConsumer {
    static class Task implements Comparable<Task> {
        private final int priority;
        private final String data;
        private final long timestamp;
        private static final AtomicInteger taskCounter = new AtomicInteger(0);
        private final int taskId;
        
        public Task(int priority, String data) {
            this.priority = priority;
            this.data = data;
            this.timestamp = System.currentTimeMillis();
            this.taskId = taskCounter.incrementAndGet();
        }
        
        @Override
        public int compareTo(Task other) {
            // Higher priority first, then by timestamp (FIFO for same priority)
            int priorityCompare = Integer.compare(other.priority, this.priority);
            if (priorityCompare != 0) {
                return priorityCompare;
            }
            return Long.compare(this.timestamp, other.timestamp);
        }
        
        @Override
        public String toString() {
            return String.format("Task[id=%d, priority=%d, data='%s']", taskId, priority, data);
        }
        
        public int getPriority() { return priority; }
        public String getData() { return data; }
    }
    
    private static final PriorityBlockingQueue<Task> taskQueue = new PriorityBlockingQueue<>();
    private static volatile boolean shutdown = false;
    
    static class Producer implements Runnable {
        private final String name;
        
        public Producer(String name) {
            this.name = name;
        }
        
        @Override
        public void run() {
            try {
                for (int i = 0; i < 10; i++) {
                    int priority = (int) (Math.random() * 10) + 1; // Priority 1-10
                    Task task = new Task(priority, name + "-Task-" + i);
                    
                    taskQueue.put(task);
                    System.out.println(name + " produced: " + task);
                    
                    Thread.sleep(500);
                }
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
    }
    
    static class Consumer implements Runnable {
        private final String name;
        
        public Consumer(String name) {
            this.name = name;
        }
        
        @Override
        public void run() {
            try {
                while (!shutdown || !taskQueue.isEmpty()) {
                    Task task = taskQueue.poll(1, java.util.concurrent.TimeUnit.SECONDS);
                    if (task != null) {
                        System.out.println(name + " consuming: " + task);
                        
                        // Simulate processing time based on priority
                        long processingTime = (11 - task.getPriority()) * 100; // Higher priority = less time
                        Thread.sleep(processingTime);
                        
                        System.out.println(name + " completed: " + task);
                    }
                }
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        // Start producers
        Thread producer1 = new Thread(new Producer("Producer-1"));
        Thread producer2 = new Thread(new Producer("Producer-2"));
        
        // Start consumers
        Thread consumer1 = new Thread(new Consumer("Consumer-1"));
        Thread consumer2 = new Thread(new Consumer("Consumer-2"));
        
        producer1.start();
        producer2.start();
        consumer1.start();
        consumer2.start();
        
        // Wait for producers to finish
        producer1.join();
        producer2.join();
        
        // Allow some time for consumers to process remaining tasks
        Thread.sleep(2000);
        
        // Signal shutdown
        shutdown = true;
        
        // Wait for consumers to finish
        consumer1.join();
        consumer2.join();
        
        System.out.println("All tasks processed. Remaining tasks: " + taskQueue.size());
    }
}
```

### Problem 3: Read-Write Lock with Writer Preference

```java
import java.util.concurrent.locks.Condition;
import java.util.concurrent.locks.ReentrantLock;

public class WriterPreferenceReadWriteLock {
    private final ReentrantLock lock = new ReentrantLock();
    private final Condition readCondition = lock.newCondition();
    private final Condition writeCondition = lock.newCondition();
    
    private int readers = 0;
    private int writers = 0;
    private int waitingWriters = 0;
    private boolean writing = false;
    
    public void readLock() throws InterruptedException {
        lock.lock();
        try {
            while (writing || waitingWriters > 0) {
                readCondition.await();
            }
            readers++;
        } finally {
            lock.unlock();
        }
    }
    
    public void readUnlock() {
        lock.lock();
        try {
            readers--;
            if (readers == 0) {
                writeCondition.signalAll();
            }
        } finally {
            lock.unlock();
        }
    }
    
    public void writeLock() throws InterruptedException {
        lock.lock();
        try {
            waitingWriters++;
            while (readers > 0 || writing) {
                writeCondition.await();
            }
            waitingWriters--;
            writing = true;
            writers++;
        } finally {
            lock.unlock();
        }
    }
    
    public void writeUnlock() {
        lock.lock();
        try {
            writing = false;
            writers--;
            writeCondition.signalAll();
            readCondition.signalAll();
        } finally {
            lock.unlock();
        }
    }
    
    // Test the custom read-write lock
    static class SharedResource {
        private static final WriterPreferenceReadWriteLock rwLock = new WriterPreferenceReadWriteLock();
        private static String data = "Initial Data";
        private static int version = 0;
        
        public static String read(String readerName) throws InterruptedException {
            rwLock.readLock();
            try {
                System.out.println(readerName + " reading: " + data + " (version " + version + ")");
                Thread.sleep(1000); // Simulate read operation
                return data;
            } finally {
                rwLock.readUnlock();
                System.out.println(readerName + " finished reading");
            }
        }
        
        public static void write(String writerName, String newData) throws InterruptedException {
            rwLock.writeLock();
            try {
                System.out.println(writerName + " writing: " + newData);
                Thread.sleep(2000); // Simulate write operation
                data = newData;
                version++;
                System.out.println(writerName + " finished writing (version " + version + ")");
            } finally {
                rwLock.writeUnlock();
            }
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        // Start multiple readers
        for (int i = 1; i <= 5; i++) {
            final int readerId = i;
            new Thread(() -> {
                try {
                    for (int j = 0; j < 3; j++) {
                        SharedResource.read("Reader-" + readerId);
                        Thread.sleep(500);
                    }
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            }).start();
        }
        
        // Start multiple writers
        for (int i = 1; i <= 2; i++) {
            final int writerId = i;
            new Thread(() -> {
                try {
                    for (int j = 0; j < 2; j++) {
                        SharedResource.write("Writer-" + writerId, 
                                           "Data from Writer-" + writerId + " iteration " + j);
                        Thread.sleep(1000);
                    }
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            }).start();
        }
    }
}
```

## Key Takeaways

1. **Choose the Right Creation Method**: Use Runnable for better design, Callable for return values, and Thread factories for custom configuration.

2. **Understand Thread Lifecycle**: Proper understanding of thread states helps in debugging and optimization.

3. **Use Appropriate Communication Mechanism**: Choose based on your specific needs - wait/notify for low-level control, BlockingQueue for producer-consumer, etc.

4. **Handle Interruption Properly**: Always check for interruption and restore the interrupt status.

5. **Avoid Deadlocks**: Use consistent lock ordering and consider timeouts for lock acquisition.

6. **Monitor Thread States**: Use tools like ThreadMXBean for monitoring and debugging concurrent applications.

This comprehensive guide covers the essential aspects of thread creation, lifecycle management, and inter-thread communication in Java, providing both theoretical understanding and practical implementation examples.
