## Introduction

Thread locks and conditions are fundamental synchronization primitives that provide more flexible and powerful alternatives to synchronized blocks. This document explores various types of locks, their characteristics, and how to use conditions for complex thread coordination.

### 🎯 **What You'll Learn**
- **Lock Types**: Different kinds of locks (ReentrantLock, ReadWriteLock, StampedLock)
- **Conditions**: Advanced thread coordination mechanisms
- **When to Use What**: Choosing the right synchronization tool for your needs
- **Performance**: Understanding the trade-offs between different approaches

### 💡 **Simple Analogy**
Think of locks like **different types of doors**:
- **synchronized** = Basic door with one key (simple but limited)
- **ReentrantLock** = Smart door with timeout, interruption, and fair queuing
- **ReadWriteLock** = Library door (many can read, only one can write)
- **StampedLock** = High-tech door with optimistic access (fastest when possible)

## Types of Thread Locks

**🔧 Technical Overview - Thread Lock Classification**:
- **Lock Hierarchy**: Java provides multiple lock types with increasing complexity and capability
- **Monitor Pattern**: All Java locks implement some form of monitor pattern for mutual exclusion
- **AQS Foundation**: Most modern locks are built on AbstractQueuedSynchronizer (AQS) framework
- **Memory Semantics**: All locks provide happens-before relationships for memory consistency
- **Fairness Options**: Locks can be fair (FIFO) or non-fair (performance-optimized)
- **Reentrancy Support**: Most locks support reentrant acquisition by the same thread

### 1. Intrinsic Locks (Synchronized)

**🔧 Technical Deep Dive - Intrinsic Lock Implementation**:
- **Monitor Objects**: Every Java object has an associated monitor (intrinsic lock)
- **JVM Implementation**: Uses native OS mutexes and condition variables internally
- **Biased Locking**: JVM optimization that biases locks toward threads that frequently acquire them
- **Lock Inflation**: JVM can escalate from biased → thin → fat locks based on contention
- **Memory Barriers**: synchronized blocks establish full memory barriers (acquire/release semantics)
- **Exception Safety**: Automatic lock release even if exceptions occur within synchronized block
- **No Timeout Support**: Cannot specify timeout or interrupt waiting threads
- **Stack-based Release**: Locks are released in reverse order of acquisition (stack-like LIFO)

```java
public class IntrinsicLockExample {
    private final Object lock = new Object();
    private int sharedCounter = 0;
    
    // Method-level synchronization
    public synchronized void synchronizedMethod() {
        sharedCounter++;
        System.out.println("Method sync: " + sharedCounter + " by " + 
                          Thread.currentThread().getName());
    }
    
    // Block-level synchronization
    public void synchronizedBlock() {
        synchronized (lock) {
            sharedCounter++;
            System.out.println("Block sync: " + sharedCounter + " by " + 
                              Thread.currentThread().getName());
        }
    }
    
    // Static synchronization
    public static synchronized void staticSynchronizedMethod() {
        System.out.println("Static sync by " + Thread.currentThread().getName());
    }
    
    public static void main(String[] args) throws InterruptedException {
        IntrinsicLockExample example = new IntrinsicLockExample();
        
        Thread[] threads = new Thread[5];
        for (int i = 0; i < threads.length; i++) {
            threads[i] = new Thread(() -> {
                for (int j = 0; j < 3; j++) {
                    example.synchronizedMethod();
                    example.synchronizedBlock();
                    IntrinsicLockExample.staticSynchronizedMethod();
                    
                    try {
                        Thread.sleep(100);
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        break;
                    }
                }
            }, "Thread-" + i);
        }
        
        for (Thread thread : threads) {
            thread.start();
        }
        
        for (Thread thread : threads) {
            thread.join();
        }
        
        System.out.println("Final counter value: " + example.sharedCounter);
    }
}
```

### 2. ReentrantLock

**🔧 Technical Deep Dive - ReentrantLock Architecture**:
- **AQS-Based Implementation**: Built on AbstractQueuedSynchronizer providing robust synchronization primitives
- **State Management**: Uses 32-bit integer state to track lock ownership and hold count
- **Fair vs Non-Fair**: Fair locks use FIFO queue; non-fair allows barging for better throughput
- **Reentrancy Mechanism**: Same thread can acquire lock multiple times; hold count tracks nested acquisitions
- **Condition Support**: Can create multiple Condition objects for fine-grained thread coordination
- **Interrupt Handling**: lockInterruptibly() allows threads to be interrupted while waiting
- **Timeout Capabilities**: tryLock(timeout) prevents indefinite blocking with precise timeout control
- **Memory Ordering**: Provides same memory semantics as synchronized (acquire/release)

```java
import java.util.concurrent.locks.ReentrantLock;
import java.util.concurrent.TimeUnit;

public class ReentrantLockExample {
    private final ReentrantLock lock = new ReentrantLock(true); // Fair lock
    private int counter = 0;
    
    public void incrementWithTryLock() {
        boolean acquired = false;
        try {
            acquired = lock.tryLock(2, TimeUnit.SECONDS);
            if (acquired) {
                counter++;
                System.out.println("TryLock: " + counter + " by " + 
                                 Thread.currentThread().getName() + 
                                 " (Hold count: " + lock.getHoldCount() + ")");
                
                // Demonstrate reentrancy
                reentrantMethod();
                
                Thread.sleep(1000); // Simulate work
            } else {
                System.out.println("Failed to acquire lock: " + 
                                 Thread.currentThread().getName());
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            System.out.println("Interrupted while acquiring lock: " + 
                             Thread.currentThread().getName());
        } finally {
            if (acquired) {
                lock.unlock();
            }
        }
    }
    
    private void reentrantMethod() {
        lock.lock(); // Reentrant call
        try {
            System.out.println("Reentrant call by " + Thread.currentThread().getName() + 
                             " (Hold count: " + lock.getHoldCount() + ")");
        } finally {
            lock.unlock();
        }
    }
    
    public void incrementWithLockInterruptibly() {
        try {
            lock.lockInterruptibly();
            try {
                counter++;
                System.out.println("Interruptible: " + counter + " by " + 
                                 Thread.currentThread().getName());
                Thread.sleep(2000); // Simulate long work
            } finally {
                lock.unlock();
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            System.out.println("Interrupted during lock acquisition: " + 
                             Thread.currentThread().getName());
        }
    }
    
    public void showLockInfo() {
        System.out.println("Lock info:");
        System.out.println("  Is locked: " + lock.isLocked());
        System.out.println("  Is held by current thread: " + lock.isHeldByCurrentThread());
        System.out.println("  Queue length: " + lock.getQueueLength());
        System.out.println("  Is fair: " + lock.isFair());
    }
    
    public static void main(String[] args) throws InterruptedException {
        ReentrantLockExample example = new ReentrantLockExample();
        
        // Test tryLock
        System.out.println("=== Testing tryLock ===");
        Thread[] tryLockThreads = new Thread[3];
        for (int i = 0; i < tryLockThreads.length; i++) {
            tryLockThreads[i] = new Thread(example::incrementWithTryLock, "TryLock-" + i);
            tryLockThreads[i].start();
        }
        
        for (Thread thread : tryLockThreads) {
            thread.join();
        }
        
        Thread.sleep(1000);
        
        // Test lockInterruptibly
        System.out.println("\n=== Testing lockInterruptibly ===");
        Thread interruptibleThread = new Thread(example::incrementWithLockInterruptibly, "Interruptible");
        interruptibleThread.start();
        
        Thread.sleep(1000);
        example.showLockInfo();
        
        System.out.println("Interrupting thread...");
        interruptibleThread.interrupt();
        
        interruptibleThread.join();
        
        System.out.println("Final counter: " + example.counter);
    }
}
```

### 3. ReadWriteLock

**🔧 Technical Deep Dive - ReadWriteLock Implementation**:
- **Shared-Exclusive Pattern**: Implements readers-writer lock pattern with shared read access and exclusive write access
- **State Partitioning**: Uses high 16 bits for read count, low 16 bits for write count in AQS state
- **Read Lock Sharing**: Multiple threads can hold read lock simultaneously without blocking each other
- **Write Lock Exclusivity**: Write lock blocks all other readers and writers for exclusive access
- **Upgrade/Downgrade**: No automatic lock upgrade (read→write) but supports downgrade (write→read)
- **Fairness Policy**: Fair mode prevents writer starvation by alternating between readers and writers
- **Reentrancy Support**: Both read and write locks are reentrant within the same thread
- **Performance Optimization**: Ideal for read-heavy workloads where reads significantly outnumber writes

```java
            writeLock.unlock();
```

### 4. StampedLock (Java 8+)

**🔧 Technical Deep Dive - StampedLock Advanced Features**:
- **Three Lock Modes**: Write (exclusive), Read (shared), and Optimistic Read (non-blocking)
- **Stamp-Based Validation**: Uses 64-bit stamps to track lock state and validate optimistic reads
- **Optimistic Reading**: Allows lock-free reads that validate data consistency after reading
- **Lock Conversion**: Supports conversion between read/write modes without releasing and reacquiring
- **No Reentrancy**: Not reentrant - same thread cannot acquire same lock multiple times
- **High Performance**: Optimized for scenarios with many readers and occasional writers
- **Memory Ordering**: Provides acquire/release semantics with memory barriers
- **Version-Based Consistency**: Uses versioning to detect concurrent modifications during optimistic reads

```java
import java.util.concurrent.locks.StampedLock;

public class StampedLockExample {
    private final StampedLock stampedLock = new StampedLock();
    private double x, y;
    
    // Write method
    public void write(double newX, double newY) {
        long stamp = stampedLock.writeLock();
        try {
            System.out.println("Writing: (" + newX + ", " + newY + ") by " + 
                             Thread.currentThread().getName());
            x = newX;
            y = newY;
            Thread.sleep(1000); // Simulate write operation
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        } finally {
            stampedLock.unlockWrite(stamp);
            System.out.println("Write completed by " + Thread.currentThread().getName());
        }
    }
    
    // Optimistic read
    public double distanceFromOrigin() {
        long stamp = stampedLock.tryOptimisticRead();
        double curX = x, curY = y;
        
        if (!stampedLock.validate(stamp)) {
            // Fallback to read lock if optimistic read failed
            stamp = stampedLock.readLock();
            try {
                curX = x;
                curY = y;
                System.out.println("Optimistic read failed, using read lock by " + 
                                 Thread.currentThread().getName());
            } finally {
                stampedLock.unlockRead(stamp);
            }
        } else {
            System.out.println("Optimistic read succeeded by " + 
                             Thread.currentThread().getName());
        }
        
        return Math.sqrt(curX * curX + curY * curY);
    }
    
    // Read with read lock
    public void readCoordinates() {
        long stamp = stampedLock.readLock();
        try {
            System.out.println("Reading: (" + x + ", " + y + ") by " + 
                             Thread.currentThread().getName());
            Thread.sleep(500); // Simulate read operation
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        } finally {
            stampedLock.unlockRead(stamp);
        }
    }
    
    // Convert read lock to write lock
    public void conditionalWrite(double threshold) {
        long stamp = stampedLock.readLock();
        try {
            while (x == 0.0 && y == 0.0) {
                long writeStamp = stampedLock.tryConvertToWriteLock(stamp);
                if (writeStamp != 0L) {
                    stamp = writeStamp;
                    x = threshold;
                    y = threshold;
                    System.out.println("Converted to write lock and updated coordinates by " + 
                                     Thread.currentThread().getName());
                    break;
                } else {
                    stampedLock.unlockRead(stamp);
                    stamp = stampedLock.writeLock();
                    // Re-read values after acquiring write lock
                }
            }
        } finally {
            stampedLock.unlock(stamp);
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        StampedLockExample example = new StampedLockExample();
        
        // Writer threads
        for (int i = 1; i <= 2; i++) {
            final int writerId = i;
            new Thread(() -> {
                for (int j = 0; j < 3; j++) {
                    example.write(writerId * 10 + j, writerId * 20 + j);
                    try {
                        Thread.sleep(1500);
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        break;
                    }
                }
            }, "Writer-" + i).start();
        }
        
        // Reader threads
        for (int i = 1; i <= 3; i++) {
            new Thread(() -> {
                for (int j = 0; j < 5; j++) {
                    example.readCoordinates();
                    try {
                        Thread.sleep(800);
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        break;
                    }
                }
            }, "Reader-" + i).start();
        }
        
        // Optimistic reader threads
        for (int i = 1; i <= 4; i++) {
            new Thread(() -> {
                for (int j = 0; j < 6; j++) {
                    double distance = example.distanceFromOrigin();
                    System.out.println("Distance calculated: " + distance + " by " + 
                                     Thread.currentThread().getName());
                    try {
                        Thread.sleep(600);
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        break;
                    }
                }
            }, "OptimisticReader-" + i).start();
        }
        
        Thread.sleep(15000);
        System.out.println("Main thread finished");
    }
```

## Condition Variables

- **Monitor Pattern Extension**: Extends basic monitor pattern with multiple wait queues

```java
import java.util.concurrent.locks.Condition;
import java.util.concurrent.locks.ReentrantLock;

public class ConditionExample {
    private final ReentrantLock lock = new ReentrantLock();
    private final Condition notEmpty = lock.newCondition();
    private final Condition notFull = lock.newCondition();
    
    private final Object[] buffer = new Object[10];
    private int count = 0;
    private int putIndex = 0;
    private int takeIndex = 0;
    
    public void put(Object item) throws InterruptedException {
        lock.lock();
        try {
            while (count == buffer.length) {
                System.out.println("Buffer full, " + Thread.currentThread().getName() + " waiting");
                notFull.await();
            }
            
            buffer[putIndex] = item;
            putIndex = (putIndex + 1) % buffer.length;
            count++;
            
            System.out.println("Put: " + item + " by " + Thread.currentThread().getName() + 
                             " (count: " + count + ")");
            
            notEmpty.signal(); // Notify waiting consumers
        } finally {
            lock.unlock();
        }
    }
    
    public Object take() throws InterruptedException {
        lock.lock();
        try {
            while (count == 0) {
                System.out.println("Buffer empty, " + Thread.currentThread().getName() + " waiting");
                notEmpty.await();
            }
            
            Object item = buffer[takeIndex];
            buffer[takeIndex] = null;
            takeIndex = (takeIndex + 1) % buffer.length;
            count--;
            
            System.out.println("Take: " + item + " by " + Thread.currentThread().getName() + 
                             " (count: " + count + ")");
            
            notFull.signal(); // Notify waiting producers
            return item;
        } finally {
            lock.unlock();
        }
    }
    
    public int size() {
        lock.lock();
        try {
            return count;
        } finally {
            lock.unlock();
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        ConditionExample buffer = new ConditionExample();
        
        // Producer threads
        for (int i = 1; i <= 3; i++) {
            final int producerId = i;
            new Thread(() -> {
                try {
                    for (int j = 0; j < 5; j++) {
                        buffer.put("Item-" + producerId + "-" + j);
                        Thread.sleep(500);
                    }
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            }, "Producer-" + i).start();
        }
        
        // Consumer threads
        for (int i = 1; i <= 2; i++) {
            new Thread(() -> {
                try {
                    for (int j = 0; j < 7; j++) {
                        buffer.take();
                        Thread.sleep(1000);
                    }
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            }, "Consumer-" + i).start();
        }
        
        // Monitor buffer size
        for (int i = 0; i < 20; i++) {
            Thread.sleep(500);
            System.out.println("Current buffer size: " + buffer.size());
        }
    }
}
```

### Custom Lock Implementation

**🔧 Technical Implementation Details**:
- **Monitor Pattern**: Uses synchronized blocks internally to implement higher-level lock semantics
- **Wait/Notify Mechanism**: Leverages Object.wait() and notifyAll() for thread coordination
- **Ownership Tracking**: Maintains current lock owner to enforce proper unlock semantics
- **State Management**: Uses volatile variables for lock state visibility across threads
- **Timeout Handling**: Implements precise timeout calculation using System.nanoTime()
- **Interrupt Support**: Properly handles InterruptedException during lock acquisition

```java
import java.util.concurrent.TimeUnit;
import java.util.concurrent.locks.Condition;
import java.util.concurrent.locks.Lock;

public class CustomLockExample {
    
    static class SimpleLock implements Lock {
        private volatile Thread owner;
        private volatile boolean locked = false;
        private final Object lockObject = new Object();
        
        @Override
        public void lock() {
            synchronized (lockObject) {
                while (locked) {
                    try {
                        lockObject.wait();
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        return;
                    }
                }
                locked = true;
                owner = Thread.currentThread();
            }
        }
        
        @Override
        public void lockInterruptibly() throws InterruptedException {
            synchronized (lockObject) {
                while (locked) {
                    lockObject.wait();
                }
                locked = true;
                owner = Thread.currentThread();
            }
        }
        
        @Override
        public boolean tryLock() {
            synchronized (lockObject) {
                if (!locked) {
                    locked = true;
                    owner = Thread.currentThread();
                    return true;
                }
                return false;
            }
        }
        
        @Override
        public boolean tryLock(long time, TimeUnit unit) throws InterruptedException {
            long timeoutNanos = unit.toNanos(time);
            synchronized (lockObject) {
                while (locked && timeoutNanos > 0) {
                    long startTime = System.nanoTime();
                    lockObject.wait(timeoutNanos / 1_000_000, (int)(timeoutNanos % 1_000_000));
                    timeoutNanos -= (System.nanoTime() - startTime);
                }
                
                if (!locked) {
                    locked = true;
                    owner = Thread.currentThread();
                    return true;
                }
                return false;
            }
        }
        
        @Override
        public void unlock() {
            synchronized (lockObject) {
                if (owner != Thread.currentThread()) {
                    throw new IllegalMonitorStateException("Current thread does not own the lock");
                }
                locked = false;
                owner = null;
                lockObject.notifyAll();
            }
        }
        
        @Override
        public Condition newCondition() {
            throw new UnsupportedOperationException("Conditions not supported by SimpleLock");
        }
        
        public boolean isLocked() {
            return locked;
        }
        
        public Thread getOwner() {
            return owner;
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        SimpleLock customLock = new SimpleLock();
        int[] counter = {0};
        
        Runnable task = () -> {
            for (int i = 0; i < 5; i++) {
                customLock.lock();
                try {
                    int current = counter[0];
                    System.out.println(Thread.currentThread().getName() + 
                                     " reading: " + current);
                    
                    Thread.sleep(100); // Simulate work
                    
                    counter[0] = current + 1;
                    System.out.println(Thread.currentThread().getName() + 
                                     " updated to: " + counter[0]);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    break;
                } finally {
                    customLock.unlock();
                }
                
                try {
                    Thread.sleep(50);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    break;
                }
            }
        };
        
        Thread thread1 = new Thread(task, "CustomLock-Thread-1");
        Thread thread2 = new Thread(task, "CustomLock-Thread-2");
        Thread thread3 = new Thread(task, "CustomLock-Thread-3");
        
        thread1.start();
        thread2.start();
        thread3.start();
        
        thread1.join();
        thread2.join();
        thread3.join();
        
        System.out.println("Final counter value: " + counter[0]);
        System.out.println("Lock is locked: " + customLock.isLocked());
    }
}
```

## Advantages and Disadvantages

**🔧 Technical Analysis of Lock Performance and Trade-offs**:

### Lock Types Comparison

| Lock Type | Advantages | Disadvantages | Technical Details |
|-----------|------------|---------------|-------------------|
| **Synchronized** | Simple, built-in, automatic release | Limited flexibility, no timeout, no fair queuing | **JVM Optimization**: Biased locking, lock elision, adaptive spinning<br/>**Memory Overhead**: ~96 bytes per monitor<br/>**Performance**: Fast path ~1-2 CPU cycles when uncontended |
| **ReentrantLock** | Flexible, fair queuing, timeout, interruptible | Manual unlock required, more complex | **AQS-Based**: Uses AbstractQueuedSynchronizer for robust implementation<br/>**Memory Overhead**: ~48 bytes + queue nodes<br/>**Fairness Cost**: Fair locks ~10x slower than unfair under contention |
| **ReadWriteLock** | Multiple readers, optimized for read-heavy workloads | Complex, potential writer starvation | **State Partitioning**: 16-bit read count, 16-bit write count<br/>**Read Scaling**: O(1) read lock acquisition when no writers<br/>**Write Penalty**: Write operations acquire exclusive access |
| **StampedLock** | Optimistic reads, high performance | Complex API, Java 8+ only | **Stamp Validation**: 64-bit version stamps for consistency<br/>**Lock-Free Reads**: Optimistic reads avoid locks entirely<br/>**Conversion Cost**: Lock conversion ~2-3x faster than release/acquire |

### Condition Variables

| Aspect | Advantages | Disadvantages | Technical Details |
|--------|------------|---------------|-------------------|
| **Multiple Conditions** | Fine-grained control, specific waiting | Increased complexity | **Queue Management**: Separate condition queues per Condition object<br/>**Memory Cost**: ~32 bytes per Condition + queue nodes<br/>**Signaling Precision**: Targeted thread wakeup reduces spurious wakeups |
| **await/signal** | Precise thread coordination | Requires careful synchronization | **Park/Unpark**: Uses LockSupport for efficient thread blocking<br/>**Happens-Before**: Signal establishes memory ordering with await<br/>**Fairness**: FIFO ordering of waiting threads |
| **signalAll** | Wake all waiting threads | Potential thundering herd | **Thundering Herd**: All threads wake up and compete for lock<br/>**CPU Cost**: O(n) wakeup cost where n = waiting threads<br/>**Context Switching**: High context switch overhead under contention |

```java
            } finally {
                statsLock.writeLock().unlock();
            }
            
            poolLock.lock();
            try {
                while (availableConnections.isEmpty()) {
                    if (!connectionAvailable.await(timeout, unit)) {
                        // Update timeout statistics
                        statsLock.writeLock().lock();
                        try {
                            timeoutRequests++;
                        } finally {
                            statsLock.writeLock().unlock();
                        }
                        return null; // Timeout
                    }
                }
                
                DatabaseConnection connection = availableConnections.poll();
                if (connection != null) {
                    connection.setInUse(true);
                    
                    // Update statistics
                    long waitTime = System.currentTimeMillis() - startTime;
                    statsLock.writeLock().lock();
                    try {
                        successfulRequests++;
                        totalWaitTime += waitTime;
                    } finally {
                        statsLock.writeLock().unlock();
                    }
                    
                    System.out.println(Thread.currentThread().getName() + 
                                     " acquired " + connection + 
                                     " (wait time: " + waitTime + "ms)");
                }
                
                return connection;
            } finally {
                poolLock.unlock();
            }
        }
        
        public void returnConnection(DatabaseConnection connection) {
            if (connection == null || !allConnections.contains(connection)) {
                return;
            }
            
            poolLock.lock();
            try {
                connection.setInUse(false);
                availableConnections.offer(connection);
                connectionAvailable.signal();
                
                System.out.println(Thread.currentThread().getName() + 
                                 " returned " + connection);
            } finally {
                poolLock.unlock();
            }
        }
        
        public void printStatistics() {
            statsLock.readLock().lock();
            try {
                System.out.println("\n=== Connection Pool Statistics ===");
                System.out.println("Total requests: " + totalRequests);
                System.out.println("Successful requests: " + successfulRequests);
                System.out.println("Timeout requests: " + timeoutRequests);
                System.out.println("Success rate: " + 
                                 (totalRequests > 0 ? (double)successfulRequests/totalRequests*100 : 0) + "%");
                System.out.println("Average wait time: " + 
                                 (successfulRequests > 0 ? totalWaitTime/successfulRequests : 0) + "ms");
                System.out.println("Available connections: " + availableConnections.size());
                System.out.println("===================================\n");
            } finally {
                statsLock.readLock().unlock();
            }
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        ConnectionPool pool = new ConnectionPool(3);
        
        // Simulate multiple clients
        ExecutorService executor = Executors.newFixedThreadPool(8);
        
        for (int i = 1; i <= 10; i++) {
            final int clientId = i;
            executor.submit(() -> {
                try {
                    DatabaseConnection conn = pool.getConnection(2, TimeUnit.SECONDS);
                    
                    if (conn != null) {
                        // Simulate database work
                        Thread.sleep(ThreadLocalRandom.current().nextInt(1000, 3000));
                        pool.returnConnection(conn);
                    } else {
                        System.out.println("Client-" + clientId + " timed out waiting for connection");
                    }
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            });
        }
        
        // Monitor statistics
        ScheduledExecutorService monitor = Executors.newScheduledThreadPool(1);
        monitor.scheduleAtFixedRate(pool::printStatistics, 2, 2, TimeUnit.SECONDS);
        
        executor.shutdown();
        executor.awaitTermination(15, TimeUnit.SECONDS);
        
        monitor.shutdown();
        pool.printStatistics();
    }
```

### 2. Cache with Read-Write Lock and Conditions

```java
import java.util.concurrent.locks.*;
import java.util.concurrent.*;

public class CacheWithLocksExample<K, V> {
    private final ConcurrentHashMap<K, CacheEntry<V>> cache = new ConcurrentHashMap<>();
    private final ReadWriteLock cacheLock = new ReentrantReadWriteLock();
    private final ReentrantLock maintenanceLock = new ReentrantLock();
    private final Condition maintenanceComplete = maintenanceLock.newCondition();
    
    private volatile boolean maintenanceMode = false;
    private final long ttlMillis;
    private final int maxSize;
    
    static class CacheEntry<V> {
        private final V value;
        private final long timestamp;
        private volatile long lastAccessed;
        private final ReentrantLock entryLock = new ReentrantLock();
        
        public CacheEntry(V value) {
            this.value = value;
            this.timestamp = System.currentTimeMillis();
            this.lastAccessed = timestamp;
        }
        
        public V getValue() {
            entryLock.lock();
            try {
                lastAccessed = System.currentTimeMillis();
                return value;
            } finally {
                entryLock.unlock();
            }
        }
        
        public boolean isExpired(long ttlMillis) {
            return System.currentTimeMillis() - timestamp > ttlMillis;
        }
        
        public long getLastAccessed() {
            entryLock.lock();
            try {
                return lastAccessed;
            } finally {
                entryLock.unlock();
            }
        }
    }
    
    public CacheWithLocksExample(long ttlMillis, int maxSize) {
        this.ttlMillis = ttlMillis;
        this.maxSize = maxSize;
        
        // Start maintenance thread
        startMaintenanceThread();
    }
    
    public V get(K key) {
        // Wait if maintenance is in progress
        maintenanceLock.lock();
        try {
            while (maintenanceMode) {
                maintenanceComplete.await();
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            return null;
        } finally {
            maintenanceLock.unlock();
        }
        
        cacheLock.readLock().lock();
        try {
            CacheEntry<V> entry = cache.get(key);
            if (entry != null && !entry.isExpired(ttlMillis)) {
                System.out.println("Cache HIT for key: " + key + " by " + 
                                 Thread.currentThread().getName());
                return entry.getValue();
            } else {
                System.out.println("Cache MISS for key: " + key + " by " + 
                                 Thread.currentThread().getName());
                return null;
            }
        } finally {
            cacheLock.readLock().unlock();
        }
    }
    
    public void put(K key, V value) {
        maintenanceLock.lock();
        try {
            while (maintenanceMode) {
                maintenanceComplete.await();
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            return;
        } finally {
            maintenanceLock.unlock();
        }
        
        cacheLock.writeLock().lock();
        try {
            // Check if cache is full
            if (cache.size() >= maxSize) {
                evictLeastRecentlyUsed();
            }
            
            cache.put(key, new CacheEntry<>(value));
            System.out.println("Cache PUT for key: " + key + " by " + 
                             Thread.currentThread().getName());
        } finally {
            cacheLock.writeLock().unlock();
        }
    }
    
    private void evictLeastRecentlyUsed() {
        K lruKey = null;
        long oldestAccess = Long.MAX_VALUE;
        
        for (Map.Entry<K, CacheEntry<V>> entry : cache.entrySet()) {
            long lastAccessed = entry.getValue().getLastAccessed();
            if (lastAccessed < oldestAccess) {
                oldestAccess = lastAccessed;
                lruKey = entry.getKey();
            }
        }
        
        if (lruKey != null) {
            cache.remove(lruKey);
            System.out.println("Evicted LRU key: " + lruKey);
        }
    }
    
    public void performMaintenance() {
        maintenanceLock.lock();
        try {
            maintenanceMode = true;
            System.out.println("Starting cache maintenance...");
            
            cacheLock.writeLock().lock();
            try {
                // Remove expired entries
                cache.entrySet().removeIf(entry -> {
                    boolean expired = entry.getValue().isExpired(ttlMillis);
                    if (expired) {
                        System.out.println("Removed expired key: " + entry.getKey());
                    }
                    return expired;
                });
                
                // Simulate maintenance work
                Thread.sleep(1000);
                
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            } finally {
                cacheLock.writeLock().unlock();
            }
            
            maintenanceMode = false;
            maintenanceComplete.signalAll();
            System.out.println("Cache maintenance completed");
            
        } finally {
            maintenanceLock.unlock();
        }
    }
    
    private void startMaintenanceThread() {
        Thread maintenanceThread = new Thread(() -> {
            while (!Thread.currentThread().isInterrupted()) {
                try {
                    Thread.sleep(5000); // Maintenance every 5 seconds
                    performMaintenance();
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    break;
                }
            }
        }, "CacheMaintenance");
        
        maintenanceThread.setDaemon(true);
        maintenanceThread.start();
    }
    
    public int size() {
        cacheLock.readLock().lock();
        try {
            return cache.size();
        } finally {
            cacheLock.readLock().unlock();
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        CacheWithLocksExample<String, String> cache = 
            new CacheWithLocksExample<>(3000, 5); // 3 second TTL, max 5 entries
        
        ExecutorService executor = Executors.newFixedThreadPool(6);
        
        // Producer threads
        for (int i = 1; i <= 2; i++) {
            final int producerId = i;
            executor.submit(() -> {
                for (int j = 0; j < 10; j++) {
                    String key = "key-" + (j % 3); // Reuse some keys
                    String value = "value-" + producerId + "-" + j;
                    cache.put(key, value);
                    
                    try {
                        Thread.sleep(800);
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        break;
                    }
                }
            });
        }
        
        // Consumer threads
        for (int i = 1; i <= 4; i++) {
            executor.submit(() -> {
                for (int j = 0; j < 15; j++) {
                    String key = "key-" + (j % 5);
                    String value = cache.get(key);
                    
                    if (value == null) {
                        // Simulate loading from external source
                        cache.put(key, "loaded-" + key + "-" + System.currentTimeMillis());
                    }
                    
                    try {
                        Thread.sleep(600);
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        break;
                    }
                }
            });
        }
        
        // Monitor cache size
        for (int i = 0; i < 20; i++) {
            Thread.sleep(1000);
            System.out.println("Cache size: " + cache.size());
        }
        
        executor.shutdown();
        executor.awaitTermination(30, TimeUnit.SECONDS);
    }
}
```

### Problem 1: Implementing a Fair Semaphore with Conditions

```java
import java.util.concurrent.locks.Condition;
import java.util.concurrent.locks.ReentrantLock;
import java.util.concurrent.TimeUnit;

public class FairSemaphoreProblem {
    
    static class FairSemaphore {
        private final ReentrantLock lock = new ReentrantLock(true); // Fair lock
        private final Condition permitAvailable = lock.newCondition();
        private int permits;
        private final int maxPermits;
        
        public FairSemaphore(int permits) {
            this.permits = permits;
            this.maxPermits = permits;
        }
        
        public void acquire() throws InterruptedException {
            acquire(1);
        }
        
        public void acquire(int permits) throws InterruptedException {
            if (permits <= 0) {
                throw new IllegalArgumentException("Permits must be positive");
            }
            
            lock.lock();
            try {
                while (this.permits < permits) {
                    System.out.println(Thread.currentThread().getName() + 
                                     " waiting for " + permits + " permits (available: " + 
                                     this.permits + ")");
                    permitAvailable.await();
                }
                
                this.permits -= permits;
                System.out.println(Thread.currentThread().getName() + 
                                 " acquired " + permits + " permits (remaining: " + 
                                 this.permits + ")");
            } finally {
                lock.unlock();
            }
        }
        
        public boolean tryAcquire() {
            return tryAcquire(1);
        }
        
        public boolean tryAcquire(int permits) {
            if (permits <= 0) {
                throw new IllegalArgumentException("Permits must be positive");
            }
            
            lock.lock();
            try {
                if (this.permits >= permits) {
                    this.permits -= permits;
                    System.out.println(Thread.currentThread().getName() + 
                                     " try-acquired " + permits + " permits (remaining: " + 
                                     this.permits + ")");
                    return true;
                }
                return false;
            } finally {
                lock.unlock();
            }
        }
        
        public boolean tryAcquire(int permits, long timeout, TimeUnit unit) throws InterruptedException {
            if (permits <= 0) {
                throw new IllegalArgumentException("Permits must be positive");
            }
            
            long timeoutNanos = unit.toNanos(timeout);
            
            lock.lock();
            try {
                while (this.permits < permits && timeoutNanos > 0) {
                    timeoutNanos = permitAvailable.awaitNanos(timeoutNanos);
                }
                
                if (this.permits >= permits) {
                    this.permits -= permits;
                    System.out.println(Thread.currentThread().getName() + 
                                     " timeout-acquired " + permits + " permits (remaining: " + 
                                     this.permits + ")");
                    return true;
                }
                
                System.out.println(Thread.currentThread().getName() + 
                                 " timed out waiting for " + permits + " permits");
                return false;
            } finally {
                lock.unlock();
            }
        }
        
        public void release() {
            release(1);
        }
        
        public void release(int permits) {
            if (permits <= 0) {
                throw new IllegalArgumentException("Permits must be positive");
            }
            
            lock.lock();
            try {
                this.permits = Math.min(maxPermits, this.permits + permits);
                System.out.println(Thread.currentThread().getName() + 
                                 " released " + permits + " permits (available: " + 
                                 this.permits + ")");
                permitAvailable.signalAll(); // Wake up all waiting threads
            } finally {
                lock.unlock();
            }
        }
        
        public int availablePermits() {
            lock.lock();
            try {
                return permits;
            } finally {
                lock.unlock();
            }
        }
        
        public int getQueueLength() {
            lock.lock();
            try {
                return lock.getQueueLength();
            } finally {
                lock.unlock();
            }
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        FairSemaphore semaphore = new FairSemaphore(3);
        
        // Heavy resource users (acquire 2 permits)
        for (int i = 1; i <= 2; i++) {
            final int userId = i;
            new Thread(() -> {
                try {
                    for (int j = 0; j < 3; j++) {
                        semaphore.acquire(2);
                        
                        // Simulate heavy resource usage
                        System.out.println("HeavyUser-" + userId + " using resources (iteration " + j + ")");
                        Thread.sleep(2000);
                        
                        semaphore.release(2);
                        
                        Thread.sleep(500); // Brief pause between iterations
                    }
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            }, "HeavyUser-" + i).start();
        }
        
        // Light resource users (acquire 1 permit)
        for (int i = 1; i <= 4; i++) {
            final int userId = i;
            new Thread(() -> {
                try {
                    for (int j = 0; j < 5; j++) {
                        if (semaphore.tryAcquire(1, 3, TimeUnit.SECONDS)) {
                            // Simulate light resource usage
                            System.out.println("LightUser-" + userId + " using resource (iteration " + j + ")");
                            Thread.sleep(1000);
                            
                            semaphore.release(1);
                        } else {
                            System.out.println("LightUser-" + userId + " gave up waiting");
                        }
                        
                        Thread.sleep(300);
                    }
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            }, "LightUser-" + i).start();
        }
        
        // Monitor semaphore state
        Thread monitor = new Thread(() -> {
            try {
                for (int i = 0; i < 30; i++) {
                    Thread.sleep(1000);
                    System.out.println("--- Semaphore Status ---");
                    System.out.println("Available permits: " + semaphore.availablePermits());
                    System.out.println("Queue length: " + semaphore.getQueueLength());
                    System.out.println("------------------------");
                }
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }, "Monitor");
        
        monitor.start();
        monitor.join();
    }
```

```java
import java.util.concurrent.locks.Condition;
import java.util.concurrent.locks.ReentrantLock;
import java.util.PriorityQueue;
import java.util.Comparator;

public class PriorityProducerConsumerProblem {
    
    static class PriorityItem implements Comparable<PriorityItem> {
        private final String data;
        private final int priority;
        private final long timestamp;
        
        public PriorityItem(String data, int priority) {
            this.data = data;
            this.priority = priority;
            this.timestamp = System.currentTimeMillis();
        }
        
        @Override
        public int compareTo(PriorityItem other) {
            // Higher priority first, then by timestamp (FIFO for same priority)
            int priorityCompare = Integer.compare(other.priority, this.priority);
            if (priorityCompare != 0) {
                return priorityCompare;
            }
            return Long.compare(this.timestamp, other.timestamp);
        }
        
        public String getData() { return data; }
        public int getPriority() { return priority; }
        public long getTimestamp() { return timestamp; }
        
        @Override
        public String toString() {
            return String.format("Item{data='%s', priority=%d, age=%dms}", 
                               data, priority, System.currentTimeMillis() - timestamp);
        }
    }
    
    static class PriorityBuffer {
        private final ReentrantLock lock = new ReentrantLock();
        private final Condition notEmpty = lock.newCondition();
        private final Condition notFull = lock.newCondition();
        private final Condition highPriorityAvailable = lock.newCondition();
        private final Condition mediumPriorityAvailable = lock.newCondition();
        
        private final PriorityQueue<PriorityItem> buffer = new PriorityQueue<>();
        private final int capacity;
        
        public PriorityBuffer(int capacity) {
            this.capacity = capacity;
        }
        
        public void put(PriorityItem item) throws InterruptedException {
            lock.lock();
            try {
                while (buffer.size() == capacity) {
                    System.out.println(Thread.currentThread().getName() + 
                                     " waiting - buffer full (" + buffer.size() + "/" + capacity + ")");
                    notFull.await();
                }
                
                buffer.offer(item);
                System.out.println(Thread.currentThread().getName() + 
                                 " produced: " + item + " (buffer size: " + buffer.size() + ")");
                
                // Signal specific conditions based on priority
                notEmpty.signal();
                if (item.getPriority() >= 8) {
                    highPriorityAvailable.signal();
                } else if (item.getPriority() >= 5) {
                    mediumPriorityAvailable.signal();
                }
            } finally {
                lock.unlock();
            }
        }
        
        public PriorityItem take() throws InterruptedException {
            lock.lock();
            try {
                while (buffer.isEmpty()) {
                    System.out.println(Thread.currentThread().getName() + 
                                     " waiting - buffer empty");
                    notEmpty.await();
                }
                
                PriorityItem item = buffer.poll();
                notFull.signal();
                
                System.out.println(Thread.currentThread().getName() + 
                                 " consumed: " + item + " (buffer size: " + buffer.size() + ")");
                return item;
            } finally {
                lock.unlock();
            }
        }
        
        public PriorityItem takeHighPriority() throws InterruptedException {
            lock.lock();
            try {
                while (buffer.isEmpty() || buffer.peek().getPriority() < 8) {
                    System.out.println(Thread.currentThread().getName() + 
                                     " waiting for high priority item");
                    highPriorityAvailable.await();
                }
                
                PriorityItem item = buffer.poll();
                notFull.signal();
                
                System.out.println(Thread.currentThread().getName() + 
                                 " consumed HIGH PRIORITY: " + item + 
                                 " (buffer size: " + buffer.size() + ")");
                return item;
            } finally {
                lock.unlock();
            }
        }
        
        public PriorityItem takeMediumPriority() throws InterruptedException {
            lock.lock();
            try {
                while (buffer.isEmpty() || buffer.peek().getPriority() < 5) {
                    System.out.println(Thread.currentThread().getName() + 
                                     " waiting for medium+ priority item");
                    mediumPriorityAvailable.await();
                }
                
                PriorityItem item = buffer.poll();
                notFull.signal();
                
                System.out.println(Thread.currentThread().getName() + 
                                 " consumed MEDIUM+ PRIORITY: " + item + 
                                 " (buffer size: " + buffer.size() + ")");
                return item;
            } finally {
                lock.unlock();
            }
        }
        
        public int size() {
            lock.lock();
            try {
                return buffer.size();
            } finally {
                lock.unlock();
            }
        }
        
        public void printBufferState() {
            lock.lock();
            try {
                System.out.println("Buffer state (size: " + buffer.size() + "):");
                PriorityQueue<PriorityItem> copy = new PriorityQueue<>(buffer);
                while (!copy.isEmpty()) {
                    System.out.println("  " + copy.poll());
                }
            } finally {
                lock.unlock();
            }
        }
    }

        // High priority producer
        Thread highPriorityProducer = new Thread(() -> {
            try {
                for (int i = 0; i < 3; i++) {
                    PriorityItem item = new PriorityItem("HighPriority-" + i, 9);
                    buffer.put(item);
                    Thread.sleep(3000); // Slower production
                }
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }, "HighPriorityProducer");
        
        // Medium priority producer
        Thread mediumPriorityProducer = new Thread(() -> {
            try {

            } catch (InterruptedException e) {

        // Low priority producer

                }
            } catch (InterruptedException e) {

            }
        }, "LowPriorityProducer");
        
        // High priority consumer (only processes high priority items)

        Thread generalConsumer = new Thread(() -> {
            try {
                for (int i = 0; i < 10; i++) {
```

## Key Takeaways

1. **Choose Appropriate Lock Type**: Use synchronized for simple cases, ReentrantLock for advanced features, ReadWriteLock for read-heavy workloads.
   - **Technical Insight**: Lock choice impacts both performance and functionality. Synchronized provides JVM-level optimizations (biased locking, lock elision) for simple cases. ReentrantLock offers advanced features through AQS framework with fair/unfair policies. ReadWriteLock uses state partitioning for concurrent reads but exclusive writes.

2. **Condition Variables**: Provide fine-grained control over thread coordination but require careful management.
   - **Technical Insight**: Conditions extend monitor pattern with multiple wait queues. Each condition maintains separate FIFO queue of waiting threads. Signal operations transfer threads from condition queue to AQS sync queue, requiring lock reacquisition before proceeding.

3. **Lock Fairness**: Fair locks prevent starvation but may reduce throughput.
   - **Technical Insight**: Fair locks use strict FIFO ordering, preventing thread starvation but reducing throughput by ~10x under contention. Unfair locks allow "barging" where newly arriving threads can acquire locks before queued threads, improving overall throughput but potentially causing starvation.

4. **Interruptibility**: Use lockInterruptibly() when threads need to respond to interruption.
   - **Technical Insight**: lockInterruptibly() integrates with thread interruption mechanism, throwing InterruptedException when interrupted while waiting. This enables responsive cancellation and prevents indefinite blocking in long-running applications.

5. **Timeout Support**: tryLock() with timeout prevents indefinite blocking.
   - **Technical Insight**: Timeout support uses precise nanosecond timing with System.nanoTime() for accuracy. Implementation uses condition.awaitNanos() which returns remaining time, allowing accurate timeout tracking across spurious wakeups.

6. **Performance Considerations**: StampedLock offers best performance for read-heavy scenarios with occasional writes.
   - **Technical Insight**: StampedLock's optimistic reads are completely lock-free, using stamp validation to detect concurrent modifications. This eliminates read-write contention entirely, providing linear read scalability. Lock conversion features avoid expensive release/reacquire cycles.

7. **Resource Management**: Always use try-finally blocks to ensure locks are properly released.
   - **Technical Insight**: Unlike synchronized blocks, explicit locks require manual release. Failure to unlock leads to permanent lock acquisition, causing deadlocks and resource leaks. Try-finally ensures unlock even when exceptions occur, maintaining system stability.

**JVM Optimizations**:
- **Biased Locking**: Optimizes locks frequently acquired by same thread
- **Lock Elision**: Eliminates locks on thread-local objects
- **Adaptive Spinning**: Spins briefly before parking threads
- **Lock Coarsening**: Merges adjacent synchronized blocks

**Deadlock Prevention Strategies**:
- **Lock Ordering**: Acquire locks in consistent global order
- **Timeout-Based Acquisition**: Use tryLock() with timeouts to avoid indefinite blocking
- **Lock-Free Algorithms**: Use atomic operations and optimistic concurrency
- **Hierarchical Locking**: Organize locks in hierarchy to prevent circular dependencies
