## Introduction

Future, CompletableFuture, and Callable are fundamental components of asynchronous programming in Java. They enable non-blocking execution, result retrieval from background tasks, and composition of complex asynchronous operations.

### 🎯 **What You'll Learn**
- **Callable**: Tasks that return results (unlike Runnable)
- **Future**: Handle to get results from asynchronous tasks
- **CompletableFuture**: Advanced async programming with chaining and composition
- **Async Patterns**: Common patterns for building responsive applications

### 💡 **Simple Analogy**
Think of these like **ordering food delivery**:
- **Callable** = Restaurant that can make your food AND give you a receipt
- **Future** = The receipt/tracking number for your order
- **CompletableFuture** = Smart tracking that lets you chain actions ("when food arrives, then pay delivery person, then send thank you text")
- You don't wait by the door - you do other things and check the status when convenient

## Callable Interface

### Basic Callable Usage

```java
import java.util.concurrent.*;

public class CallableBasics {
    
    // Simple Callable implementation
    static class NumberCalculator implements Callable<Integer> {
        private final int number;
        
        public NumberCalculator(int number) {
            this.number = number;
        }
        
        @Override
        public Integer call() throws Exception {
            System.out.println("Calculating factorial of " + number + 
                             " on " + Thread.currentThread().getName());
            
            if (number < 0) {
                throw new IllegalArgumentException("Number must be non-negative");
            }
            
            int result = 1;
            for (int i = 1; i <= number; i++) {
                result *= i;
                Thread.sleep(100); // Simulate computation time
            }
            
            System.out.println("Factorial of " + number + " = " + result);
            return result;
        }
    }
    
    public static void basicCallableExample() {
        ExecutorService executor = Executors.newFixedThreadPool(3);
        
        try {
            // Submit Callable tasks
            Future<Integer> future1 = executor.submit(new NumberCalculator(5));
            Future<Integer> future2 = executor.submit(new NumberCalculator(7));
            Future<Integer> future3 = executor.submit(new NumberCalculator(4));
            
            // Get results
            System.out.println("Result 1: " + future1.get());
            System.out.println("Result 2: " + future2.get());
            System.out.println("Result 3: " + future3.get());
            
        } catch (InterruptedException | ExecutionException e) {
            e.printStackTrace();
        } finally {
            executor.shutdown();
        }
    }
    
    // Lambda Callable
    public static void lambdaCallableExample() {
        ExecutorService executor = Executors.newSingleThreadExecutor();
        
        try {
            // Using lambda
            Future<String> future = executor.submit(() -> {
                Thread.sleep(2000);
                return "Hello from Callable lambda!";
            });
            
            System.out.println("Waiting for result...");
            String result = future.get(3, TimeUnit.SECONDS);
            System.out.println("Result: " + result);
            
        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            executor.shutdown();
        }
    }
    
    public static void main(String[] args) {
        System.out.println("=== Basic Callable Example ===");
        basicCallableExample();
        
        System.out.println("\n=== Lambda Callable Example ===");
        lambdaCallableExample();
    }
}
```

## Future Interface

### Future Operations and States

```java
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicInteger;

public class FutureOperations {
    
    public static void futureStatesDemo() {
        ExecutorService executor = Executors.newFixedThreadPool(2);
        
        Future<String> quickTask = executor.submit(() -> {
            Thread.sleep(1000);
            return "Quick task completed";
        });
        
        Future<String> slowTask = executor.submit(() -> {
            Thread.sleep(5000);
            return "Slow task completed";
        });
        
        try {
            // Check initial states
            System.out.println("Quick task done: " + quickTask.isDone());
            System.out.println("Slow task done: " + slowTask.isDone());
            
            // Get quick task result
            String quickResult = quickTask.get(2, TimeUnit.SECONDS);
            System.out.println("Quick result: " + quickResult);
            System.out.println("Quick task done: " + quickTask.isDone());
            
            // Try to get slow task with timeout
            try {
                String slowResult = slowTask.get(2, TimeUnit.SECONDS);
                System.out.println("Slow result: " + slowResult);
            } catch (TimeoutException e) {
                System.out.println("Slow task timed out, cancelling...");
                boolean cancelled = slowTask.cancel(true);
                System.out.println("Cancelled: " + cancelled);
                System.out.println("Is cancelled: " + slowTask.isCancelled());
            }
            
        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            executor.shutdown();
        }
    }
    
    // Future with exception handling
    public static void futureExceptionHandling() {
        ExecutorService executor = Executors.newFixedThreadPool(2);
        
        Future<Integer> successTask = executor.submit(() -> {
            Thread.sleep(1000);
            return 42;
        });
        
        Future<Integer> failureTask = executor.submit(() -> {
            Thread.sleep(500);
            throw new RuntimeException("Task failed!");
        });
        
        try {
            // Successful task
            Integer result1 = successTask.get();
            System.out.println("Success result: " + result1);
            
            // Failed task
            try {
                Integer result2 = failureTask.get();
                System.out.println("Failure result: " + result2);
            } catch (ExecutionException e) {
                System.out.println("Task failed with: " + e.getCause().getMessage());
            }
            
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        } finally {
            executor.shutdown();
        }
    }
    
    public static void main(String[] args) {
        System.out.println("=== Future States Demo ===");
        futureStatesDemo();
        
        System.out.println("\n=== Future Exception Handling ===");
        futureExceptionHandling();
    }
}
```

## CompletableFuture

### Basic CompletableFuture Operations

```java
import java.util.concurrent.CompletableFuture;
import java.util.concurrent.ExecutionException;
import java.util.concurrent.TimeUnit;

public class CompletableFutureBasics {
    
    public static void basicOperations() {
        System.out.println("=== Basic CompletableFuture Operations ===");
        
        // Creating completed futures
        CompletableFuture<String> completed = CompletableFuture.completedFuture("Already done");
        System.out.println("Completed future: " + completed.join());
        
        // Async supply
        CompletableFuture<Integer> asyncSupply = CompletableFuture.supplyAsync(() -> {
            System.out.println("Async supply running on: " + Thread.currentThread().getName());
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
            return 100;
        });
        
        System.out.println("Async supply result: " + asyncSupply.join());
        
        // Async run (no return value)
        CompletableFuture<Void> asyncRun = CompletableFuture.runAsync(() -> {
            System.out.println("Async run executing on: " + Thread.currentThread().getName());
            try {
                Thread.sleep(500);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
            System.out.println("Async run completed");
        });
        
        asyncRun.join(); // Wait for completion
    }
    
    public static void transformationOperations() {
        System.out.println("\n=== Transformation Operations ===");
        
        CompletableFuture<String> future = CompletableFuture
            .supplyAsync(() -> {
                System.out.println("Initial supply on: " + Thread.currentThread().getName());
                return "Hello";
            })
            .thenApply(s -> {
                System.out.println("thenApply on: " + Thread.currentThread().getName());
                return s + " World";
            })
            .thenApplyAsync(s -> {
                System.out.println("thenApplyAsync on: " + Thread.currentThread().getName());
                return s + "!";
            });
        
        System.out.println("Transformation result: " + future.join());
        
        // thenCompose for chaining futures
        CompletableFuture<String> chainedFuture = CompletableFuture
            .supplyAsync(() -> "First")
            .thenCompose(s -> CompletableFuture.supplyAsync(() -> s + " Second"))
            .thenCompose(s -> CompletableFuture.supplyAsync(() -> s + " Third"));
        
        System.out.println("Chained result: " + chainedFuture.join());
    }
    
    public static void combiningFutures() {
        System.out.println("\n=== Combining Futures ===");
        
        CompletableFuture<String> future1 = CompletableFuture.supplyAsync(() -> {
            try { Thread.sleep(1000); } catch (InterruptedException e) { }
            return "Result1";
        });
        
        CompletableFuture<String> future2 = CompletableFuture.supplyAsync(() -> {
            try { Thread.sleep(1500); } catch (InterruptedException e) { }
            return "Result2";
        });
        
        // Combine both results
        CompletableFuture<String> combined = future1.thenCombine(future2, 
            (result1, result2) -> result1 + " + " + result2);
        
        System.out.println("Combined result: " + combined.join());
        
        // Wait for either to complete
        CompletableFuture<String> either = future1.applyToEither(future2, result -> "First: " + result);
        System.out.println("Either result: " + either.join());
    }
    
    public static void main(String[] args) {
        basicOperations();
        transformationOperations();
        combiningFutures();
    }
}
```

### Advanced CompletableFuture Features

```java
import java.util.concurrent.*;
import java.util.List;
import java.util.Arrays;

public class AdvancedCompletableFuture {
    
    public static void exceptionHandling() {
        System.out.println("=== Exception Handling ===");
        
        CompletableFuture<String> future = CompletableFuture
            .supplyAsync(() -> {
                if (Math.random() > 0.5) {
                    throw new RuntimeException("Random failure!");
                }
                return "Success";
            })
            .handle((result, exception) -> {
                if (exception != null) {
                    System.out.println("Handled exception: " + exception.getMessage());
                    return "Default value";
                } else {
                    return result;
                }
            });
        
        System.out.println("Result with handling: " + future.join());
        
        // Exception recovery
        CompletableFuture<String> recovery = CompletableFuture
            .supplyAsync(() -> {
                throw new RuntimeException("Always fails!");
            })
            .exceptionally(throwable -> {
                System.out.println("Exception occurred: " + throwable.getMessage());
                return "Recovered value";
            });
        
        System.out.println("Recovery result: " + recovery.join());
    }
    
    public static void allOfAnyOf() {
        System.out.println("\n=== allOf and anyOf ===");
        
        CompletableFuture<String> task1 = CompletableFuture.supplyAsync(() -> {
            try { Thread.sleep(1000); } catch (InterruptedException e) { }
            return "Task1";
        });
        
        CompletableFuture<String> task2 = CompletableFuture.supplyAsync(() -> {
            try { Thread.sleep(2000); } catch (InterruptedException e) { }
            return "Task2";
        });
        
        CompletableFuture<String> task3 = CompletableFuture.supplyAsync(() -> {
            try { Thread.sleep(1500); } catch (InterruptedException e) { }
            return "Task3";
        });
        
        // Wait for all to complete
        CompletableFuture<Void> allOf = CompletableFuture.allOf(task1, task2, task3);
        CompletableFuture<List<String>> allResults = allOf.thenApply(v -> 
            Arrays.asList(task1.join(), task2.join(), task3.join()));
        
        System.out.println("All results: " + allResults.join());
        
        // Wait for any to complete
        CompletableFuture<Object> anyOf = CompletableFuture.anyOf(task1, task2, task3);
        System.out.println("First result: " + anyOf.join());
    }
    
    public static void customExecutor() {
        System.out.println("\n=== Custom Executor ===");
        
        ExecutorService customExecutor = Executors.newFixedThreadPool(2, r -> {
            Thread t = new Thread(r, "CustomThread-" + System.nanoTime());
            t.setDaemon(true);
            return t;
        });
        
        CompletableFuture<String> future = CompletableFuture
            .supplyAsync(() -> {
                System.out.println("Running on: " + Thread.currentThread().getName());
                return "Custom executor result";
            }, customExecutor)
            .thenApplyAsync(s -> {
                System.out.println("Then apply on: " + Thread.currentThread().getName());
                return s + " - processed";
            }, customExecutor);
        
        System.out.println("Custom executor result: " + future.join());
        customExecutor.shutdown();
    }
    
    public static void main(String[] args) {
        exceptionHandling();
        allOfAnyOf();
        customExecutor();
    }
}
```

## Asynchronous Programming Patterns

### Pipeline Processing

```java
import java.util.concurrent.CompletableFuture;
import java.util.concurrent.ThreadLocalRandom;
import java.util.List;
import java.util.stream.Collectors;
import java.util.stream.IntStream;

public class AsyncPatterns {
    
    static class DataProcessor {
        
        public static CompletableFuture<String> fetchData(String id) {
            return CompletableFuture.supplyAsync(() -> {
                System.out.println("Fetching data for " + id + " on " + Thread.currentThread().getName());
                try {
                    Thread.sleep(ThreadLocalRandom.current().nextInt(500, 1500));
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
                return "raw_data_" + id;
            });
        }
        
        public static CompletableFuture<String> processData(String rawData) {
            return CompletableFuture.supplyAsync(() -> {
                System.out.println("Processing " + rawData + " on " + Thread.currentThread().getName());
                try {
                    Thread.sleep(ThreadLocalRandom.current().nextInt(300, 800));
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
                return "processed_" + rawData;
            });
        }
        
        public static CompletableFuture<String> enrichData(String processedData) {
            return CompletableFuture.supplyAsync(() -> {
                System.out.println("Enriching " + processedData + " on " + Thread.currentThread().getName());
                try {
                    Thread.sleep(ThreadLocalRandom.current().nextInt(200, 600));
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
                return "enriched_" + processedData;
            });
        }
        
        public static CompletableFuture<String> processRecord(String id) {
            return fetchData(id)
                .thenCompose(DataProcessor::processData)
                .thenCompose(DataProcessor::enrichData)
                .whenComplete((result, throwable) -> {
                    if (throwable != null) {
                        System.err.println("Failed to process " + id + ": " + throwable.getMessage());
                    } else {
                        System.out.println("Completed processing: " + result);
                    }
                });
        }
    }
    
    public static void pipelineProcessing() {
        System.out.println("=== Pipeline Processing ===");
        
        List<CompletableFuture<String>> futures = IntStream.range(1, 6)
            .mapToObj(i -> "ID" + i)
            .map(DataProcessor::processRecord)
            .collect(Collectors.toList());
        
        CompletableFuture<List<String>> allResults = CompletableFuture
            .allOf(futures.toArray(new CompletableFuture[0]))
            .thenApply(v -> futures.stream()
                .map(CompletableFuture::join)
                .collect(Collectors.toList()));
        
        System.out.println("All pipeline results: " + allResults.join());
    }
    
    // Scatter-Gather Pattern
    public static void scatterGatherPattern() {
        System.out.println("\n=== Scatter-Gather Pattern ===");
        
        CompletableFuture<Integer> service1 = CompletableFuture.supplyAsync(() -> {
            try { Thread.sleep(1000); } catch (InterruptedException e) { }
            return 10;
        });
        
        CompletableFuture<Integer> service2 = CompletableFuture.supplyAsync(() -> {
            try { Thread.sleep(1200); } catch (InterruptedException e) { }
            return 20;
        });
        
        CompletableFuture<Integer> service3 = CompletableFuture.supplyAsync(() -> {
            try { Thread.sleep(800); } catch (InterruptedException e) { }
            return 30;
        });
        
        // Gather results
        CompletableFuture<Integer> totalResult = service1
            .thenCombine(service2, Integer::sum)
            .thenCombine(service3, Integer::sum);
        
        System.out.println("Scatter-gather result: " + totalResult.join());
        
        // Or use with timeout
        try {
            Integer result = totalResult.get(2, TimeUnit.SECONDS);
            System.out.println("Result within timeout: " + result);
        } catch (Exception e) {
            System.out.println("Timeout or error: " + e.getMessage());
        }
    }
    
    public static void main(String[] args) {
        pipelineProcessing();
        scatterGatherPattern();
    }
}
```

## Real-Life Examples

### 1. REST API Client with Async Processing

```java
import java.util.concurrent.*;
import java.util.List;
import java.util.Map;
import java.util.HashMap;
import java.util.stream.Collectors;

public class AsyncRestClient {
    
    static class ApiResponse {
        private final String endpoint;
        private final int statusCode;
        private final String data;
        private final long responseTime;
        
        public ApiResponse(String endpoint, int statusCode, String data, long responseTime) {
            this.endpoint = endpoint;
            this.statusCode = statusCode;
            this.data = data;
            this.responseTime = responseTime;
        }
        
        // Getters
        public String getEndpoint() { return endpoint; }
        public int getStatusCode() { return statusCode; }
        public String getData() { return data; }
        public long getResponseTime() { return responseTime; }
        
        @Override
        public String toString() {
            return String.format("ApiResponse{endpoint='%s', status=%d, time=%dms}", 
                               endpoint, statusCode, responseTime);
        }
    }
    
    static class RestClient {
        
        public CompletableFuture<ApiResponse> callApi(String endpoint) {
            return CompletableFuture.supplyAsync(() -> {
                long startTime = System.currentTimeMillis();
                
                try {
                    // Simulate HTTP call
                    Thread.sleep(ThreadLocalRandom.current().nextInt(200, 1000));
                    
                    // Simulate occasional failures
                    if (Math.random() < 0.1) {
                        throw new RuntimeException("Network error for " + endpoint);
                    }
                    
                    int statusCode = Math.random() < 0.9 ? 200 : 500;
                    String data = "Response data from " + endpoint;
                    long responseTime = System.currentTimeMillis() - startTime;
                    
                    return new ApiResponse(endpoint, statusCode, data, responseTime);
                    
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    throw new RuntimeException("Interrupted", e);
                }
            });
        }
        
        public CompletableFuture<Map<String, Object>> fetchUserProfile(String userId) {
            CompletableFuture<ApiResponse> userInfo = callApi("/users/" + userId);
            CompletableFuture<ApiResponse> userPrefs = callApi("/users/" + userId + "/preferences");
            CompletableFuture<ApiResponse> userStats = callApi("/users/" + userId + "/statistics");
            
            return userInfo.thenCombine(userPrefs, (info, prefs) -> {
                Map<String, Object> profile = new HashMap<>();
                profile.put("info", info);
                profile.put("preferences", prefs);
                return profile;
            }).thenCombine(userStats, (profile, stats) -> {
                profile.put("statistics", stats);
                return profile;
            }).handle((profile, throwable) -> {
                if (throwable != null) {
                    System.err.println("Error fetching user profile: " + throwable.getMessage());
                    Map<String, Object> errorProfile = new HashMap<>();
                    errorProfile.put("error", throwable.getMessage());
                    return errorProfile;
                }
                return profile;
            });
        }
        
        public CompletableFuture<List<ApiResponse>> batchApiCalls(List<String> endpoints) {
            List<CompletableFuture<ApiResponse>> futures = endpoints.stream()
                .map(this::callApi)
                .collect(Collectors.toList());
            
            return CompletableFuture.allOf(futures.toArray(new CompletableFuture[0]))
                .thenApply(v -> futures.stream()
                    .map(future -> {
                        try {
                            return future.join();
                        } catch (Exception e) {
                            return new ApiResponse("error", 500, e.getMessage(), 0);
                        }
                    })
                    .collect(Collectors.toList()));
        }
    }
    
    public static void main(String[] args) {
        RestClient client = new RestClient();
        
        // Single user profile fetch
        System.out.println("=== Fetching User Profile ===");
        CompletableFuture<Map<String, Object>> profileFuture = client.fetchUserProfile("user123");
        Map<String, Object> profile = profileFuture.join();
        System.out.println("User profile: " + profile);
        
        // Batch API calls
        System.out.println("\n=== Batch API Calls ===");
        List<String> endpoints = List.of(
            "/products/1", "/products/2", "/products/3",
            "/orders/100", "/orders/101", "/inventory/check"
        );
        
        CompletableFuture<List<ApiResponse>> batchFuture = client.batchApiCalls(endpoints);
        List<ApiResponse> responses = batchFuture.join();
        
        responses.forEach(System.out::println);
        
        // Calculate statistics
        long avgResponseTime = responses.stream()
            .mapToLong(ApiResponse::getResponseTime)
            .sum() / responses.size();
        
        long successCount = responses.stream()
            .mapToInt(r -> r.getStatusCode() == 200 ? 1 : 0)
            .sum();
        
        System.out.println("\nBatch Statistics:");
        System.out.println("Average response time: " + avgResponseTime + "ms");
        System.out.println("Success rate: " + (successCount * 100 / responses.size()) + "%");
    }
}
```

## Difficult Problems

### Problem 1: Timeout and Retry with Exponential Backoff

```java
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicInteger;
import java.time.Duration;

public class TimeoutRetryProblem {
    
    static class RetryableOperation {
        private final String operationName;
        private final AtomicInteger attemptCount = new AtomicInteger(0);
        private final double failureRate;
        
        public RetryableOperation(String operationName, double failureRate) {
            this.operationName = operationName;
            this.failureRate = failureRate;
        }
        
        public String execute() throws Exception {
            int attempt = attemptCount.incrementAndGet();
            System.out.println(operationName + " - Attempt " + attempt + 
                             " on " + Thread.currentThread().getName());
            
            // Simulate variable execution time
            Thread.sleep(ThreadLocalRandom.current().nextInt(500, 2000));
            
            // Simulate failures
            if (Math.random() < failureRate) {
                throw new RuntimeException(operationName + " failed on attempt " + attempt);
            }
            
            return operationName + " succeeded on attempt " + attempt;
        }
        
        public int getAttemptCount() {
            return attemptCount.get();
        }
    }
    
    static class AsyncRetryExecutor {
        private final ScheduledExecutorService scheduler = Executors.newScheduledThreadPool(4);
        
        public <T> CompletableFuture<T> executeWithRetry(
                Callable<T> operation, 
                int maxRetries, 
                Duration initialDelay,
                Duration timeout) {
            
            CompletableFuture<T> result = new CompletableFuture<>();
            executeWithRetryInternal(operation, maxRetries, initialDelay, timeout, 0, result);
            return result;
        }
        
        private <T> void executeWithRetryInternal(
                Callable<T> operation,
                int maxRetries,
                Duration currentDelay,
                Duration timeout,
                int currentAttempt,
                CompletableFuture<T> result) {
            
            if (result.isCancelled()) {
                return;
            }
            
            CompletableFuture<T> attemptFuture = CompletableFuture.supplyAsync(() -> {
                try {
                    return operation.call();
                } catch (Exception e) {
                    throw new RuntimeException(e);
                }
            });
            
            // Apply timeout to this attempt
            CompletableFuture<T> timeoutFuture = attemptFuture
                .orTimeout(timeout.toMillis(), TimeUnit.MILLISECONDS);
            
            timeoutFuture.whenComplete((value, throwable) -> {
                if (throwable == null) {
                    // Success
                    result.complete(value);
                } else if (currentAttempt >= maxRetries) {
                    // Max retries reached
                    result.completeExceptionally(new RuntimeException(
                        "Max retries (" + maxRetries + ") exceeded. Last error: " + throwable.getMessage()));
                } else {
                    // Schedule retry with exponential backoff
                    System.out.println("Attempt " + (currentAttempt + 1) + " failed: " + 
                                     throwable.getMessage() + ". Retrying in " + 
                                     currentDelay.toMillis() + "ms");
                    
                    scheduler.schedule(() -> {
                        Duration nextDelay = Duration.ofMillis(currentDelay.toMillis() * 2);
                        executeWithRetryInternal(operation, maxRetries, nextDelay, timeout, 
                                               currentAttempt + 1, result);
                    }, currentDelay.toMillis(), TimeUnit.MILLISECONDS);
                }
            });
        }
        
        public void shutdown() {
            scheduler.shutdown();
        }
    }
    
    public static void main(String[] args) {
        AsyncRetryExecutor executor = new AsyncRetryExecutor();
        
        try {
            // Test different failure rates
            RetryableOperation[] operations = {
                new RetryableOperation("HighFailure", 0.8),
                new RetryableOperation("MediumFailure", 0.5),
                new RetryableOperation("LowFailure", 0.2)
            };
            
            CompletableFuture<?>[] futures = new CompletableFuture[operations.length];
            
            for (int i = 0; i < operations.length; i++) {
                final RetryableOperation op = operations[i];
                futures[i] = executor.executeWithRetry(
                    op::execute,
                    5,  // max retries
                    Duration.ofMillis(500), // initial delay
                    Duration.ofSeconds(3)   // timeout per attempt
                ).whenComplete((result, throwable) -> {
                    if (throwable != null) {
                        System.err.println("Final failure for " + op.operationName + 
                                         " after " + op.getAttemptCount() + " attempts: " + 
                                         throwable.getMessage());
                    } else {
                        System.out.println("Final success: " + result);
                    }
                });
            }
            
            // Wait for all operations to complete
            CompletableFuture.allOf(futures).join();
            
        } finally {
            executor.shutdown();
        }
    }
}
```

## Key Takeaways

1. **Callable vs Runnable**: Use Callable when you need return values or exception propagation from background tasks.

2. **Future Limitations**: Basic Future interface is blocking and limited; CompletableFuture provides non-blocking, composable operations.

3. **CompletableFuture Power**: Enables complex asynchronous workflows with transformation, combination, and exception handling.

4. **Exception Handling**: Use handle(), exceptionally(), and whenComplete() for proper async exception management.

5. **Performance Considerations**: Custom executors can optimize thread usage for specific workload patterns.

6. **Composition Patterns**: Chain operations with thenApply(), thenCompose(), and thenCombine() for readable async code.

This comprehensive guide covers Future, CompletableFuture, and Callable, providing both theoretical understanding and practical implementation patterns for effective asynchronous programming in Java.
