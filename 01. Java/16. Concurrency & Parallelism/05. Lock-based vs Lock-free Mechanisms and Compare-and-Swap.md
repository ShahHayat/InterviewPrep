## Introduction

This document explores the fundamental differences between lock-based and lock-free concurrency mechanisms. We'll examine how Compare-and-Swap operations enable lock-free programming and discuss their practical applications in high-performance concurrent systems.

### 🎯 **What You'll Learn**
- **Lock-based vs Lock-free**: Two fundamentally different approaches to thread safety
- **Compare-and-Swap (CAS)**: The atomic operation that makes lock-free programming possible
- **Atomic Classes**: Java's built-in lock-free data structures
- **Performance Trade-offs**: When to use each approach

### 💡 **Simple Analogy**
Think of the difference like **two approaches to sharing a bathroom**:
- **Lock-based** = Using a door lock (only one person at a time, others wait)
- **Lock-free** = Using optimistic approach (try to enter, back off if occupied, retry)
- **CAS** = The mechanism that checks "is bathroom empty?" and "enter if empty" atomically

## Lock-based Mechanisms

### Characteristics of Lock-based Synchronization

```java
public class LockBasedCounter {
    private final Object lock = new Object();
    private volatile int count = 0;
    
    // Lock-based increment
    public void increment() {
        synchronized (lock) {
            count++; // Critical section
        }
    }
    
    // Lock-based decrement
    public void decrement() {
        synchronized (lock) {
            count--; // Critical section
        }
    }
    
    public int get() {
        synchronized (lock) {
            return count;
        }
    }
    
    // Demonstrates blocking behavior
    public void longOperation() {
        synchronized (lock) {
            try {
                System.out.println(Thread.currentThread().getName() + " acquired lock");
                Thread.sleep(2000); // Long operation blocks other threads
                count += 10;
                System.out.println(Thread.currentThread().getName() + " releasing lock");
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        LockBasedCounter counter = new LockBasedCounter();
        
        // Start a long operation
        Thread longThread = new Thread(counter::longOperation, "LongOperation");
        longThread.start();
        
        Thread.sleep(100); // Ensure long operation starts first
        
        // These threads will be blocked
        Thread[] blockedThreads = new Thread[3];
        for (int i = 0; i < blockedThreads.length; i++) {
            blockedThreads[i] = new Thread(() -> {
                System.out.println(Thread.currentThread().getName() + " trying to increment");
                counter.increment();
                System.out.println(Thread.currentThread().getName() + " increment completed");
            }, "BlockedThread-" + i);
            blockedThreads[i].start();
        }
        
        // Wait for all threads
        longThread.join();
        for (Thread thread : blockedThreads) {
            thread.join();
        }
        
        System.out.println("Final count: " + counter.get());
    }
}
```

### Problems with Lock-based Mechanisms

```java
import java.util.concurrent.locks.ReentrantLock;

public class LockBasedProblems {
    private final ReentrantLock lock1 = new ReentrantLock();
    private final ReentrantLock lock2 = new ReentrantLock();
    
    // Deadlock scenario
    public void method1() {
        lock1.lock();
        try {
            System.out.println(Thread.currentThread().getName() + " acquired lock1");
            Thread.sleep(100);
            
            lock2.lock();
            try {
                System.out.println(Thread.currentThread().getName() + " acquired lock2");
                // Do work
            } finally {
                lock2.unlock();
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        } finally {
            lock1.unlock();
        }
    }
    
    public void method2() {
        lock2.lock();
        try {
            System.out.println(Thread.currentThread().getName() + " acquired lock2");
            Thread.sleep(100);
            
            lock1.lock();
            try {
                System.out.println(Thread.currentThread().getName() + " acquired lock1");
                // Do work
            } finally {
                lock1.unlock();
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        } finally {
            lock2.unlock();
        }
    }
    
    // Priority inversion example
    private final Object sharedResource = new Object();
    
    public void lowPriorityTask() {
        synchronized (sharedResource) {
            System.out.println("Low priority task holding resource");
            try {
                Thread.sleep(3000); // Long operation
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
    }
    
    public void highPriorityTask() {
        System.out.println("High priority task waiting for resource");
        synchronized (sharedResource) {
            System.out.println("High priority task got resource");
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        LockBasedProblems problems = new LockBasedProblems();
        
        // Demonstrate deadlock
        System.out.println("=== Deadlock Demonstration ===");
        Thread thread1 = new Thread(problems::method1, "Thread-1");
        Thread thread2 = new Thread(problems::method2, "Thread-2");
        
        thread1.start();
        thread2.start();
        
        // Wait a bit to see if deadlock occurs
        Thread.sleep(2000);
        
        if (thread1.isAlive() || thread2.isAlive()) {
            System.out.println("Deadlock detected! Interrupting threads...");
            thread1.interrupt();
            thread2.interrupt();
        }
        
        thread1.join();
        thread2.join();
        
        // Demonstrate priority inversion
        System.out.println("\n=== Priority Inversion Demonstration ===");
        Thread lowPriority = new Thread(problems::lowPriorityTask, "LowPriority");
        Thread highPriority = new Thread(problems::highPriorityTask, "HighPriority");
        
        lowPriority.setPriority(Thread.MIN_PRIORITY);
        highPriority.setPriority(Thread.MAX_PRIORITY);
        
        lowPriority.start();
        Thread.sleep(100); // Let low priority acquire resource
        highPriority.start();
        
        lowPriority.join();
        highPriority.join();
    }
}
```

## Lock-free Mechanisms

### Understanding Lock-free Programming

Lock-free programming uses atomic operations to achieve thread safety without locks, eliminating many lock-related problems.

```java
import java.util.concurrent.atomic.AtomicInteger;

public class LockFreeCounter {
    private final AtomicInteger count = new AtomicInteger(0);
    
    // Lock-free increment
    public void increment() {
        count.incrementAndGet();
    }
    
    // Lock-free decrement
    public void decrement() {
        count.decrementAndGet();
    }
    
    public int get() {
        return count.get();
    }
    
    // Non-blocking operation
    public void longOperation() {
        System.out.println(Thread.currentThread().getName() + " starting long operation");
        try {
            Thread.sleep(2000); // This doesn't block other threads from accessing count
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
        count.addAndGet(10);
        System.out.println(Thread.currentThread().getName() + " completed long operation");
    }
    
    public static void main(String[] args) throws InterruptedException {
        LockFreeCounter counter = new LockFreeCounter();
        
        // Start a long operation
        Thread longThread = new Thread(counter::longOperation, "LongOperation");
        longThread.start();
        
        Thread.sleep(100); // Ensure long operation starts first
        
        // These threads are NOT blocked
        Thread[] nonBlockedThreads = new Thread[3];
        for (int i = 0; i < nonBlockedThreads.length; i++) {
            nonBlockedThreads[i] = new Thread(() -> {
                System.out.println(Thread.currentThread().getName() + " incrementing");
                counter.increment();
                System.out.println(Thread.currentThread().getName() + " increment completed");
            }, "NonBlockedThread-" + i);
            nonBlockedThreads[i].start();
        }
        
        // Wait for all threads
        longThread.join();
        for (Thread thread : nonBlockedThreads) {
            thread.join();
        }
        
        System.out.println("Final count: " + counter.get());
    }
}
```

### Lock-free Data Structures

```java
import java.util.concurrent.atomic.AtomicReference;

public class LockFreeStack<T> {
    private final AtomicReference<Node<T>> head = new AtomicReference<>();
    
    private static class Node<T> {
        final T data;
        final Node<T> next;
        
        Node(T data, Node<T> next) {
            this.data = data;
            this.next = next;
        }
    }
    
    public void push(T item) {
        Node<T> newNode = new Node<>(item, null);
        Node<T> currentHead;
        
        do {
            currentHead = head.get();
            newNode.next = currentHead;
        } while (!head.compareAndSet(currentHead, newNode));
        
        System.out.println(Thread.currentThread().getName() + " pushed: " + item);
    }
    
    public T pop() {
        Node<T> currentHead;
        Node<T> newHead;
        
        do {
            currentHead = head.get();
            if (currentHead == null) {
                return null; // Stack is empty
            }
            newHead = currentHead.next;
        } while (!head.compareAndSet(currentHead, newHead));
        
        System.out.println(Thread.currentThread().getName() + " popped: " + currentHead.data);
        return currentHead.data;
    }
    
    public boolean isEmpty() {
        return head.get() == null;
    }
    
    public void printStack() {
        Node<T> current = head.get();
        System.out.print("Stack contents: ");
        while (current != null) {
            System.out.print(current.data + " ");
            current = current.next;
        }
        System.out.println();
    }
    
    public static void main(String[] args) throws InterruptedException {
        LockFreeStack<Integer> stack = new LockFreeStack<>();
        
        // Producer threads
        Thread[] producers = new Thread[3];
        for (int i = 0; i < producers.length; i++) {
            final int producerId = i;
            producers[i] = new Thread(() -> {
                for (int j = 0; j < 5; j++) {
                    stack.push(producerId * 10 + j);
                    try {
                        Thread.sleep(100);
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        break;
                    }
                }
            }, "Producer-" + i);
        }
        
        // Consumer threads
        Thread[] consumers = new Thread[2];
        for (int i = 0; i < consumers.length; i++) {
            consumers[i] = new Thread(() -> {
                for (int j = 0; j < 7; j++) {
                    Integer item = stack.pop();
                    if (item == null) {
                        System.out.println(Thread.currentThread().getName() + " found empty stack");
                        break;
                    }
                    try {
                        Thread.sleep(200);
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        break;
                    }
                }
            }, "Consumer-" + i);
        }
        
        // Start all threads
        for (Thread producer : producers) {
            producer.start();
        }
        
        Thread.sleep(500); // Let producers add some items
        
        for (Thread consumer : consumers) {
            consumer.start();
        }
        
        // Wait for completion
        for (Thread producer : producers) {
            producer.join();
        }
        for (Thread consumer : consumers) {
            consumer.join();
        }
        
        stack.printStack();
    }
}
```

## Compare-and-Swap (CAS)

### Understanding CAS Operations

```java
import java.util.concurrent.atomic.AtomicInteger;
import java.util.concurrent.atomic.AtomicReference;

public class CompareAndSwapExample {
    
    // Basic CAS demonstration
    public static void basicCASDemo() {
        AtomicInteger atomicInt = new AtomicInteger(10);
        
        System.out.println("Initial value: " + atomicInt.get());
        
        // CAS: expect 10, update to 20
        boolean success1 = atomicInt.compareAndSet(10, 20);
        System.out.println("CAS(10, 20): " + success1 + ", value: " + atomicInt.get());
        
        // CAS: expect 10 (but current is 20), update to 30
        boolean success2 = atomicInt.compareAndSet(10, 30);
        System.out.println("CAS(10, 30): " + success2 + ", value: " + atomicInt.get());
        
        // CAS: expect 20, update to 30
        boolean success3 = atomicInt.compareAndSet(20, 30);
        System.out.println("CAS(20, 30): " + success3 + ", value: " + atomicInt.get());
    }
    
    // CAS with retry loop
    public static void casRetryLoop() {
        AtomicInteger counter = new AtomicInteger(0);
        
        Runnable incrementTask = () -> {
            for (int i = 0; i < 1000; i++) {
                int current;
                int updated;
                do {
                    current = counter.get();
                    updated = current + 1;
                } while (!counter.compareAndSet(current, updated));
            }
            System.out.println(Thread.currentThread().getName() + " completed");
        };
        
        Thread[] threads = new Thread[5];
        for (int i = 0; i < threads.length; i++) {
            threads[i] = new Thread(incrementTask, "CAS-Thread-" + i);
        }
        
        long startTime = System.currentTimeMillis();
        
        for (Thread thread : threads) {
            thread.start();
        }
        
        try {
            for (Thread thread : threads) {
                thread.join();
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
        
        long endTime = System.currentTimeMillis();
        
        System.out.println("Final counter value: " + counter.get());
        System.out.println("Time taken: " + (endTime - startTime) + "ms");
    }
    
    // ABA problem demonstration
    public static void abaProblemDemo() {
        AtomicReference<String> ref = new AtomicReference<>("A");
        
        Thread thread1 = new Thread(() -> {
            String original = ref.get();
            System.out.println("Thread1 read: " + original);
            
            try {
                Thread.sleep(2000); // Simulate some work
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                return;
            }
            
            // Try to update A -> C
            boolean success = ref.compareAndSet(original, "C");
            System.out.println("Thread1 CAS(A, C): " + success + ", current: " + ref.get());
        }, "Thread1");
        
        Thread thread2 = new Thread(() -> {
            try {
                Thread.sleep(500); // Let thread1 read first
                
                // Change A -> B
                boolean success1 = ref.compareAndSet("A", "B");
                System.out.println("Thread2 CAS(A, B): " + success1);
                
                Thread.sleep(500);
                
                // Change B -> A (ABA problem)
                boolean success2 = ref.compareAndSet("B", "A");
                System.out.println("Thread2 CAS(B, A): " + success2);
                
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }, "Thread2");
        
        thread1.start();
        thread2.start();
        
        try {
            thread1.join();
            thread2.join();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
    
    public static void main(String[] args) {
        System.out.println("=== Basic CAS Demo ===");
        basicCASDemo();
        
        System.out.println("\n=== CAS Retry Loop ===");
        casRetryLoop();
        
        System.out.println("\n=== ABA Problem Demo ===");
        abaProblemDemo();
    }
}
```

```java
import java.util.concurrent.atomic.AtomicReference;
import java.util.concurrent.atomic.AtomicStampedReference;

public class AdvancedCASExample {
    
    // Solving ABA problem with AtomicStampedReference
    static class ABASolution {
        private final AtomicStampedReference<String> ref = 
            new AtomicStampedReference<>("A", 0);
        
        public void demonstrateABASolution() {
            Thread thread1 = new Thread(() -> {
                int[] stampHolder = new int[1];
                String original = ref.get(stampHolder);
                int originalStamp = stampHolder[0];
                
                System.out.println("Thread1 read: " + original + " with stamp: " + originalStamp);
                
                try {
                    Thread.sleep(2000); // Simulate work
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    return;
                }
                
                // Try to update with original stamp
                boolean success = ref.compareAndSet(original, "C", originalStamp, originalStamp + 1);
                System.out.println("Thread1 CAS with stamp: " + success);
                
                if (success) {
                    System.out.println("Thread1 successfully updated to C");
                } else {
                    String current = ref.get(stampHolder);
                    System.out.println("Thread1 failed - current: " + current + 
                                     " with stamp: " + stampHolder[0]);
                }
            }, "Thread1");
            
            Thread thread2 = new Thread(() -> {
                try {
                    Thread.sleep(500);
                    
                    int[] stampHolder = new int[1];
                    
                    // A -> B
                    String current = ref.get(stampHolder);
                    boolean success1 = ref.compareAndSet(current, "B", 
                                                       stampHolder[0], stampHolder[0] + 1);
                    System.out.println("Thread2 A->B: " + success1);
                    
                    Thread.sleep(500);
                    
                    // B -> A (but with new stamp)
                    current = ref.get(stampHolder);
                    boolean success2 = ref.compareAndSet(current, "A", 
                                                       stampHolder[0], stampHolder[0] + 1);
                    System.out.println("Thread2 B->A: " + success2);
                    
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            }, "Thread2");
            
            thread1.start();
            thread2.start();
            
            try {
                thread1.join();
                thread2.join();
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
    }
    
    // Lock-free linked list node
    static class LockFreeLinkedList<T> {
        private final AtomicReference<Node<T>> head = new AtomicReference<>();
        
        private static class Node<T> {
            final T data;
            final AtomicReference<Node<T>> next = new AtomicReference<>();
            
            Node(T data) {
                this.data = data;
            }
        }
        
        public boolean add(T item) {
            Node<T> newNode = new Node<>(item);
            
            while (true) {
                Node<T> currentHead = head.get();
                newNode.next.set(currentHead);
                
                if (head.compareAndSet(currentHead, newNode)) {
                    System.out.println("Added: " + item + " by " + 
                                     Thread.currentThread().getName());
                    return true;
                }
                // CAS failed, retry
            }
        }
        
        public boolean remove(T item) {
            while (true) {
                Node<T> current = head.get();
                
                if (current == null) {
                    return false; // List is empty
                }
                
                if (current.data.equals(item)) {
                    // Remove head
                    Node<T> next = current.next.get();
                    if (head.compareAndSet(current, next)) {
                        System.out.println("Removed: " + item + " by " + 
                                         Thread.currentThread().getName());
                        return true;
                    }
                    // CAS failed, retry
                } else {
                    // Look for item in the rest of the list
                    Node<T> prev = current;
                    Node<T> node = current.next.get();
                    
                    while (node != null) {
                        if (node.data.equals(item)) {
                            Node<T> next = node.next.get();
                            if (prev.next.compareAndSet(node, next)) {
                                System.out.println("Removed: " + item + " by " + 
                                                 Thread.currentThread().getName());
                                return true;
                            }
                            // CAS failed, restart from head
                            break;
                        }
                        prev = node;
                        node = node.next.get();
                    }
                    
                    if (node == null) {
                        return false; // Item not found
                    }
                }
            }
        }
        
        public void printList() {
            Node<T> current = head.get();
            System.out.print("List: ");
            while (current != null) {
                System.out.print(current.data + " ");
                current = current.next.get();
            }
            System.out.println();
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        System.out.println("=== ABA Solution Demo ===");
        ABASolution abaSolution = new ABASolution();
        abaSolution.demonstrateABASolution();
        
        System.out.println("\n=== Lock-free Linked List Demo ===");
        LockFreeLinkedList<Integer> list = new LockFreeLinkedList<>();
        
        // Add elements concurrently
        Thread[] addThreads = new Thread[3];
        for (int i = 0; i < addThreads.length; i++) {
            final int threadId = i;
            addThreads[i] = new Thread(() -> {
                for (int j = 0; j < 5; j++) {
                    list.add(threadId * 10 + j);
                    try {
                        Thread.sleep(50);
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        break;
                    }
                }
            }, "AddThread-" + i);
        }
        
        for (Thread thread : addThreads) {
            thread.start();
        }
        for (Thread thread : addThreads) {
            thread.join();
        }
        
        list.printList();
        
        // Remove elements concurrently
        Thread[] removeThreads = new Thread[2];
        for (int i = 0; i < removeThreads.length; i++) {
            final int threadId = i;
            removeThreads[i] = new Thread(() -> {
                for (int j = 0; j < 3; j++) {
                    list.remove(threadId * 10 + j);
                    try {
                        Thread.sleep(100);
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        break;
                    }
                }
            }, "RemoveThread-" + i);
        }
        
        for (Thread thread : removeThreads) {
            thread.start();
        }
        for (Thread thread : removeThreads) {
            thread.join();
        }
        
        list.printList();
    }
}
```

```java
import java.util.concurrent.atomic.*;

public class AtomicClassesExample {
```

## Advantages and Disadvantages

### Lock-based vs Lock-free Comparison

| Aspect | Lock-based | Lock-free |
|--------|------------|-----------|
| **Blocking** | Threads can block indefinitely | Non-blocking, always makes progress |
| **Deadlock** | Possible with multiple locks | Impossible |
| **Priority Inversion** | Can occur | Does not occur |
| **Performance** | Can be slow due to contention | Generally faster, especially under contention |
| **Complexity** | Easier to understand and debug | More complex, harder to get right |
| **Memory Usage** | Lock objects consume memory | Lower memory overhead |
| **Composability** | Difficult to compose operations | Better composability |
| **Fairness** | Can provide fairness guarantees | No inherent fairness |

### CAS Operation Characteristics

| Aspect | Advantages | Disadvantages |
|--------|------------|---------------|
| **Performance** | Fast, single atomic instruction | Can have high retry overhead |
| **Scalability** | Scales well with CPU cores | Performance degrades under extreme contention |
| **ABA Problem** | Can occur without proper handling | Requires careful design or stamped references |
| **Memory Model** | Provides strong consistency guarantees | Requires understanding of memory ordering |

```java
import java.util.concurrent.atomic.AtomicReference;
import java.util.concurrent.atomic.AtomicInteger;

public class LockFreeMessageQueue<T> {
    
    private static class Node<T> {
        volatile T data;
        volatile Node<T> next;
        
        Node(T data) {
            this.data = data;
        }
    }
    
    private final AtomicReference<Node<T>> head;
    private final AtomicReference<Node<T>> tail;
    private final AtomicInteger size = new AtomicInteger(0);
    
    public LockFreeMessageQueue() {
        Node<T> dummy = new Node<>(null);
        head = new AtomicReference<>(dummy);
        tail = new AtomicReference<>(dummy);
    }
    
    public boolean offer(T item) {
        if (item == null) {
            throw new NullPointerException("Item cannot be null");
        }
        
        Node<T> newNode = new Node<>(item);
        
        while (true) {
            Node<T> currentTail = tail.get();
            Node<T> tailNext = currentTail.next;
            
            if (currentTail == tail.get()) { // Consistency check
                if (tailNext == null) {
                    // Try to link new node at the end of the list
                    if (compareAndSetNext(currentTail, null, newNode)) {
                        // Successfully linked, now move tail
                        tail.compareAndSet(currentTail, newNode);
                        size.incrementAndGet();
                        System.out.println("Enqueued: " + item + " by " + 
                                         Thread.currentThread().getName());
                        return true;
                    }
                } else {
                    // Tail is lagging, try to advance it
                    tail.compareAndSet(currentTail, tailNext);
                }
            }
        }
    }
    
    public T poll() {
        while (true) {
            Node<T> currentHead = head.get();
            Node<T> currentTail = tail.get();
            Node<T> headNext = currentHead.next;
            
            if (currentHead == head.get()) { // Consistency check
                if (currentHead == currentTail) {
                    if (headNext == null) {
                        // Queue is empty
                        return null;
                    }
                    // Tail is lagging, try to advance it
                    tail.compareAndSet(currentTail, headNext);
                } else {
                    if (headNext == null) {
                        // Inconsistent state, retry
                        continue;
                    }
                    
                    // Read data before CAS
                    T data = headNext.data;
                    
                    // Try to move head to next node
                    if (head.compareAndSet(currentHead, headNext)) {
                        size.decrementAndGet();
                        System.out.println("Dequeued: " + data + " by " + 
                                         Thread.currentThread().getName());
                        return data;
                    }
                }
            }
        }
    }
    
    public T peek() {
        while (true) {
            Node<T> currentHead = head.get();
            Node<T> currentTail = tail.get();
            Node<T> headNext = currentHead.next;
            
            if (currentHead == head.get()) {
                if (currentHead == currentTail) {
                    if (headNext == null) {
                        return null; // Queue is empty
                    }
                    tail.compareAndSet(currentTail, headNext);
                } else {
                    if (headNext == null) {
                        continue;
                    }
                    return headNext.data;
                }
            }
        }
    }
    
    public int size() {
        return size.get();
    }
    
    public boolean isEmpty() {
        return peek() == null;
    }
    
    // Atomic CAS operation for next pointer
    private boolean compareAndSetNext(Node<T> node, Node<T> expect, Node<T> update) {
        // In real implementation, this would use sun.misc.Unsafe or VarHandle
        // For demonstration, we'll use a simple approach
        synchronized (node) {
            if (node.next == expect) {
                node.next = update;
                return true;
            }
            return false;
        }
    }
    
    // Message processing example

        private volatile boolean running = true;
```

### Problem 1: Implementing a Lock-free Hash Map

```java
import java.util.concurrent.atomic.AtomicReference;
import java.util.concurrent.atomic.AtomicReferenceArray;

public class LockFreeHashMapProblem<K, V> {
    
    private static final int DEFAULT_CAPACITY = 16;
    private static final double LOAD_FACTOR = 0.75;
    
    private volatile AtomicReferenceArray<Node<K, V>> table;
    private volatile int size = 0;
    private volatile int threshold;
    
    static class Node<K, V> {
        final K key;
        volatile V value;
        volatile Node<K, V> next;
        final int hash;
        
        Node(K key, V value, int hash, Node<K, V> next) {
            this.key = key;
            this.value = value;
            this.hash = hash;
            this.next = next;
        }
    }
    
    public LockFreeHashMapProblem() {
        this.table = new AtomicReferenceArray<>(DEFAULT_CAPACITY);
        this.threshold = (int) (DEFAULT_CAPACITY * LOAD_FACTOR);
    }
    
    private int hash(K key) {
        if (key == null) return 0;
        int h = key.hashCode();
        return h ^ (h >>> 16);
    }
    
    private int indexFor(int hash, int length) {
        return hash & (length - 1);
    }
    
    public V get(K key) {
        int hash = hash(key);
        AtomicReferenceArray<Node<K, V>> currentTable = table;
        int index = indexFor(hash, currentTable.length());
        
        Node<K, V> node = currentTable.get(index);
        while (node != null) {
            if (node.hash == hash && (node.key == key || 
                (key != null && key.equals(node.key)))) {
                return node.value;
            }
            node = node.next;
        }
        return null;
    }
    
    public V put(K key, V value) {
        return putInternal(key, value, false);
    }
    
    public V putIfAbsent(K key, V value) {
        return putInternal(key, value, true);
    }
    
    private V putInternal(K key, V value, boolean onlyIfAbsent) {
        int hash = hash(key);
        
        while (true) {
            AtomicReferenceArray<Node<K, V>> currentTable = table;
            int index = indexFor(hash, currentTable.length());
            
            Node<K, V> head = currentTable.get(index);
            
            // Search for existing key
            Node<K, V> node = head;
            while (node != null) {
                if (node.hash == hash && (node.key == key || 
                    (key != null && key.equals(node.key)))) {
                    // Key exists, update value
                    V oldValue = node.value;
                    if (!onlyIfAbsent) {
                        node.value = value;
                    }
                    return oldValue;
                }
                node = node.next;
            }
            
            // Key doesn't exist, add new node
            Node<K, V> newNode = new Node<>(key, value, hash, head);
            
            if (currentTable.compareAndSet(index, head, newNode)) {
                size++;
                
                // Check if resize is needed
                if (size > threshold) {
                    resize();
                }
                
                System.out.println("Put: " + key + "=" + value + " by " + 
                                 Thread.currentThread().getName());
                return null;
            }
            // CAS failed, retry
        }
    }
    
    public V remove(K key) {
        int hash = hash(key);
        
        while (true) {
            AtomicReferenceArray<Node<K, V>> currentTable = table;
            int index = indexFor(hash, currentTable.length());
            
            Node<K, V> head = currentTable.get(index);
            
            if (head == null) {
                return null; // Key not found
            }
            
            // Check if head node is the one to remove
            if (head.hash == hash && (head.key == key || 
                (key != null && key.equals(head.key)))) {
                
                if (currentTable.compareAndSet(index, head, head.next)) {
                    size--;
                    System.out.println("Removed: " + key + " by " + 
                                     Thread.currentThread().getName());
                    return head.value;
                }
                // CAS failed, retry
                continue;
            }
            
            // Search in the rest of the list
            Node<K, V> prev = head;
            Node<K, V> current = head.next;
            
            while (current != null) {
                if (current.hash == hash && (current.key == key || 
                    (key != null && key.equals(current.key)))) {
                    
                    // Try to remove current node
                    if (compareAndSetNext(prev, current, current.next)) {
                        size--;
                        System.out.println("Removed: " + key + " by " + 
                                         Thread.currentThread().getName());
                        return current.value;
                    }
                    // CAS failed, restart from head
                    break;
                }
                prev = current;
                current = current.next;
            }
            
            if (current == null) {
                return null; // Key not found
            }
        }
    }
    
    private boolean compareAndSetNext(Node<K, V> node, Node<K, V> expect, Node<K, V> update) {
        // Simplified implementation - in real code, use VarHandle or Unsafe
        synchronized (node) {
            if (node.next == expect) {
                node.next = update;
                return true;
            }
            return false;
        }
    }
    
    private void resize() {
        AtomicReferenceArray<Node<K, V>> oldTable = table;
        int oldCapacity = oldTable.length();
        int newCapacity = oldCapacity << 1;
        
        AtomicReferenceArray<Node<K, V>> newTable = new AtomicReferenceArray<>(newCapacity);
        
        // Rehash all nodes
        for (int i = 0; i < oldCapacity; i++) {
            Node<K, V> head = oldTable.get(i);
            
            while (head != null) {
                Node<K, V> next = head.next;
                int newIndex = indexFor(head.hash, newCapacity);
                
                // Add to new table
                Node<K, V> newHead = newTable.get(newIndex);
                Node<K, V> newNode = new Node<>(head.key, head.value, head.hash, newHead);
                newTable.set(newIndex, newNode);
                
                head = next;
            }
        }
        
        table = newTable;
        threshold = (int) (newCapacity * LOAD_FACTOR);
        
        System.out.println("Resized table to capacity: " + newCapacity);
    }
    
    public int size() {
        return size;
    }
    
    public boolean isEmpty() {
        return size == 0;
    }

        AtomicReferenceArray<Node<K, V>> currentTable = table;
        int capacity = currentTable.length();
        int[] bucketSizes = new int[capacity];
        int totalNodes = 0;
        int nonEmptyBuckets = 0;
        
        for (int i = 0; i < capacity; i++) {
            Node<K, V> node = currentTable.get(i);
            int bucketSize = 0;
            
            while (node != null) {
                bucketSize++;
                totalNodes++;
                node = node.next;
            }
            
            bucketSizes[i] = bucketSize;
            if (bucketSize > 0) {
                nonEmptyBuckets++;
            }
        }
        
        System.out.println("=== Hash Map Statistics ===");
        System.out.println("Capacity: " + capacity);
        System.out.println("Size: " + size);
        System.out.println("Load factor: " + (double) totalNodes / capacity);
        System.out.println("Non-empty buckets: " + nonEmptyBuckets);
        System.out.println("Average bucket size: " + (double) totalNodes / nonEmptyBuckets);
    }
```

### Problem 2: Lock-free Producer-Consumer with Backpressure

```java
import java.util.concurrent.atomic.AtomicReference;
import java.util.concurrent.atomic.AtomicLong;
import java.util.concurrent.atomic.AtomicBoolean;

public class LockFreeBackpressureQueue<T> {
    
    private static final int DEFAULT_CAPACITY = 1024;
    
    private final Node<T>[] buffer;
    private final int capacity;
    private final int mask;
    
    private final AtomicLong writeSequence = new AtomicLong(0);
    private final AtomicLong readSequence = new AtomicLong(0);
    private final AtomicLong cachedReadSequence = new AtomicLong(0);
    private final AtomicLong cachedWriteSequence = new AtomicLong(0);
    
    private final AtomicBoolean backpressureActive = new AtomicBoolean(false);
    private final AtomicLong droppedItems = new AtomicLong(0);
    
    static class Node<T> {
        volatile T data;
        volatile long sequence = -1;
        
        Node() {}
    }
    
    @SuppressWarnings("unchecked")
    public LockFreeBackpressureQueue(int capacity) {
        if (Integer.bitCount(capacity) != 1) {
            throw new IllegalArgumentException("Capacity must be a power of 2");
        }
        
        this.capacity = capacity;
        this.mask = capacity - 1;
        this.buffer = new Node[capacity];
        
        for (int i = 0; i < capacity; i++) {
            buffer[i] = new Node<>();
            buffer[i].sequence = i;
        }
    }
    
    public LockFreeBackpressureQueue() {
        this(DEFAULT_CAPACITY);
    }
    
    public boolean offer(T item) {
        return offer(item, false);
    }
    
    public boolean offer(T item, boolean dropOnBackpressure) {
        if (item == null) {
            throw new NullPointerException("Item cannot be null");
        }
        
        long currentWriteSeq;
        Node<T> node;
        
        while (true) {
            currentWriteSeq = writeSequence.get();
            node = buffer[(int) (currentWriteSeq & mask)];
            long nodeSeq = node.sequence;
            long diff = nodeSeq - currentWriteSeq;
            
            if (diff == 0) {
                // Slot is available
                if (writeSequence.compareAndSet(currentWriteSeq, currentWriteSeq + 1)) {
                    break;
                }
            } else if (diff < 0) {
                // Buffer is full
                if (dropOnBackpressure) {
                    droppedItems.incrementAndGet();
                    backpressureActive.set(true);
                    System.out.println("Dropped item due to backpressure: " + item + 
                                     " by " + Thread.currentThread().getName());
                    return false;
                } else {
                    // Check if we should activate backpressure
                    long cachedRead = cachedReadSequence.get();
                    if (currentWriteSeq - cachedRead >= capacity) {
                        // Update cached read sequence
                        cachedReadSequence.set(readSequence.get());
                        if (currentWriteSeq - cachedReadSequence.get() >= capacity) {
                            backpressureActive.set(true);
                            return false; // Buffer is truly full
                        }
                    }
                    
                    // Yield and retry
                    Thread.yield();
                }
            }
        }
        
        // Store the item
        node.data = item;
        node.sequence = currentWriteSeq + 1;
        
        backpressureActive.set(false);
        
        System.out.println("Offered: " + item + " at sequence " + currentWriteSeq + 
                         " by " + Thread.currentThread().getName());
        return true;
    }
    
    public T poll() {
        long currentReadSeq;
        Node<T> node;
        
        while (true) {
            currentReadSeq = readSequence.get();
            node = buffer[(int) (currentReadSeq & mask)];
            long nodeSeq = node.sequence;
            long diff = nodeSeq - (currentReadSeq + 1);
            
            if (diff == 0) {
                // Item is available
                if (readSequence.compareAndSet(currentReadSeq, currentReadSeq + 1)) {
                    break;
                }
            } else if (diff < 0) {
                // No item available
                return null;
            }
        }
        
        T data = node.data;
        node.data = null;
        node.sequence = currentReadSeq + capacity;
        
        System.out.println("Polled: " + data + " at sequence " + currentReadSeq + 
                         " by " + Thread.currentThread().getName());
        return data;
    }
    
    public int size() {
        long write = writeSequence.get();
        long read = readSequence.get();
        return (int) Math.max(0, write - read);
    }
    
    public boolean isEmpty() {
        return writeSequence.get() == readSequence.get();
    }
    
    public boolean isBackpressureActive() {
        return backpressureActive.get();
    }
    
    public long getDroppedItemsCount() {
        return droppedItems.get();
    }
    
    public void printStatistics() {
        System.out.println("=== Queue Statistics ===");
        System.out.println("Capacity: " + capacity);
        System.out.println("Current size: " + size());
        System.out.println("Write sequence: " + writeSequence.get());
        System.out.println("Read sequence: " + readSequence.get());
        System.out.println("Backpressure active: " + backpressureActive.get());
        System.out.println("Dropped items: " + droppedItems.get());
    }
    
    // Adaptive producer that responds to backpressure
    static class AdaptiveProducer<T> implements Runnable {
        private final LockFreeBackpressureQueue<T> queue;
        private final String name;
        private final T[] items;
        private volatile boolean running = true;
        private int producedCount = 0;
        private int droppedCount = 0;
        
        @SuppressWarnings("unchecked")
        public AdaptiveProducer(LockFreeBackpressureQueue<T> queue, String name, T[] items) {
            this.queue = queue;
            this.name = name;
            this.items = items;
        }
        
        @Override
        public void run() {
            int itemIndex = 0;
            int sleepTime = 10; // Initial sleep time
            
            while (running && itemIndex < items.length) {
                T item = items[itemIndex];
                
                if (queue.offer(item, true)) { // Drop on backpressure
                    producedCount++;
                    itemIndex++;
                    
                    // Reduce sleep time on successful offer
                    sleepTime = Math.max(1, sleepTime - 1);
                } else {
                    droppedCount++;
                    
                    // Increase sleep time on backpressure
                    sleepTime = Math.min(100, sleepTime + 5);
                }
                
                try {
                    Thread.sleep(sleepTime);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    break;
                }
            }
            
            System.out.println(name + " finished - Produced: " + producedCount + 
                             ", Dropped: " + droppedCount);
        }
        
        public void stop() {
            running = false;
        }
    }
    
    // Bursty consumer that simulates variable processing time
    static class BurstyConsumer<T> implements Runnable {
        private final LockFreeBackpressureQueue<T> queue;
        private final String name;
        private volatile boolean running = true;
        private int consumedCount = 0;
        
        public BurstyConsumer(LockFreeBackpressureQueue<T> queue, String name) {
            this.queue = queue;
            this.name = name;
        }
        
        @Override
        public void run() {
            while (running) {
                T item = queue.poll();
                
                if (item != null) {
                    consumedCount++;
                    
                    // Simulate variable processing time
                    try {
                        if (consumedCount % 10 == 0) {
                            Thread.sleep(100); // Occasional slow processing
                        } else {
                            Thread.sleep(20); // Normal processing
                        }
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        break;
                    }
                } else {
                    // No item available, brief pause
                    try {
                        Thread.sleep(5);
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        break;
                    }
                }
            }
            
            System.out.println(name + " finished - Consumed: " + consumedCount);
        }
        
        public void stop() {
            running = false;
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        LockFreeBackpressureQueue<String> queue = new LockFreeBackpressureQueue<>(64);
        
        // Create items for producers
        String[] items1 = new String[100];
        String[] items2 = new String[100];
        
        for (int i = 0; i < 100; i++) {
            items1[i] = "Producer1-Item-" + i;
            items2[i] = "Producer2-Item-" + i;
        }
        
        // Start adaptive producers
        AdaptiveProducer<String> producer1 = new AdaptiveProducer<>(queue, "Producer1", items1);
        AdaptiveProducer<String> producer2 = new AdaptiveProducer<>(queue, "Producer2", items2);
        
        Thread producer1Thread = new Thread(producer1);
        Thread producer2Thread = new Thread(producer2);
        
        // Start bursty consumers
        BurstyConsumer<String> consumer1 = new BurstyConsumer<>(queue, "Consumer1");
        BurstyConsumer<String> consumer2 = new BurstyConsumer<>(queue, "Consumer2");
        
        Thread consumer1Thread = new Thread(consumer1);
        Thread consumer2Thread = new Thread(consumer2);
        
        // Start all threads
        producer1Thread.start();
        producer2Thread.start();
        consumer1Thread.start();
        consumer2Thread.start();
        
        // Monitor queue statistics
        Thread monitorThread = new Thread(() -> {
            try {
                for (int i = 0; i < 30; i++) {
                    Thread.sleep(1000);
                    queue.printStatistics();
                    System.out.println("---");
                }
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }, "Monitor");
        
        monitorThread.start();
        
        // Let the simulation run
        Thread.sleep(20000);
        
        // Stop all threads
        producer1.stop();
        producer2.stop();
        consumer1.stop();
        consumer2.stop();
        
        producer1Thread.join();
        producer2Thread.join();
        consumer1Thread.join();
        consumer2Thread.join();
        monitorThread.interrupt();
        monitorThread.join();
        
        System.out.println("\n=== Final Statistics ===");
        queue.printStatistics();
    }
```

## Key Takeaways

1. **Lock-free vs Lock-based**: Lock-free mechanisms provide better scalability and avoid blocking but are more complex to implement correctly.

2. **CAS Operations**: The foundation of lock-free programming, providing atomic compare-and-swap operations that enable wait-free algorithms.

3. **ABA Problem**: A common issue in lock-free programming that can be solved using stamped references or careful algorithm design.

4. **Performance Trade-offs**: Lock-free structures excel under high contention but may have overhead in low-contention scenarios.

5. **Atomic Classes**: Java provides comprehensive atomic classes that handle most common lock-free programming needs.

6. **Memory Ordering**: Understanding memory consistency and ordering is crucial for correct lock-free implementations.

7. **Complexity Management**: Lock-free programming requires careful design and testing due to subtle race conditions and edge cases.
