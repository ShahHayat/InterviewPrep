## Introduction

**🔧 Technical Overview - ScheduledThreadPoolExecutor Architecture and Time-Based Task Management**:
- **Time-Based Scheduling**: Extends ThreadPoolExecutor to support delayed and periodic task execution using a priority queue-based delay queue implementation
- **DelayedWorkQueue**: Internal priority queue that orders tasks by their scheduled execution time, enabling efficient retrieval of the next task to execute
- **ScheduledFuture Interface**: Extension of Future that provides additional methods for querying and controlling scheduled task execution
- **Timing Precision**: Uses System.nanoTime() for high-precision timing calculations, avoiding issues with system clock adjustments
- **Task Cancellation**: Supports cancellation of scheduled tasks with proper cleanup of internal data structures to prevent memory leaks
- **Thread Pool Integration**: Leverages ThreadPoolExecutor's worker thread management while adding scheduling-specific functionality
- **Overflow Handling**: Manages long-term scheduling by handling potential overflow in delay calculations for tasks scheduled far in the future

ScheduledThreadPoolExecutor provides the ability to schedule tasks for future execution, either once or repeatedly. Understanding proper shutdown procedures is crucial for resource management and graceful application termination.

**🔧 Technical Deep Dive - Internal Implementation and Performance Characteristics**:
- **DelayedWorkQueue Implementation**: Uses a heap-based priority queue with leader-follower pattern to efficiently manage scheduled tasks without excessive polling
- **Leader Thread Optimization**: One thread acts as the "leader" waiting for the next scheduled task, while others wait as "followers" to minimize CPU usage
- **Timing Wheel Alternative**: Unlike timing wheel implementations, uses a priority queue approach that scales better with sparse scheduling patterns
- **Memory Management**: Automatically removes cancelled tasks from internal queues during normal operation to prevent memory accumulation
- **Clock Synchronization**: Handles system clock changes gracefully by using relative timing based on nanoTime() rather than absolute wall-clock time
- **Fairness Considerations**: Maintains fairness between scheduled and non-scheduled tasks by integrating with ThreadPoolExecutor's existing fairness mechanisms
- **Batch Execution**: Groups multiple ready tasks for execution to reduce scheduling overhead when many tasks become ready simultaneously
- **Resource Cleanup**: Provides comprehensive cleanup mechanisms during shutdown to ensure all scheduled tasks are properly cancelled or completed

## ScheduledThreadPoolExecutor

**🔧 Technical Overview - ScheduledThreadPoolExecutor Core Components and Scheduling Mechanisms**:
- **ScheduledFutureTask**: Internal implementation of ScheduledFuture that wraps user tasks with timing information and provides cancellation support
- **Execution Time Calculation**: Uses triggerTime() method to calculate absolute execution times based on delays and periods, handling overflow conditions
- **Periodic Task Management**: Maintains separate handling for fixed-rate and fixed-delay tasks with different rescheduling logic after completion
- **Task Queue Management**: Uses DelayQueue<ScheduledFutureTask> as the work queue, automatically ordering tasks by execution time
- **Worker Thread Integration**: Extends ThreadPoolExecutor's worker threads to handle time-based task retrieval and execution
- **Shutdown Behavior Control**: Provides configurable policies for handling scheduled tasks during shutdown (continue execution vs cancel)
- **Exception Handling**: Isolates task exceptions to prevent impact on scheduler operation and other scheduled tasks

### Basic Scheduling Operations

**🔧 Technical Deep Dive - Scheduling Methods and Execution Semantics**:
- **schedule() Method**: Creates one-time delayed tasks using ScheduledFutureTask with computed trigger time based on current nanoTime plus delay
- **scheduleAtFixedRate() Implementation**: Creates periodic tasks that maintain fixed intervals between task starts, compensating for execution time variations
- **scheduleWithFixedDelay() Implementation**: Creates periodic tasks that wait for a fixed delay after task completion before scheduling the next execution
- **Time Unit Conversion**: All scheduling methods convert time units to nanoseconds internally for consistent high-precision timing calculations
- **Initial Delay Handling**: Supports initial delay parameter that determines when the first execution occurs, separate from periodic intervals
- **Task Wrapping**: User-provided Runnable and Callable tasks are wrapped in ScheduledFutureTask instances that handle timing and periodic execution
- **Future Return Values**: All scheduling methods return ScheduledFuture instances that allow querying execution status and cancelling scheduled tasks
- **Thread Safety**: All scheduling operations are thread-safe and can be called concurrently from multiple threads without external synchronization

```java
import java.util.concurrent.*;
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;

public class ScheduledExecutorBasics {
    
    private static final DateTimeFormatter TIME_FORMAT = DateTimeFormatter.ofPattern("HH:mm:ss.SSS");
    
    private static void log(String message) {
        System.out.println(LocalDateTime.now().format(TIME_FORMAT) + " - " + message);
    }
    
    public static void basicScheduling() {
        ScheduledExecutorService scheduler = Executors.newScheduledThreadPool(3);
        
        log("Starting scheduled tasks");
        
        // Schedule one-time task with delay
        scheduler.schedule(() -> {
            log("One-time task executed");
        }, 2, TimeUnit.SECONDS);
        
        // Schedule recurring task with fixed rate
        ScheduledFuture<?> fixedRateTask = scheduler.scheduleAtFixedRate(() -> {
            log("Fixed rate task - " + Thread.currentThread().getName());
            try {
                Thread.sleep(1000); // Task takes 1 second
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }, 1, 3, TimeUnit.SECONDS); // Initial delay: 1s, Period: 3s
        
        // Schedule recurring task with fixed delay
        ScheduledFuture<?> fixedDelayTask = scheduler.scheduleWithFixedDelay(() -> {
            log("Fixed delay task - " + Thread.currentThread().getName());
            try {
                Thread.sleep(1500); // Task takes 1.5 seconds
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }, 1, 2, TimeUnit.SECONDS); // Initial delay: 1s, Delay: 2s after completion
        
        // Let tasks run for 15 seconds
        try {
            Thread.sleep(15000);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
        
        // Cancel specific tasks
        log("Cancelling tasks");
        fixedRateTask.cancel(false);
        fixedDelayTask.cancel(false);
        
        // Shutdown scheduler
        scheduler.shutdown();
        try {
            if (!scheduler.awaitTermination(5, TimeUnit.SECONDS)) {
                scheduler.shutdownNow();
            }
        } catch (InterruptedException e) {
            scheduler.shutdownNow();
            Thread.currentThread().interrupt();
        }
        
        log("Scheduler terminated");
    }
    
    public static void main(String[] args) {
        basicScheduling();
    }
}
```

## Scheduling Methods

**🔧 Technical Overview - Periodic Scheduling Algorithms and Timing Behavior**:
- **Fixed Rate Scheduling**: Maintains constant intervals between task starts, potentially allowing overlapping executions if tasks run longer than the period
- **Fixed Delay Scheduling**: Ensures a minimum delay between task completion and next execution, preventing overlapping but allowing variable intervals
- **Drift Compensation**: Fixed rate scheduling compensates for timing drift by calculating next execution time based on original schedule, not completion time
- **Execution Overlap Handling**: Fixed rate tasks can overlap if execution time exceeds the period, requiring careful resource management in task implementation
- **Clock Skew Resilience**: Both scheduling types use nanoTime() to avoid issues with system clock adjustments or daylight saving time changes
- **Cancellation Propagation**: Cancelling a periodic task prevents future executions while allowing current execution to complete naturally
- **Exception Recovery**: Task exceptions in periodic schedules are caught and logged, but don't terminate the periodic scheduling for that task

### Fixed Rate vs Fixed Delay

**🔧 Technical Deep Dive - Scheduling Algorithm Implementation and Performance Characteristics**:
- **Fixed Rate Algorithm**: Next execution time = initialTime + (n * period), where n is the execution count, maintaining mathematical precision
- **Fixed Delay Algorithm**: Next execution time = completionTime + delay, calculated after each task completion for dynamic scheduling
- **Time Precision Handling**: Uses nanosecond precision internally but accepts various TimeUnit values, converting appropriately for scheduling calculations
- **Scheduling Accuracy**: Achieves sub-millisecond accuracy on most platforms, limited primarily by OS thread scheduling granularity
- **Memory Efficiency**: Periodic tasks reuse the same ScheduledFutureTask instance, updating only the trigger time to minimize object allocation
- **Concurrency Control**: Multiple periodic tasks can execute concurrently unless the pool size limits concurrent execution
- **Resource Utilization**: Fixed delay scheduling provides natural backpressure by preventing task queue buildup when tasks run slowly
- **Performance Monitoring**: Provides access to task execution statistics through ThreadPoolExecutor methods for performance analysis and tuning

import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicInteger;

public class SchedulingComparison {
    
    private static void log(String message) {
        System.out.printf("[%d] %s%n", System.currentTimeMillis(), message);
    }
    
    public static void compareSchedulingMethods() {
        ScheduledExecutorService scheduler = Executors.newScheduledThreadPool(4);
        AtomicInteger fixedRateCounter = new AtomicInteger(0);
        AtomicInteger fixedDelayCounter = new AtomicInteger(0);
        
        // Fixed Rate: Executes every 2 seconds regardless of execution time
        scheduler.scheduleAtFixedRate(() -> {
            int count = fixedRateCounter.incrementAndGet();
            log("FixedRate task " + count + " started");
            
            try {
                // Simulate variable execution time
                Thread.sleep(count % 3 == 0 ? 3000 : 1000);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                return;
            }
            
            log("FixedRate task " + count + " completed");
        }, 0, 2, TimeUnit.SECONDS);
        
        // Fixed Delay: Waits 2 seconds after each completion
        scheduler.scheduleWithFixedDelay(() -> {
            int count = fixedDelayCounter.incrementAndGet();
            log("FixedDelay task " + count + " started");
            
            try {
                // Simulate variable execution time
                Thread.sleep(count % 3 == 0 ? 3000 : 1000);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                return;
            }
            
            log("FixedDelay task " + count + " completed");
        }, 0, 2, TimeUnit.SECONDS);
        
        // Let tasks run for 20 seconds
        try {
            Thread.sleep(20000);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
        
        scheduler.shutdown();
        try {
            scheduler.awaitTermination(10, TimeUnit.SECONDS);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
        
        log("Final counts - FixedRate: " + fixedRateCounter.get() + 
            ", FixedDelay: " + fixedDelayCounter.get());
    }
    
    public static void main(String[] args) {

    }

## Shutdown Methods Comparison

**🔧 Technical Overview - Executor Shutdown Lifecycle and State Management**:
- **Shutdown State Transitions**: Executor transitions through states: RUNNING → SHUTDOWN → STOP → TIDYING → TERMINATED
- **Task Queue Handling**: Different shutdown methods handle queued tasks differently - graceful completion vs immediate cancellation
- **Thread Interruption**: shutdownNow() sends interrupt signals to worker threads, requiring tasks to be interrupt-responsive for clean termination
- **Resource Cleanup**: Proper shutdown ensures thread termination, task queue cleanup, and resource deallocation to prevent memory leaks
- **Timeout Management**: awaitTermination() provides bounded waiting with timeout to prevent indefinite blocking during shutdown
- **Exception Propagation**: Shutdown methods handle exceptions during termination process, providing appropriate error reporting and recovery
- **Concurrent Shutdown**: Multiple threads can safely call shutdown methods concurrently, with appropriate synchronization to ensure consistent state

### Understanding Different Shutdown Approaches

**🔧 Technical Deep Dive - Shutdown Method Implementation and Behavioral Differences**:
- **shutdown() Implementation**: Sets shutdown state, rejects new tasks, but allows queued and running tasks to complete naturally
- **shutdownNow() Implementation**: Sets stop state, attempts to interrupt worker threads, returns list of tasks that never started execution
- **awaitTermination() Implementation**: Uses Condition.await() with timeout to wait for all threads to terminate, returning boolean success indicator
- **State Synchronization**: Uses AbstractQueuedSynchronizer (AQS) internally to manage shutdown state transitions with proper memory barriers
- **Interrupt Handling**: Worker threads check interrupt status and handle InterruptedException appropriately during task execution
- **Task Cancellation**: Scheduled tasks are cancelled during shutdown based on policy settings (continueExistingPeriodicTasksAfterShutdown)
- **Thread Lifecycle**: Worker threads terminate naturally after completing current tasks (shutdown) or when interrupted (shutdownNow)
- **Resource Accounting**: Tracks active tasks, completed tasks, and thread states to determine when termination is complete

## Best Practices

**🔧 Technical Overview - Production-Ready Shutdown Patterns and Resource Management**:
- **Graceful Shutdown Pattern**: Implements shutdown() → awaitTermination() → shutdownNow() sequence for optimal resource cleanup
- **Shutdown Hook Integration**: Uses Runtime.addShutdownHook() to ensure proper cleanup during JVM termination or application shutdown
- **Task Interruption Handling**: Designs tasks to be interrupt-responsive by checking Thread.interrupted() and handling InterruptedException properly
- **Resource Leak Prevention**: Ensures all executor services are properly shut down to prevent thread leaks and memory accumulation
- **Timeout Configuration**: Chooses appropriate timeout values for awaitTermination() based on expected task completion times
- **Exception Recovery**: Implements proper exception handling during shutdown to ensure cleanup completes even if individual tasks fail
- **Monitoring Integration**: Incorporates shutdown status monitoring and logging for operational visibility and debugging

### Proper Shutdown Pattern

**🔧 Technical Deep Dive - Advanced Shutdown Strategies and Implementation Patterns**:
- **Cooperative Cancellation**: Implements task cancellation through shared volatile flags rather than relying solely on thread interruption
- **Shutdown State Coordination**: Uses AtomicBoolean or similar thread-safe mechanisms to coordinate shutdown state across multiple components
- **Resource Cleanup Ordering**: Ensures proper cleanup order - stop accepting new work, complete current work, clean up resources
- **Timeout Strategy**: Implements tiered timeout approach with different timeouts for graceful vs forced shutdown phases
- **Exception Isolation**: Isolates shutdown exceptions to prevent cascade failures during application termination
- **Thread Factory Configuration**: Configures thread factories appropriately (daemon threads, naming, exception handlers) for shutdown behavior
- **Memory Barrier Placement**: Ensures proper memory barriers around shutdown state changes to guarantee visibility across threads
- **Shutdown Hook Ordering**: Considers shutdown hook execution order and dependencies when multiple hooks are involved

import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicBoolean;

public class ProperShutdownPatterns {
    
    static class GracefulShutdownExample {
        private final ScheduledExecutorService scheduler;
        private final AtomicBoolean shutdownRequested = new AtomicBoolean(false);
        
        public GracefulShutdownExample() {
            this.scheduler = Executors.newScheduledThreadPool(2, r -> {
                Thread t = new Thread(r, "GracefulWorker-" + System.nanoTime());
                t.setDaemon(false); // Ensure JVM waits for these threads
                return t;
            });
        }
        
        public void startTasks() {
            // Long-running periodic task
            scheduler.scheduleWithFixedDelay(() -> {
                if (shutdownRequested.get()) {
                    return; // Exit early if shutdown requested
                }
                
                System.out.println("Processing batch...");
                try {
                    Thread.sleep(2000); // Simulate work
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    return;
                }
                System.out.println("Batch processing completed");
            }, 0, 3, TimeUnit.SECONDS);
            
            // Cleanup task
            scheduler.scheduleAtFixedRate(() -> {
                if (shutdownRequested.get()) {
                    return;
                }
                
                System.out.println("Running cleanup...");
                try {
                    Thread.sleep(500);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    return;
                }
                System.out.println("Cleanup completed");
            }, 5, 10, TimeUnit.SECONDS);
        }
        
        public void shutdown() {
            System.out.println("Shutdown requested");
            shutdownRequested.set(true);
            
            scheduler.shutdown();
            
            try {
                // Wait for tasks to complete gracefully
                if (!scheduler.awaitTermination(10, TimeUnit.SECONDS)) {
                    System.out.println("Tasks didn't complete within timeout, forcing shutdown");
                    scheduler.shutdownNow();
                    
                    // Wait for forced termination
                    if (!scheduler.awaitTermination(5, TimeUnit.SECONDS)) {
                        System.err.println("Scheduler did not terminate");
                    }
                }
            } catch (InterruptedException e) {
                scheduler.shutdownNow();
                Thread.currentThread().interrupt();
            }
            
            System.out.println("Shutdown completed");
        }
    }
    
    // Shutdown hook example
    static class ShutdownHookExample {
        private final ScheduledExecutorService scheduler;
        
        public ShutdownHookExample() {
            this.scheduler = Executors.newScheduledThreadPool(1);
            
            // Register shutdown hook
            Runtime.getRuntime().addShutdownHook(new Thread(() -> {
                System.out.println("Shutdown hook triggered");
                shutdownGracefully();
            }, "ShutdownHook"));
        }
        
        public void startBackgroundTasks() {
            scheduler.scheduleAtFixedRate(() -> {
                System.out.println("Background task running...");
                try {
                    Thread.sleep(1000);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    return;
                }
            }, 0, 2, TimeUnit.SECONDS);
        }
        
        private void shutdownGracefully() {
            System.out.println("Shutting down scheduler...");
            scheduler.shutdown();
            
            try {
                if (!scheduler.awaitTermination(3, TimeUnit.SECONDS)) {
                    System.out.println("Forcing shutdown...");
                    scheduler.shutdownNow();
                }
            } catch (InterruptedException e) {
                scheduler.shutdownNow();
                Thread.currentThread().interrupt();
            }
        }
    }
    
    public static void main(String[] args) throws InterruptedException {
        // Test graceful shutdown
        System.out.println("=== Graceful Shutdown Example ===");
        GracefulShutdownExample example1 = new GracefulShutdownExample();
        example1.startTasks();
        
        Thread.sleep(8000);
        example1.shutdown();
        
        // Test shutdown hook
        System.out.println("\n=== Shutdown Hook Example ===");
        ShutdownHookExample example2 = new ShutdownHookExample();
        example2.startBackgroundTasks();
        
        Thread.sleep(5000);
        System.out.println("Main thread ending (shutdown hook will trigger)");
    }
}

import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicLong;
import java.lang.management.ManagementFactory;
import java.lang.management.MemoryMXBean;
import java.lang.management.ThreadMXBean;

public class SystemMonitoringService {
    
    private final ScheduledExecutorService scheduler;
    private final AtomicLong alertCount = new AtomicLong(0);
    private volatile boolean running = true;
    
    // Monitoring thresholds
    private static final double MEMORY_THRESHOLD = 0.8; // 80%
    private static final int THREAD_THRESHOLD = 100;
    private static final double CPU_THRESHOLD = 0.9; // 90%
    
    public SystemMonitoringService() {
        this.scheduler = Executors.newScheduledThreadPool(3, r -> {
            Thread t = new Thread(r, "SystemMonitor-" + System.nanoTime());
            t.setDaemon(true);
            return t;
        });
    }
    
    public void startMonitoring() {
        System.out.println("Starting system monitoring...");
        
        // Memory monitoring
        scheduler.scheduleAtFixedRate(this::monitorMemory, 0, 10, TimeUnit.SECONDS);
        
        // Thread monitoring
        scheduler.scheduleAtFixedRate(this::monitorThreads, 5, 15, TimeUnit.SECONDS);
        
        // Health check report
        scheduler.scheduleAtFixedRate(this::generateHealthReport, 30, 60, TimeUnit.SECONDS);
        
        // Cleanup old alerts
        scheduler.scheduleWithFixedDelay(this::cleanupAlerts, 300, 300, TimeUnit.SECONDS);
    }
    
    private void monitorMemory() {
        if (!running) return;
        
        MemoryMXBean memoryBean = ManagementFactory.getMemoryMXBean();
        long used = memoryBean.getHeapMemoryUsage().getUsed();
        long max = memoryBean.getHeapMemoryUsage().getMax();
        
        double usage = (double) used / max;
        
        System.out.printf("Memory Usage: %.1f%% (%d MB / %d MB)%n", 
                         usage * 100, used / (1024 * 1024), max / (1024 * 1024));
        
        if (usage > MEMORY_THRESHOLD) {
            triggerAlert("HIGH_MEMORY", String.format("Memory usage: %.1f%%", usage * 100));
        }
    }
    
    private void monitorThreads() {
        if (!running) return;
        
        ThreadMXBean threadBean = ManagementFactory.getThreadMXBean();
        int threadCount = threadBean.getThreadCount();
        int daemonCount = threadBean.getDaemonThreadCount();
        
        System.out.printf("Thread Count: %d (Daemon: %d, Non-daemon: %d)%n", 
                         threadCount, daemonCount, threadCount - daemonCount);
        
        if (threadCount > THREAD_THRESHOLD) {
            triggerAlert("HIGH_THREAD_COUNT", "Thread count: " + threadCount);
        }
    }
    
    private void generateHealthReport() {
        if (!running) return;
        
        System.out.println("\n=== HEALTH REPORT ===");
        System.out.println("Monitoring service status: " + (running ? "ACTIVE" : "STOPPING"));
        System.out.println("Total alerts triggered: " + alertCount.get());
        System.out.println("Scheduler active count: " + 
                          ((ScheduledThreadPoolExecutor) scheduler).getActiveCount());
        System.out.println("Scheduler queue size: " + 
                          ((ScheduledThreadPoolExecutor) scheduler).getQueue().size());
        System.out.println("====================\n");
    }
    
    private void cleanupAlerts() {
        if (!running) return;
        
        System.out.println("Performing alert cleanup...");
        // In a real system, this would clean up old alert records
        System.out.println("Alert cleanup completed");
    }
    
    private void triggerAlert(String alertType, String message) {
        long alertId = alertCount.incrementAndGet();
        System.err.printf("ALERT #%d [%s]: %s%n", alertId, alertType, message);
        
        // In a real system, this would:
        // - Send notifications
        // - Log to monitoring system
        // - Trigger automated responses
    }
    
    public void shutdown() {
        System.out.println("Shutting down monitoring service...");
        running = false;
        
        scheduler.shutdown();
        
        try {
            if (!scheduler.awaitTermination(30, TimeUnit.SECONDS)) {
                System.out.println("Forcing shutdown of monitoring tasks...");
                scheduler.shutdownNow();
                
                if (!scheduler.awaitTermination(10, TimeUnit.SECONDS)) {
                    System.err.println("Monitoring service did not terminate cleanly");
                }
            }
        } catch (InterruptedException e) {
            scheduler.shutdownNow();
            Thread.currentThread().interrupt();
        }
        
        System.out.println("Monitoring service shutdown completed");
    }

        // Add shutdown hook

        monitor.startMonitoring();

                }
            }

import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicInteger;
import java.util.List;
import java.util.ArrayList;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

public class DependentTaskScheduler {
    
    static class Task {
        private final String id;
        private final Runnable work;
        private final List<String> dependencies;
        private final int maxRetries;
        private final long retryDelayMs;
        
        public Task(String id, Runnable work, List<String> dependencies, 
                   int maxRetries, long retryDelayMs) {
            this.id = id;
            this.work = work;
            this.dependencies = new ArrayList<>(dependencies);
            this.maxRetries = maxRetries;
            this.retryDelayMs = retryDelayMs;
        }
        
        // Getters
        public String getId() { return id; }
        public Runnable getWork() { return work; }
        public List<String> getDependencies() { return dependencies; }
        public int getMaxRetries() { return maxRetries; }
        public long getRetryDelayMs() { return retryDelayMs; }
    }
    
    static class TaskResult {
        private final String taskId;
        private final boolean success;
        private final String error;
        private final int attempts;
        
        public TaskResult(String taskId, boolean success, String error, int attempts) {
            this.taskId = taskId;
            this.success = success;
            this.error = error;
            this.attempts = attempts;
        }
        
        // Getters
        public String getTaskId() { return taskId; }
        public boolean isSuccess() { return success; }
        public String getError() { return error; }
        public int getAttempts() { return attempts; }
    }
    
    private final ScheduledExecutorService scheduler;
    private final Map<String, Task> tasks = new ConcurrentHashMap<>();
    private final Map<String, TaskResult> completedTasks = new ConcurrentHashMap<>();
    private final Map<String, AtomicInteger> retryCounters = new ConcurrentHashMap<>();
    private final Map<String, ScheduledFuture<?>> scheduledTasks = new ConcurrentHashMap<>();
    
    public DependentTaskScheduler(int poolSize) {
        this.scheduler = Executors.newScheduledThreadPool(poolSize);
    }
    
    public void addTask(Task task) {
        tasks.put(task.getId(), task);
        retryCounters.put(task.getId(), new AtomicInteger(0));
        System.out.println("Added task: " + task.getId() + 
                          " (dependencies: " + task.getDependencies() + ")");
    }
    
    public void startExecution() {
        System.out.println("Starting task execution...");
        
        // Schedule initial check for ready tasks
        scheduleTaskCheck();
    }
    
    private void scheduleTaskCheck() {
        scheduler.schedule(this::checkAndExecuteReadyTasks, 100, TimeUnit.MILLISECONDS);
    }
    
    private void checkAndExecuteReadyTasks() {
        for (Task task : tasks.values()) {
            if (!completedTasks.containsKey(task.getId()) && 
                !scheduledTasks.containsKey(task.getId()) &&
                areDependenciesSatisfied(task)) {
                
                executeTask(task);
            }
        }
        
        // Schedule next check if there are still pending tasks
        if (hasPendingTasks()) {
            scheduleTaskCheck();
        } else {
            System.out.println("All tasks completed or failed");
            printExecutionSummary();
        }
    }
    
    private boolean areDependenciesSatisfied(Task task) {
        for (String dependency : task.getDependencies()) {
            TaskResult result = completedTasks.get(dependency);
            if (result == null || !result.isSuccess()) {
                return false;
            }
        }
        return true;
    }
    
    private void executeTask(Task task) {
        System.out.println("Executing task: " + task.getId());
        
        ScheduledFuture<?> future = scheduler.schedule(() -> {
            try {
                task.getWork().run();
                onTaskSuccess(task);
            } catch (Exception e) {
                onTaskFailure(task, e);
            }
        }, 0, TimeUnit.MILLISECONDS);
        
        scheduledTasks.put(task.getId(), future);
    }
    
    private void onTaskSuccess(Task task) {
        System.out.println("Task completed successfully: " + task.getId());
        
        TaskResult result = new TaskResult(task.getId(), true, null, 
                                         retryCounters.get(task.getId()).get() + 1);
        completedTasks.put(task.getId(), result);
        scheduledTasks.remove(task.getId());
        
        // Schedule next check for newly available tasks
        scheduleTaskCheck();
    }
    
    private void onTaskFailure(Task task, Exception error) {
        int attempts = retryCounters.get(task.getId()).incrementAndGet();
        System.err.println("Task failed: " + task.getId() + " (attempt " + attempts + 
                          ") - " + error.getMessage());
        
        scheduledTasks.remove(task.getId());
        
        if (attempts < task.getMaxRetries()) {
            // Schedule retry
            System.out.println("Scheduling retry for task: " + task.getId() + 
                             " in " + task.getRetryDelayMs() + "ms");
            
            ScheduledFuture<?> retryFuture = scheduler.schedule(() -> {
                executeTask(task);
            }, task.getRetryDelayMs(), TimeUnit.MILLISECONDS);
            
            scheduledTasks.put(task.getId(), retryFuture);
        } else {
            // Max retries exceeded
            System.err.println("Task failed permanently: " + task.getId() + 
                             " (max retries exceeded)");
            
            TaskResult result = new TaskResult(task.getId(), false, 
                                             error.getMessage(), attempts);
            completedTasks.put(task.getId(), result);
            
            scheduleTaskCheck();
        }
    }
    
    private boolean hasPendingTasks() {
        return tasks.size() > completedTasks.size();
    }
    
    private void printExecutionSummary() {
        System.out.println("\n=== EXECUTION SUMMARY ===");
        
        int successful = 0;
        int failed = 0;
        
        for (TaskResult result : completedTasks.values()) {
            System.out.println("Task " + result.getTaskId() + ": " + 
                             (result.isSuccess() ? "SUCCESS" : "FAILED") + 
                             " (attempts: " + result.getAttempts() + ")");
            
            if (result.isSuccess()) {
                successful++;
            } else {
                failed++;
                System.out.println("  Error: " + result.getError());
            }
        }
        
        System.out.println("Total: " + tasks.size() + 
                          ", Successful: " + successful + 
                          ", Failed: " + failed);
        System.out.println("=========================");
    }
    
    public void shutdown() {
        System.out.println("Shutting down task scheduler...");
        
        // Cancel all scheduled tasks
        scheduledTasks.values().forEach(future -> future.cancel(false));
        
        scheduler.shutdown();
        
        try {
            if (!scheduler.awaitTermination(10, TimeUnit.SECONDS)) {
                scheduler.shutdownNow();
            }
        } catch (InterruptedException e) {
            scheduler.shutdownNow();
            Thread.currentThread().interrupt();
        }
        
        System.out.println("Task scheduler shutdown completed");
    }
    
    public static void main(String[] args) throws InterruptedException {
        DependentTaskScheduler scheduler = new DependentTaskScheduler(4);
        
        // Create tasks with dependencies
        scheduler.addTask(new Task("A", () -> {
            System.out.println("Executing task A");
            try { Thread.sleep(1000); } catch (InterruptedException e) { }
        }, List.of(), 3, 2000));
        
        scheduler.addTask(new Task("B", () -> {
            System.out.println("Executing task B");
            try { Thread.sleep(800); } catch (InterruptedException e) { }
        }, List.of(), 3, 1500));
        
        scheduler.addTask(new Task("C", () -> {
            System.out.println("Executing task C (depends on A)");
            try { Thread.sleep(600); } catch (InterruptedException e) { }
        }, List.of("A"), 2, 1000));
        
        scheduler.addTask(new Task("D", () -> {
            System.out.println("Executing task D (depends on B)");
            if (Math.random() < 0.7) {
                throw new RuntimeException("Task D random failure");
            }
            try { Thread.sleep(500); } catch (InterruptedException e) { }
        }, List.of("B"), 4, 3000));
        
        scheduler.addTask(new Task("E", () -> {
            System.out.println("Executing task E (depends on C and D)");
            try { Thread.sleep(400); } catch (InterruptedException e) { }
        }, List.of("C", "D"), 2, 2000));
        
        scheduler.startExecution();
        
        // Wait for completion
        Thread.sleep(30000);
        
        scheduler.shutdown();
    }
}

## Key Takeaways

1. **Fixed Rate vs Fixed Delay**: Fixed rate maintains constant intervals; fixed delay waits after completion.
   - **Technical Insight**: Fixed rate scheduling uses mathematical precision (initialTime + n*period) to maintain schedule accuracy, while fixed delay uses dynamic calculation (completionTime + delay) to prevent task overlap and provide natural backpressure.

2. **Proper Shutdown Sequence**: Use shutdown() → awaitTermination() → shutdownNow() pattern for graceful termination.
   - **Technical Insight**: This sequence provides graceful shutdown (allowing running tasks to complete), bounded waiting (preventing indefinite blocking), and forced termination (ensuring cleanup) while maintaining proper state transitions through the executor lifecycle.

3. **Resource Management**: Always ensure executor services are properly shut down to prevent resource leaks.
   - **Technical Insight**: ScheduledThreadPoolExecutor creates non-daemon threads by default, which prevent JVM termination. Proper shutdown releases thread resources, clears task queues, and allows garbage collection of associated objects.

4. **Exception Handling**: Handle task exceptions appropriately to prevent scheduler thread termination.
   - **Technical Insight**: Uncaught exceptions in scheduled tasks are captured and logged but don't terminate the scheduling thread. However, they can prevent periodic task rescheduling, requiring proper exception handling within task implementations.

5. **Monitoring**: Track scheduler statistics for performance tuning and debugging.
   - **Technical Insight**: ScheduledThreadPoolExecutor provides comprehensive statistics through ThreadPoolExecutor methods including active thread count, completed task count, queue size, and largest pool size for operational monitoring.

6. **Shutdown Hooks**: Use shutdown hooks for cleanup when application terminates unexpectedly.
   - **Technical Insight**: Shutdown hooks execute during JVM termination and provide the last opportunity for cleanup. They should implement timeout-based shutdown patterns to prevent hanging the JVM shutdown process.
